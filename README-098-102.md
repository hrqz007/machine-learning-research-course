# 机器学习科研课程 098–102

本批严格接续公开课程大纲：门控记忆、注意力计算、Transformer块、分词与语言目标、训练规模与预算。每讲都提供lecture/lab/answers的Markdown与PDF、真实执行Notebook、CPU代码、数据输出、机制图、结果图和单元测试。

## 学习路线

| 讲次 | 主题 | 重点验收 |
|---|---|---|
| 098 | 门控记忆与序列任务 | LSTM单步、延迟记忆对比、有效token损失与padding |
| 099 | 注意力的完整计算 | 三token手算、Q/K/V梯度、框架对齐与因果mask |
| 100 | Transformer块与位置 | Pre-LN完整块与全部梯度、置换对称性、顺序任务 |
| 101 | 分词与语言学习目标 | 训练集分词器、标签移位、按文档划分与PPL口径 |
| 102 | 语言模型训练与规模 | 18组受控小实验、预算/去重审计、拟合与外推边界 |

每讲先读lecture，再按lab操作，最后核对answers。运行实验只需Python与requirements.txt；PDF重建另外需要构建依赖和Node.js/MathJax。所有实验在CPU完成，不需要API密钥、云算力或下载预训练权重。

## 真实结果与限制

098三种循环结构在当前简单任务都达到准确率上限，不能据此声称门控优越。099验证注意力机制，不测语言能力。100只有两种枚举顺序，说明位置对称性与优化，不声称泛化。101不同分词的PPL不能直接比较，补充共同字节口径。102区分独特训练数据、重复处理token、参数与计算预算，经验拟合不宣称复现大模型规模律。

共15份PDF、43页，39项单元测试，每讲5个实际执行Notebook代码单元。测试和数值记录在各讲outputs。仅精确移除环境缓存诊断，不改写模型成绩或测试判定。

## 文件与复现

每讲自包含，不依赖相邻讲的代码。数据均由随附脚本生成，许可见各讲DATA_LICENSE.md。file-manifest.json提供该讲内容校验值；PUBLIC_FILES.json列出该讲发布文件。批次manifest记录范围与统计。重新实验可能改变运行时间、PDF元数据或跨版本浮点末位；数值结论按文稿给定阈值审查。
