# 五幅原创图

1. 01_information：种子7、10%标签，训练可见信息与仅用于审计的隐藏真值。
2. 02_cycle：伪标签筛选、冻结、加权与重训的信息流，明确隐藏真值不进入训练。
3. 03_results：九个条件下监督与伪标签测试准确率种子均值，一格有效重复数4，其余5。
4. 04_reinforcement：两个错误种子扩张出120条错误伪标签；准确率维持0，置信度略降但仍高。
5. 05_weak_labels：规则与聚合覆盖率，以及复制规则造成的虚假0.5到0.8概率变化。

plots.py从数据或冻结协议结果生成PNG和SVG，不复制外部图片。全部图的含义与限制在讲义中解释。
