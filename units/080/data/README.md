# 数据字典与信息权限

五个种子7、19、31、43、59。每个种子有240条训练池、100条验证、600条测试，彼此由随机流连续独立生成。每个划分类别0/1数量相等。x1=标准正态噪声+1.25×(2y−1)，x2=1.6×独立标准正态噪声。无量纲，无真实个人或业务数据。

seed-N-features.json：pool_X（240×2，训练可见）、validation_X/validation_y（保留作独立验证；冻结实验未用于调参）、test_X（600×2，训练不使用）。seed-N-audit.json：pool_y（只用于受控标签抽样和训练后伪标签审计）、test_y（只在冻结协议下评估）。训练器self_train不接收隐藏真值或测试集。

按真值分层挑选少量人工种子是模拟设计便利，不代表现实未标注池可免费按未知类别抽样。名义2%实际选4条（1.67%），10%选24条，30%选72条。标签噪声是按指定概率独立翻转，并记录实际比例。生成后无额外标准化，也不从测试数据估计变换。

生成器使用NumPy default_rng/PCG64固定种子，generation.json记录每个文件字节数和SHA256。安装依赖后无需联网即可重建；默认新数据写outputs/generated-data，实验仍读取本data目录。
