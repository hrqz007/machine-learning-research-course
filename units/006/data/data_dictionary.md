# 第006讲教学数据字典

## 来源与研究单位

本目录中的房屋、事件、片区、日期、距离、价格和来源标签全部人为构造，不包含真实个人或市场记录。一个分析样本代表一次挂牌事件。导出文件中的复制记录不新增事件；同一房屋不同日期的挂牌是不同事件。

原始listings.csv有16条数据行。L003与L009各复制一次。L001/L013对应同一房屋H01，L002/L014对应同一房屋H02。整理后应为14次事件、12套房屋。CSV首行是表头，所以数据起于第2行。

## listings.csv

| 字段 | 含义与单位 | 约定 |
| --- | --- | --- |
| event_id | 稳定挂牌事件编号 | 文本；整理后必须唯一 |
| property_id | 稳定房屋编号 | 文本；允许复挂牌而重复 |
| listed_at | 挂牌日期 | 年月日字符串；转换为日期 |
| district_code | 片区代码 | N、S、E、W、X；首尾空格不属于代码 |
| area_sqm | 建筑面积 平方米 | 正数；空白和“未知”表示缺失；首尾空格可去掉 |
| list_price_wan | 总挂牌价 万元 | 本例全部已知且为正数；不是成交价 |

L004面积空白，L010面积为“未知”。L014片区与面积带首尾空格。L012面积300、价格600是确认的有效大记录，不因极端而删除。挂牌价与面积是此教学表的描述字段，不提供未来成交标签。

## district_candidates.csv

未经确认的辅助资料。district_code为键候选；district_name是名称；distance_km表示该教学片区参考点到虚构交通点的距离，单位千米；source_id表示来源标签A或B。距离不代表每套房屋的真实通勤距离，也没有进入模型。

N在A与B中分别为1.2和1.8，存在冲突，必须核查而非任意保留第一条。S、E、W各只有一条。X没有条目，不意味着X事件不存在。

## district_registry.csv

题目给定的确认登记册，每个片区代码唯一。verification_note说明登记册确认A版本；N采用1.2。这个文件为教学提供明确证据，真实项目需要对应来源核实与版本审批，不能由统计结果偏好决定。

## split_manifest.csv

为训练填补边界演示提前固定的清单。event_id唯一，split取train或test。L009至L012为测试，其他十个事件为训练。房屋编号不跨组。该划分只是本讲确定性案例，不自动适用于真实时间预测或代表性评估。

## 衍生列

source_csv_line追踪原始CSV行号，不参与完全重复判断。_merge标记片区左合并匹配状态。area_was_missing标记原面积缺失，area_imputed_sqm保存训练均值填补后的演示输入；area_sqm仍保留原观测与缺失。距离未匹配保留缺失，不猜值。

## 审计边界

脚本读取原始文件，不覆盖它们。清洗日志记录去掉的复制、首尾空格变化和缺失标记解释。决策日志记录复挂牌保留、确认登记册依据、未匹配事件保留、大面积保留及训练均值范围。未知数值文本或冲突事件编号触发错误。两次运行应得到相同衍生表与摘要。
