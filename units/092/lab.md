# 092 实验：同预算下比较普通CNN与残差CNN

## 研究问题

保持所有卷积和线性参数、初始化、batch顺序、学习率与更新次数相同，仅增加恒等旁路，观察优化轨迹、最终分类与CPU成本。预先声明结果可能持平；不以“残差必须赢”作为成功标准。

## 环境与复现

Python、numpy、torch、matplotlib，CPU单线程，float32，无外部数据或在线服务。

```bash
python test_experiment.py
python experiment.py
```

程序内固定数据种子920/921和模型种子0/1/2。outputs/results.json保存资源和最终指标，history.json保存六条完整曲线，三幅图保存在figures。重复运行会更新结果和计时，不会修改模型结构。

## 1 数据审计

读取data：先建立平衡标签，再打乱标签，独立生成噪声，最后按标签添加水平/垂直线。线中心在[3,8]整数范围、长度5，图像12×12，避免初始短线被边界截断。训练384张、测试256张，来自不同随机种子但同一机制。不要把生成器的独立样本说成真实世界外推证据。

## 2 结构手算

逐层标出NCHW形状，推导1266参数与176,272 MAC。确认两模型的state_dict可以完全互相加载，因为参数结构相同。residual布尔值只决定z+h还是z，既不增加卷积也不改变激活顺序。

## 3 配对协议

每个种子先生成初始参数模板与120×32的样本索引表，两个模型分别加载模板并使用同一表。每次训练3840个样本位置。选择Adam、学习率0.01、120步是预设教学配置，没有根据测试集挑选最好配置。若增加超参数搜索，须自行划验证集。

## 4 运行和解读

六次原始测试及右移一像素测试均为100%，因此此任务的准确率饱和。请继续读训练曲线、预测概率变化和延迟。seed0普通模型最后batch损失约0.116，残差约0.000358，但两者均100%测试准确率；只看硬标签会掩盖置信度差异，而只看一个batch的损失也不足以判断整体概率质量。

时间测量包括：训练循环墙钟；推理预热20次，再测batch1的100次延迟并报告中位数与p90。关闭自动求导、单线程。不要把约0.055毫秒这一本地值当所有CPU的速度。

## 5 反例与扩展

手算[0,1,0,2,0,0]的stride2最大池化，并循环平移一位重算。它是无条件平移不变的反例。再观察真实测试右移后概率变化，解释为何准确率不变仍不足以证明严格不变。

扩展实验可加入池化、多尺度或投影残差，每次只改一类因素。为每个新结构重新计算参数/MAC，指定固定步数还是固定时间预算。若困难度太低，预先设计更大噪声或不同长度测试，不要为得到残差胜出而只挑有利种子。
