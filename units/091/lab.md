# 091 实验：让卷积的每一条路径都有证据

## 目标与环境

用NumPy逐循环实现互相关及反向传播，再与PyTorch CPU双精度结果和中央差分核验。依赖Python、numpy、torch、matplotlib；无需联网运行。数据是程序内原创小数组，不含真实个人数据。运行命令：

```bash
python experiment.py
python test_experiment.py
```

脚本用自身路径定位输出，因此从任何目录启动都可。设置MPLCONFIGDIR到可写缓存目录可以避免字体缓存警告。不要把测试通过理解为支持所有卷积选项：本实现不支持groups、dilation、非对称padding、转置卷积。

## A 先写下预测

1. 不运行代码，算出3×3数列图与2×2核[[1,0],[0,-1]]的结果。
2. 预测批量2、输入通道2、图像5×6、输出通道3、核3×2，在三组(stride,padding)=(1,0)、(1,1)、(2,1)下的输出形状。
3. 给出全1输入和核的重叠反传图。

## B 逐段阅读实现

corr2d中xp是补边后的数组；patch只包含当前窗口，而w[q]在所有空间位置复用。输出dtype由输入、权重、偏置共同确定。backward先建立与xp同形的梯度，逐窗口累加，再裁掉补边。db沿样本和空间轴求和，但保留输出通道轴。

在审计段，torch.tensor使用NumPy float64数组，因此框架也采用双精度。每个输出乘一个随机上游梯度后求和，形成标量损失。请在纸上说明这个标量对输出的梯度为何恰好等于dy。

## C 真正运行与记录

程序生成outputs/results.json和三幅PNG。基准执行中，前向/反传最大绝对差约10^-15，中央差分最大误差约1.57×10^-9，全部通过10^-7门槛。你自己的浮点末位可能略有差异；如超门槛，优先检查轴顺序、窗口起点、+=以及padding裁剪。

图1核验手算，图2核验感受野支持集9与25个像素，图3核验边界条件。循环补边与循环平移匹配时误差应接近零；零补边与循环平移不匹配时边界附近可以出现误差。

## D 故意破坏再定位

复制代码后把dxp累加改为覆盖。运行test_overlap，预期中心值4不再正确。再把w沿两个空间轴翻转，观察手算输出变为+4而非-4。将padding=0时的特殊裁剪删除，观察返回空数组的风险。每次只改一个地方，保存失败断言，再恢复正确实现。
