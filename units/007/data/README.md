# 固定的原始合成材料

houses.csv 为 60 套彼此独立生成的教学房屋，每行唯一 house_id、面积平方米、合成价格万元。面积用 NumPy Generator(seed=20261004) 在40至100的整数中抽取；噪声在-8至8的整数中抽取；价格为2×面积+10+噪声。先批量生成全部面积，再批量生成全部噪声。无真实房屋、个人或市场信息。

split.csv 用独立 seed=7 的排列指定36条训练、12条验证、12条测试，角色通过稳定编号对应，不依赖当前行顺序。随机划分适用于本例刻意构造的独立数据，不是所有真实问题的建议。

正常复跑直接读取固定文件。generate_data.py 可以在新目录重建来源，不覆盖本目录；相同种子仍需结合生成器、版本与调用顺序解释。公开测试标签用于流程教学，不提供现实盲测保证。
