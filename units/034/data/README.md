# 第034讲合成输入

labels.csv含4个原创数学标签−2、0、1、5。模型对所有行预测同一参数w，单行损失(w−y)²/2，训练目标为四行平均。最优均值1，最小目标13/4，均匀单样本梯度噪声方差13/2。它用于隔离抽样机制，不是现实回归准确率数据。

model_spec.json明确初值、固定学习率、递减学习率偏移、样本梯度预算、独立重复数、根种子、batch大小、手算索引和有限重要性抽样检查概率。概率只是一次枚举检查，不自动改变主实验均匀抽样。手算索引使用1起始编号，程序内部必须明确转换为0起始。

样本梯度预算按每批实际处理的行数累计；整批预算不足时不应静默超支。不同方法对相同预算允许不同更新次数。放回抽样B=4仍可能重复，不能标为full-batch。
