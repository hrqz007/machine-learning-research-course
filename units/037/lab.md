## 1 实验目标与独立入口

本实验从同一4×2合成设计实现近端梯度、固定步长次梯度、循环坐标下降，再单独求光滑盒约束问题。验收对象是完整计算链、稀疏性和最优性残差。没有划分训练测试集；不要把最终训练目标称作预测精度或模型泛化能力。

先修是矩阵乘法、链式法则和全批梯度。先读数据字典，再手算两轮，最后运行程序。lecture.pdf解释理论；本指南独立给出运行命令、预期值和故障定位；answers.pdf包含20题解答。

## 2 环境与运行

核心实际核验环境为Python3.12.14、NumPy2.3.5、Matplotlib3.10.8。requirements.txt包含Notebook所需nbformat5.11.1及ipykernel7.4.0；environment.yml提供可选环境声明。库对照另需requirements-library.txt中的scikit-learn1.8.0和SciPy1.17.0。安装环境不等于实验已通过，仍须执行下面的检查。

```bash
python -m pip install -r requirements.txt
python experiment.py --output-dir outputs
```

在本单元目录启动Jupyter并打开experiment.ipynb，重启内核，从第一格向下执行。Notebook第一格必须先校验默认数据、配置和两个核心脚本的SHA，任何数值输出或图之前不允许绕过它。若需自定义数据，用CLI传入单独的CSV/JSON，不改Notebook的默认契约来掩盖变化。

```bash
python experiment.py --data my_data.csv --config my_spec.json --output-dir custom_outputs
python -m pip install -r requirements-library.txt
python library_check.py --output-dir library_outputs
```

完整report.json含每轮旧前向、试探点、分支、同步新前向、诊断与停止原因。图片可用python build_assets.py重新计算，但脚本会替换本单元figures中的教学图片；普通运行不需要执行这条构建命令。

## 3 固定数据与模型

CSV列顺序必须为id,x1,x2,y。四行是(−1,−1,−1.75)、(−1,1,−2.25)、(1,−1,1.25)、(1,1,2.75)。θ=(θ1,θ2)，预测x1θ1+x2θ2，没有截距。

目标$f=\sum_i r_i^2/8$、$J=f+\lambda(|\theta_1|+|\theta_2|)$。固定λ=0.5、η=0.5、θ⁰=(0,0.5)、最多80轮、KKT无穷范数容差10⁻¹⁰。数据的正交闭式只用作独立参照，不在程序更新中代替逐行梯度。

第一项纸笔验收：算出XᵀX/4=I、Xᵀy/4=(2,1/4)，并验证f=1/8+(θ1−2)²/2+(θ2−1/4)²/2。若得到两倍梯度，先查有没有把1/(2n)漏写成1/n。

## 4 第一轮逐行重建

旧参数(0,1/2)，对每一行写五步：预测→残差→r²/2→两个局部导数x1、x2→平均梯度分项rxj/4。每行公共导数还有∂ℓ/∂r=r与∂r/∂预测=1。

|行|预测|残差|半平方|梯度分项1|梯度分项2|
|---|---:|---:|---:|---:|---:|
|s1|−1/2|5/4|25/32|−5/16|−5/16|
|s2|1/2|11/4|121/32|−11/16|11/16|
|s3|−1/2|−7/4|49/32|−7/16|7/16|
|s4|1/2|−9/4|81/32|−9/16|−9/16|

分项相加g=(−2,1/4)，z=(1,3/8)，τ=1/4。两个z均大于τ，所以θ¹=(3/4,1/8)。更新后全部新预测为(−7/8,−5/8,5/8,7/8)，新残差(7/8,13/8,−5/8,−15/8)，新半平方(49,169,25,225)/128。它们的平均为117/128，加入7/16惩罚后J₁=173/128。

## 5 第二轮逐行重建

本轮旧残差就是上节的新残差。对θ1的梯度分项(−7,−13,−5,−15)/32，和−5/4；对θ2的分项(−7,13,5,−15)/32，和−1/8。所有局部导数仍按每行原始x1、x2乘入，平均因子只用一次。

z=(11/8,3/16)，阈值仍为1/4。第一坐标取11/8−1/4=9/8；第二坐标落在阈值闭区间内，取精确0。同步写θ²=(9/8,0)。

|行|新预测|新残差|新半平方|
|---|---:|---:|---:|
|s1|−9/8|5/8|25/128|
|s2|−9/8|9/8|81/128|
|s3|9/8|−1/8|1/128|
|s4|9/8|−13/8|169/128|

平均数据损失69/128，惩罚9/16，J₂=141/128。每个分数都由Fraction独立重算；不要把表中舍入小数重新输入迭代。

## 6 读取完整轨迹而非只看最终参数

在report的paths.proximal中，trace是完整成功更新列表，completed_updates是其长度，attempted_updates还包括尝试但因算术范围停止的那一步。status明确区分tolerance_satisfied、fixed_budget_completed、arithmetic_range_stop。

检查每个trace条目的old_forward.theta是否等于前一个new_forward.theta；确认第一项old_forward来自initial_forward。全部半平方求平均应等于data_loss；正则项单列；objective应等于两者之和。到达零的第二坐标必须来自zero分支，不能来自人为近零截断。

主例理论最优θ*=(1.5,0)，J*=1.03125。近端路径在达到容差时停止，默认第34次更新满足；坐标法第1次完整扫描满足；次梯度方法80次预算结束仍有残差。这些步数依赖容差、浮点路径与配置，不是普遍性能结论。请以实际status与completed_updates核实它们。

## 7 正确阅读三种最优性诊断

θ¹处Lasso KKT向量(−0.75,0.375)，近端映射(−0.75,0.25)。θ²处KKT无穷范数0.375；零坐标已合格，但非零坐标还未合格。最优点的光滑梯度无穷范数0.5，不应把它设为停止阈值。

默认数据有独立闭式最优值，所以报告default_objective_gap；自定义数据返回null，不能把null补成0。报告用稳定的展开式计算默认目标差，避免直接相减接近的J和J*丢掉微小差异。图中对数坐标对零值设显示下限；原数据并未改写。

## 8 投影与坐标下降的对照

投影路径优化f over [0,1]²，不是Lasso J。第一步(1,3/8)，第二步(1,5/16)，极限(1,1/4)。图中梯度范数最终接近1是正确现象；projected_mapping_inf和box_violation才是停止诊断。

循环坐标下降按[0,1]依次更新；第二坐标使用第一坐标新值。主数据正交，第一次扫描就给(1.5,0)。在独立标记的相关设计中，比较order=[0,1]与[1,0]，记录每个坐标的partial_response、q、c和新参数。不要只比较一整轮的终点而丢掉顺序证据。

## 9 失败实验要改一个明确因素

实验A保留主X、y、λ，另令θ⁰=(0,0)、η=3。手算并运行第一次近端更新应得到(4.5,0)，J由69/32升到177/32。此时η>1/L，不能套用本讲的充分下降条件。

实验B保留默认设置，查看次梯度路径第二系数反复跨过0。sign(0)=0只是合法选择，不等于KKT停机；使用原参数精确零计数，而不是把很小系数都涂成0。

实验C把第二列变成ρx1+(1−ρ)x2，ρ=7/8。程序以单独stress区块保存新设计，并记录新L与近端η。主实验33/32最优值不自动适用。该次变换恰好仍有(1.5,0)作为Lasso最优点，可用KKT独立证明；报告仍不套用只对原数据推导的闭式目标差。

## 11 真实库与Notebook的核验边界

实际scikit-learn1.8.0使用alpha=0.5、fit_intercept=False、selection='cyclic'、tol=10⁻¹²、max_iter=10000、positive=False。目标缩放与本讲1/(2n)完全对齐。主设计与相关设计均实际运行，记录coef_、n_iter_、dual_gap_及我们重新计算的KKT残差。库默认从零开始，我们的坐标法从(0,0.5)开始，所以不声称所有中间迭代相同。

Notebook通过新Python进程中新建真实IPython InProcessKernel逐格执行，8幅输出图由代码重新计算并内嵌，而非复制预生成PNG。此路线不测试浏览器Jupyter UI或socket内核传输。独立作者核验包括普通与−O进程、两个cwd、合法数据篡改首格失败，以及输入末字段哨兵。独立外部复核状态单独管理，不把作者自检称为独立验收。
