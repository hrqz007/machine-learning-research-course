# 原创合成数据字典

regression.csv为本讲独立设计的4行教学数据，不来自真实个人、机构或测量记录。每行代表一条无量纲合成回归样本。没有训练测试划分，不支持泛化或因果主张。

|字段|类型与单位|意义|
|---|---|---|
|id|不重复非空字符串|s1至s4，按文件顺序追踪|
|x1|有限实数，无量纲|第一特征，−1、−1、1、1|
|x2|有限实数，无量纲|第二特征，−1、1、−1、1|
|y|有限实数，无量纲|−7/4、−9/4、5/4、11/4|

所有列都有固定含义，列顺序严格为id,x1,x2,y。无缺失、无重复id、无截距列。y=2x1+x2/4+z/2，其中z=(1,−1,−1,1)，三列两两正交。文件小数均是二进制可精确表示的dyadic数；一般自定义十进制不会自动具有此性质。

model_spec.json的kind固定问题类型；initial_parameters是长度2的旧θ；steps是最大更新预算；learning_rate是η；lambda是λ，目标为Σr²/(2n)+λΣ|θj|；tolerance是停止残差无穷范数上限；lower_bounds、upper_bounds定义单独光滑投影实验的盒；coordinate_order用从0编号的坐标顺序；stress_rho定义单独压力设计第二列rho*x1+(1-rho)*x2。

默认值：(0,0.5)、80轮、η=0.5、λ=0.5、容差1e-10、盒[0,1]²、顺序[0,1]、rho=0.875。所有配置字段都要提供，未知/重复字段拒绝。完整数值范围见README和lab。

压力设计不覆盖regression.csv，它完整保存于运行报告stress.data。主设计的闭式目标差只在数据逐值匹配时提供；压力设计返回null，不借用主例证明。
