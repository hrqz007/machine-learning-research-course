# 一级资料

2026-10-08重新读取。推导、手算及数据均为本单元原创。

1. [scikit-learn 1.8 PCA方法](https://scikit-learn.org/1.8/modules/decomposition.html#pca)：PCA中心化但不自动标准化，fit/transform工作流。
2. [scikit-learn 1.8 PCA API](https://scikit-learn.org/1.8/modules/generated/sklearn.decomposition.PCA.html)：components、explained_variance与full SVD求解器。
3. [NumPy SVD官方API](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)：U、s、Vh的形状与分解关系。
4. [NumPy eigh官方API](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html)：对称矩阵特征分解及升序返回约定。

NumPy在线stable文档可能更新；本实验实际固定NumPy2.3.5，scikit-learn1.8.0，所有代数与库核验以真实运行报告为准。
