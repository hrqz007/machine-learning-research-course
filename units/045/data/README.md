# 已知条件概率的原创教学数据

posteriors.csv的一行是一个条件组，不是已经标好标签的单个观察。p_positive给P(Y=1|该组)，weight给该组在已定义总体中的比例；八组各1/8。代价规则可以在已知概率上被精确核验，但不能由此估计现实模型校准或泛化。

label_shift.csv每列分别表示P(X|Y=0)或P(X|Y=1)，沿三个X组求和为1。该CSV的概率条件方向与主CSV不同。来源/目标类别先验由decision_spec.json给出，类条件表保持不变。

decision_spec.json预先固定主代价FP1/FN3、拒绝费3/8、六组成本、九个阈值、两个先验、三类例子、模拟种子4505和每组256个标签。模拟是脚本现场重建的独立Bernoulli结果；三政策使用同一标签，不根据标签挑阈值。

全部表格、概率和机制为原创，未使用个人数据或外部数据集。默认CLI检查data_integrity.json。改实验时先复制输入并显式传--data、--shift和--config，保留原教学契约。
