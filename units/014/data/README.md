# 第十四讲数据

`observations.csv` 有表头 `record_id,x,y`，3条原创合成无量纲记录：R01对应(0,1)，R02对应(1,2)，R03对应(2,2)。每行是一条固定观察，不是一个参数坐标。

两个参数 a、b 在实验中变化，数据 x、y 和平均中的记录数保持固定。预测式为 `p_i = a*x_i + b*b`。数据不是由某个宣称已知的真实概率模型抽样得到，也没有训练/测试划分；用途是核查导数计算、矩阵形状和数值边界。

记录ID需非空且唯一。读取CSV时显式将数值字段从文字解析成实数。核心数学函数另外拒绝隐式布尔、字符串、复数与object输入，防止广播或类型转换掩盖错误。
