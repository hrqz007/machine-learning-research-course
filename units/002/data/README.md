# 合成挂牌教学数据

raw_events.csv 包含 11 个导出行和 17 个字段，按 event_id 对应 10 个挂牌事件。R02 为 E01 的重复导出，H01 在两个不同日期发生两次挂牌。所有编号、房屋、日期和金额均为人为构造，不含真实市场或个人资料。

expected_labels.csv 保存截至 2025-04-20 按本讲约定可得的标准答案。空白标签表示未知，不能转换成 0。它用于程序与手算核验，不是训练数据。

字段含义、单位、来源、可用时间、空白意义与角色，详见本单元 answers.pdf 或 answers.md 的完整数据字典。程序只读这两个文件，不联网下载数据。
