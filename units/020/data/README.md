# 合成数据说明

本单元没有真实人员、设备或业务记录。所有数据在CPU本地由experiment.py生成，不联网、不下载、不含个人信息。model_spec.json是本版本生成设定的可读副本；运行逻辑使用experiment.py中显式参数，脚本不把该JSON当成动态配置。修改模型时同时更新设定和说明。

synthetic_preview.csv是固定种子下最初20行，供检查列含义和格式，不用于估计总体矩。完整12000行由脚本写到所选结果目录的synthetic_samples.csv。不同分布列是分别生成的教学样本，同行索引不代表同一真实对象；不能从这些列之间的相关性推断现实机制。

- bernoulli：报警指示0或1，成功概率1/4，种子20001
- binomial：一批8次独立同概率试验的成功数，p=1/4，种子20002
- categorical：互斥类别索引0=A、1=B、2=C，概率1/2、3/10、1/5，种子20003；编号没有自然距离
- poisson：等暴露窗口计数，λ=4，种子20004
- gaussian：无量纲测量误差，μ=1、方差v=4、标准差2，种子20005
- mixture：先按各1/2选择强度1或7，再从对应Poisson生成；分组种子20006，两个候选计数流种子20106、20206
- mixture_group：0对应λ=1，1对应λ=7；这是合成生成时已知的组，不是从结果倒推的标签

随机数引擎为NumPy Generator(PCG64)。固定种子与固定NumPy版本用于本课程复现，不保证跨版本位级相同。理论均值和方差由正文推导，合成样本不会被人为修正以匹配理论矩。

另有Poisson(4)的120批重复，每种规模40、400、4000各40批。种子202000+100×规模+重复编号，编号0到39；全部统计量保留在运行报告中。不存在挑选种子、封存测试泄漏、真实系统基准或泛化性能声称。
