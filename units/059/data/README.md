# 原创合成数据

固定种子59059，生成900个独立对象。四列输入原先为独立标准正态，再将x2替换为x0加标准差0.22的独立正态噪声。x0、x1定义标签概率：x0≤−0.3为0.10；其余中x1>0.25为0.82，否则0.36。按概率独立生成伯努利标签。

前450行训练，后225行验证，最后225行测试。row_id为生成行号；x0至x3为输入；y为0/1标签；true_probability为已知合成机制，仅作教学解释，禁止当作输入。x2与x0相关，但不包含未来标签。CSV保留17位有效数字。

本数据为原创模拟，不含真实人物、机构或设备数据，没有外部数据许可依赖。它用于隔离树复杂度与扰动敏感性，不代表现实任务效果。独立行划分由生成机制支持，不能推广到群组或时间数据。

重建到新目录：python generate_data.py --directory outputs/new-data。生成器拒绝直接覆盖发布data目录。默认种子和分布写于generation.json，运行时不联网。experiment-result.json记录三个CSV的SHA256。
