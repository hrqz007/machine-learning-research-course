# 本讲原创合成数据

数据不涉及真实人物或现实业务。所有CSV为UTF-8文本，首行为列名，浮点数用17位有效数字保存；无缺失值、无外部下载和许可依赖。generate_data.py以NumPy default_rng(58058)在固定调用顺序下生成全部四张表。

## 分类

classification_train.csv：320行；classification_test.csv：160行。字段x0、x1为独立Uniform(−2,2)数值，y为0/1。条件概率在x0≤0时为0.12；否则x1≤0.35时为0.30，其余为0.88。标签按Bernoulli条件分布抽样。

先产生480行后按固定行序取前320行训练、末160行测试。每行是新的独立合成对象，不是同一对象的重复记录。模型只能使用x0、x1；生成器的真实概率用于教学图，不作为模型特征。

## 回归

regression_train.csv：240行；regression_test.csv：120行。x0为Uniform(−3,3)，y为分段均值加独立Normal(0,0.35²)噪声。均值在x0≤−1时−1，−1<x0≤1时2，x0>1时0.5。

回归数据沿用同一个随机数发生器，在分类数据之后生成。重建时应执行整个生成器，不能从同一个种子直接跳到回归段而期待得到相同数值。

## 研究协议

三个模型固定max_depth=2与min_samples_leaf=12；分类使用gini、entropy两个预定机制演示，回归使用squared_error。先拟合训练数据、冻结模型和协议，再读取测试文件报告结果。测试不承担模型选择任务。数据文件本身可读，流程约束不等于访问控制。

重新生成请使用新目录，例如python generate_data.py --directory outputs/new-data。原始data目录禁止由生成器覆盖。除最后的测试评价外，树的任何均值、频率、分裂和基线都只来自训练行。
