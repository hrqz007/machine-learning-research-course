# 第058讲 独立实验指南

## 1 实验问题和完成标准

本次要从零训练一棵浅树，并让每个分裂、每个叶子和每个边界判断都能独立核验。主问题是分裂机制是否实现正确，不是寻找最高测试分数。不要在看到测试结果后修改深度、叶样本数、种子或数据生成分布，再把新分数称为原协议的确认结果。

交付四样东西：一份手算候选表；一次真实执行的Notebook或脚本结果；普通与优化模式的独立测试记录；一页解释报告，写清树能解释什么、不能解释什么。建议按“先预测结果、再运行、再解释差异”的顺序学习。

本包附带全部合成CSV，不需要下载数据或注册账号。训练/测试分割固定：分类320/160行，回归240/120行。文件data/README.md说明字段与生成机制，generate_data.py可以在新目录重建。不要用测试数据拟合叶子均值或决定阈值。

## 2 环境与最短运行路径

推荐在Anaconda Prompt或终端进入本讲目录，再创建独立环境：

```bash
conda env create -f environment.yml
conda activate ml058
python experiment.py --out outputs/result.json
python test_experiment.py --report outputs/result.json --out outputs/test.json
python -O test_experiment.py --report outputs/result.json --out outputs/test-O.json
python plots.py --report outputs/result.json --directory outputs/figures
```

如果已用Python 3.11建立虚拟环境，可以执行python -m pip install -r requirements.txt。依赖版本锁定便于核验，但本次没有实际建立第二套全新Conda安装；作者执行环境的版本和未测试项目如实写入verification.json。

普通模式与-O模式都应通过284项检查。后者会移除Python的assert语句，所以本讲的关键检查使用显式异常，不能靠被优化移除的assert维持正确性。

PDF重建是可选步骤，另需build-requirements.txt列出的排版依赖、Node.js与本目录package.json中的MathJax。数值实验不依赖PDF工具。完整重建命令在README.md；不想重排版也可以直接阅读已经验收的三份PDF。

## 3 Notebook应怎样运行

打开experiment.ipynb，选择已安装上述依赖的Python内核。先重启内核，再从上到下运行全部单元。第一个单元检查工作目录，随后重新执行实验、审计并生成图，最后把图像嵌入输出，不依赖上次会话留下的变量。

也可以在一个新Python进程里顺序执行：

```bash
python execute_notebook.py --out outputs/fresh-kernel.ipynb
```

这个脚本使用真实IPython InProcessKernel。作者已实际执行，文件包含输出和图片；Jupyter浏览器界面与外进程socket内核通信没有因此自动得到验证。

遇到ModuleNotFoundError，先确认Notebook选中的内核与安装依赖的环境一致。遇到找不到data文件，先确认当前目录是units/058或其父仓库根目录。不要把错误吞掉后继续截图当作成功。

## 4 练习A：先在纸上决定怎么切

题1：一列输入为1、1、3、5、5。写出所有能产生不同非空训练分组的中点候选。阈值1.5与2是否对应不同训练分组？为什么相同输入不能按行号被分到两边？

题2：输入1至6、二分类标签0、0、1、0、1、1。分别对五个候选计算左/右样本数、正类比例、加权Gini与减少量。不要只报告最佳候选。写出并列最优时本讲选择哪个阈值。

题3：沿用题2，计算阈值2.5的熵信息增益，保留6位小数。说明若评价代码使用自然对数，如何与bit单位结果换算。

题4：回归标签1、2、2、8、9、8对应输入1至6。推导叶子均值最小化平方误差；算父平均平方误差、阈值3.5的两个叶值、分裂后误差与减少量。说明为什么此处方差分母是n而不是n−1。

题5：父节点10行、正负各5。分裂A的左右组分别是“0正2负”和“5正3负”；分裂B分别是“4正1负”和“1正4负”。正确加权法和错误简单平均法各选哪个？解释错误的根源。

提示：题2至4可与图中的候选收益核对，但应保留你自己的计算。题5没有调用树训练器，是为检验目标函数理解而设。

## 5 练习B：检查每个节点的证据

运行实验后，打开experiment-result.json或你自己的输出，找到models.gini.nodes。节点0是根，节点2、3、5、6是叶子。列表里的train_indices是该节点所包含的训练行，顺序与分类训练CSV的行序一致，编号从0开始。

题6：写出四个叶子的样本数、正类数、正类频率和最终类别；把叶样本数加总，检查是否为320。对一个查询(1,1)，写出依次检查的两个条件和最后预测。对(−1,1)重复一次。

题7：查看根、左子节点与右子节点的局部Gini收益。算每个节点对整棵树目标的贡献，验证“父不纯度减叶子加权不纯度”等于这些贡献之和。解释为什么不能直接把三个局部收益相加。

题8：对训练输入0、2和标签0、1训练深度1的树。用np.nextafter生成阈值左邻数、阈值本身、右邻数。记录三个预测，并说明为什么测试库模型时要考虑float32转换。

## 6 练习C：限制与故障注入

题9：画出四点XOR。计算两种根分裂的立即Gini收益；解释本实现为什么停下。再写一棵深度2的条件判断程序，对四点全部预测正确。你的结论能否推广成“任何决策树都无法拟合XOR”？

题10：把报告复制到outputs/tampered.json，只将Gini测试准确率改成1，保留其他字段。对这份副本运行test_experiment.py，记录非零退出与具体失败项。不要改动发布版报告，更不要为了通过检查删掉失败断言。

题11：分别给tree.py输入缺失值、非法类别2、错误特征数、负深度和空数组。为什么应当显式拒绝？再说明“输入特征缩放后预测永远完全相同”为什么是过强的承诺。

题12：用不超过250字总结本次结果，必须包含固定协议、分类与回归的基线、库对照、测试未参与选择的边界、一个算法限制和一个因果解释限制。不要把合成数据的分数描述成现实业务性能。

## 7 预期结果与判读

分类Gini与熵浅树都得到0.768750测试准确率，训练多数类基线0.643750。回归浅树测试MSE约0.146755379，训练均值基线约1.831889079。两种分类与库预测一致；回归最大预测差在 $10^{-15}$ 量级。

差异大于预期时，依次核查：是否读了正确的CSV；是否只用训练行；是否把“≤”写成“<”；是否按样本数加权；是否误用n−1；是否把根深度当成1；是否在平局时用了另一套规则。不要一开始就用更多随机种子把问题平均掉。

本次确认性材料只说明固定教学程序的复现与计算机制。改变深度、种子、分布可以作为扩展探索，但要另存目录、说明变化，不覆盖原报告。复杂度的验证选择、剪枝与稳定性分析不是本讲的验收项目。
