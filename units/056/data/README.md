# ML056 数据字典

固定seed5600原创合成数据，无外部个人数据和下载。development.csv有1200行，test.csv有600行。逗号分隔，首行为列名。生成器把前1200个独立抽样行固定为开发集，其余为最终测试，不强制测试类别比例。

- row_id：全局唯一整数，开发0至1199、测试1200至1799
- x0：标准正态加0.7×group，输入列
- x1：标准正态，输入列
- x2：40倍标准正态，约8%独立NaN，输入列，真实概率不依赖它
- group：Bernoulli(0.4)，只用于预定错误分析，不是重复实体ID
- y：由lecture.md中的概率式抽取的0/1标签

protocol.json在分析代码中固定主指标、候选、阈值、种子、分组和成功判据。这是教学分析计划，不是外部登记的预注册。generate_data.py默认重建到outputs/generated-data，不覆盖本数据。
