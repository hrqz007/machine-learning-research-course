# 第056讲 实验 可信分类项目交付

## 实验目的与边界

你将从固定数据完成一套分类研究报告：6个模型候选、5个阈值、三折嵌套验证、一个先验基线、一次最终测试、配对区间及两个预定子群的错误分析。本文件可独立使用，所需定义、命令与验收标准都在这里。

数据是合成的独立行，不对应真实个人。1800行中开发1200、最终测试600。输入x0、x1、x2；group只用于错误分析；y为0或1。仅x2允许NaN。漏判成本4、误报成本1。p≥t判1，平均成本(4FN+FP)/N为唯一主指标。读完固定data/protocol.json后再运行，不用测试数据修改任务。

## 1 安装和文件定位

建议Python3.12，新建虚拟环境或使用environment.yml中的Conda环境。在本讲目录运行：

```bash
python -m pip install -r requirements.txt
python experiment.py --out outputs/my-result.json
python test_experiment.py --report outputs/my-result.json
python plots.py --report outputs/my-result.json --directory outputs/my-figures
python execute_notebook.py --out outputs/my-notebook.ipynb
```

CPU即可，不需要GPU、付费API、登录或联网下载数据。首次安装软件需要网络，之后数值实验离线完成。默认数据按脚本所在目录定位，显式输出路径按当前工作目录解析。Notebook执行器启动一个新的Python进程中的真实IPython进程内内核，不是只填入执行序号；它不验证浏览器Jupyter界面或外部socket传输。

requirements.txt只包含数值实验与Notebook依赖。PDF重建另需build-requirements.txt、Node.js、npm install及Noto CJK字体。bash build_all.sh写到outputs/rebuild，不替换原交付物。不要把缺少可选PDF渲染依赖误报为模型实验失败。

## 2 先写下你预期会看到什么

不运行模型前，回答三个问题并保存预测：二阶交互能否改善本例？标准化是否应该从全部1800行计算？较低阈值可能如何同时改变FN和FP？这些是学习者假设，不是应被实验强行满足的答案。

练习A：五行标签(1,1,0,0,1)，概率(0.1,0.2,0.3,0.0,0.9)。分别算t=0.2和t=0.5时的计数与成本。说明等于阈值如何处理，以及为什么概率评价不随阈值变化。

练习B：解释为什么把“用全数据填补中位数”改成“只在开发集填补”仍未完全修复内层交叉验证泄漏。精确指出内层一轮允许看到哪些行。

## 3 跟踪一次嵌套验证

打开experiment.py，从develop追踪到select。对外层第0折，记录train_ids与valid_ids数量；在selection.ledger第0候选中查三个内层fits。验证每个内层训练和验证集合不重叠，内层所有ID都属于外层训练。

练习C：手工计算训练次数。一个候选在一个内层三折中训练几次？选择阈值会增加训练吗？三次外层重拟合加一次最终重拟合后，总训练数是多少？请避免把候选阈值评分次数混成模型数。

OOF意为每行概率来自没有拟合该行的模型。整个候选的OOF向量仍被用于选择候选，因此其最低成本不能当作无偏最终结果。练习D：设计一个会错误使用外层验证信息的修改，并用文字指出它破坏了哪一层边界；不要修改封存数据来制造更好的分数。

## 4 审计而不是只读输出

运行test_experiment.py。它根据训练ID重新计算中位数、均值和尺度，并根据保存的幂次、系数和截距重新算OOF概率。报告应含72次内层参数核对、76次总拟合、120条阈值评分。

练习E：复制outputs/my-result.json到另一个输出文件，把其中一个内层训练中位数加1，再运行审计。预期应失败。保留原始交付结果，不能为了“测试通过”更改审计容差。测试失败后解释错误信息属于概率重建还是训练统计检查。

审计能发现程序中明确编码的错误，不证明无遗漏。对真实研究仍需核实数据来源、抽样、标签时间、重复实体、特征可用时间和项目动机。

## 5 阅读最终测试及负结果

预期所选degree=2、C=0.1、t=0.2。最终TP239、FN11、FP241、TN109；成本0.475、准确率0.58、召回0.956。基线成本0.583333。数值浮点末位可有极小差别，计数应一致。

练习F：若有人只汇报“召回95.6%”，请补一段不可省略的错误分析。再计算预测为正的行数，以及每复核一个预测正例中大约有多少比例实际为负。不要把教学成本单位写成人民币。

练习G：从test里的bootstrap_distribution求2.5%和97.5%分位点，与保存的paired_bootstrap_95核对。说明为何必须配对，以及这个区间没有重新训练模型。

## 7 写出能被质疑的结论
