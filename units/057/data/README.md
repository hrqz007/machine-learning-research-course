# ML057 数据字典与固定协议

原创合成数据，seed5700。没有个人数据或外部下载。generate_data.py默认生成新目录，避免覆盖本包基准。

- X：shape(900,2)。先生成独立u、v均匀分布于[-2,2]，标签生成后第二列乘40，因此X=(u,40v)。
- y：shape(900,)。先取v>0.55*sin(2u)的0/1指标，再独立以0.10概率翻转。
- noise：shape(900,20)，标准正态，与信号和标签独立。维数对照使用同一矩阵的列前缀。
- xr：shape(380,)，均匀分布[-3,3]；yr=sin(2*xr)+N(0,0.3^2)。

分类前360行训练，接着180行验证，最后360行测试；回归分别100、80、200行。特征和标签一起按原行索引切分，行之间独立。分类所有缩放器只fit前360行。k候选1、5、21、61，每条固定路线按验证指标最小选择，相同时选小k；不合并训练和验证重新fit。所有路线预定并全部报告，不按测试挑部署赢家。

另一个seed5790偏差方差实验独立抽40份80行训练数据，在固定101点网格预测；全预测矩阵保存在结果JSON中，误差目标是真实均值而非新含噪标签。维数对照固定k=21、等权，其首条测试点距离比是单查询描述。protocol.json提供机器可读摘要。
