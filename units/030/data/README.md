# 第030讲 数据与配置

cases.csv是课程原创确定性合成数据，未对应真实人、仪器或生产任务。无外部下载、账号、隐私或许可证附加要求；不代表对外部教材或软件重新授予版权许可。

字段必须按case,id,x,y顺序出现。case为hand、constant或changed_sample；id是全文件唯一的字母加数字标识；x输入单位N，y输出单位V。每组2至2000行。程序会检查所有行，包括焦点未选中组和最后一行。

- hand：x=0,1,2,3,4；y=1,2,2,4,6。与第028讲手算数据相同；闭式参数(3/5,6/5)，J*=4/25。
- constant：x=2,2,2；y=1,2,4。最优集合a+2b=7/3，J*=7/9；参数非唯一。
- changed_sample：x=0,1,2,3,4；y=1,2,3,5,6。展示观测变化后样本最优也变化；闭式参数(4/5,13/10)，J*=3/100。这不是从统计分布抽到的大样本实验。

model_spec.json的字段如下：

- focus_case：重点分析场景，未选中数据仍必须合法
- paths：1至12条路径；每条严格含name、initial、step、max_steps、gradient_tolerance
- name：字母开头、最多32位的小写字母数字下划线名称；不同路径名称不重复
- initial：顺序为[a,b]的两个有限普通实数
- step：10⁻⁸至1，max_steps：0至10000整数，gradient_tolerance：10⁻¹²至1
- candidate_parameters：1至30组[a,b]，最后一组也必须验证
- slope_upper：半平面约束b≤上界；默认1
- grid：递增的a_bounds和b_bounds，以及5至201的整数points；每轴点数相同

数值输入绝对值最多10⁶，非零至少10⁻¹⁰⁰。JSON不允许重复键、额外字段、NaN、Infinity或用布尔值代替数字。CSV数字不允许空白、千分位或单位后缀。1e-400在原始词元阶段拒绝；0e-400按真正零接受。具体内部计算限制见README.md。

正文和Notebook的总体风险图使用另一个显式教学机制：X在0..4上均匀取值，条件均值为1+X，条件噪声方差1/4。它是为了独立定义风险，不由hand拟合参数估计，也不在运行中抽样。因此这一实验不使用RNG。
