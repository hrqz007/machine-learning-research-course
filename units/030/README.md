## 关键结果

hand数据x=(0,1,2,3,4)、y=(1,2,2,4,6)。目标始终为J=SSE/(2n)，所以J*=4/25不是MSE。独立闭式参数为(3/5,6/5)，SSE*=8/5；全局恒等式为J=4/25+(a+2b−3)²/2+(b−6/5)²。Hessian为[[1,2],[2,6]]，特征值为(7±√41)/2。

默认三个路径实际得到：moderate在251次更新满足1e-8梯度阈值，short_budget在20次预算耗尽，too_large在45次更新后因下一候选超出保护范围停止。前两次适中步长更新为(0.6,1.68)、(0.408,1.104)，J依次为0.8512、0.242944。阈值停止是计算状态，不是正确模型或泛化证书。次数是本环境运行结果，不是跨平台CPU性能基准。

constant数据的全部最优参数满足a+2b=7/3，J*=7/9，返回的(7/3,0)只是代表。changed_sample闭式参数为(4/5,13/10)，J*=3/100。hand加约束b≤1时最优是(1,1)，J=0.2，梯度(0,-0.4)并非零。

显式教学总体X均匀取0..4、Y=1+X+ε且条件噪声均值0、方差1/4，风险最小参数为(1,1)，风险0.125。训练最优(0.6,1.2)在这个总体的风险为0.165。这里比较的是两个明确函数，不借由单个训练例宣称任何现实泛化能力。

## API与计算路径

loss_gradient(x,y,theta)返回目标、长度2梯度和梯度范数，残差符号为预测减观测。exact_reference(x,y)使用内部Fraction按存储的二进制实数值进行精确有理数闭式计算，返回精确字符串及舍入后的显示值；它不依赖轨迹求解器。geometry(x,y)构造Hessian，调用NumPy对称特征值函数，数学唯一性由精确Sxx判断。

trace_path(x,y,spec)先验证全部参数，再运行最多max_steps次更新。history包括初始状态，所以记录数为updates_completed+1。每个状态都检查有限数值。结束状态包括gradient_tolerance_met、budget_exhausted、growth_limit_reached、stagnated_without_tolerance；只有第一种success=true。计算中不支持的数值范围会明确抛错，不能把NaN当作收敛。

surface(x,y,grid)返回xy约定的a、b和高度数组，形状为(points,points)，行改变b、列改变a。最小格点只是离散网格最优。constrained_reference(x,y,slope_upper)用闭式消元求b≤上界的特定问题；不支持非唯一设计，不是通用约束优化器。

compile_report验证整个输入对象，包括所有未选场景、最后候选、最后路径与全部网格字段，然后开始计算。run在完整计算、允许有限JSON序列化成功之后才创建输出目录和同目录临时文件，随后原子替换报告。原子替换不等于对断电等灾难承诺持久性。该实验没有RNG。

## 保守数值合同

外部标量只接受Python int/float、普通NumPy整数以及float16/32/64。拒绝bool、np.bool_、文本、复数、非有限值、Decimal/Fraction、对象和扩展浮点。整数转float后须保持精确整数值。向量只接受list、tuple或一维普通整数/无符号整数/浮点ndarray，数组dtype宽度不超过8字节；不接受二维列向量、对象、布尔或复数数组。原始类型先验证，不能先用np.asarray(dtype=float)清洗掉非法类型。

一般输入数值绝对值最多10⁶，非零绝对值至少10⁻¹⁰⁰。直接x/y接口1至2000行；文件每组三组各2至2000行。路径1至12条；候选1至30组；步长10⁻⁸至1；梯度阈值10⁻¹²至1；最大更新0至10000；网格每轴5至201点。路径中拟议参数若绝对值超过10⁶，明确保护性停止。

精确参照中的转换量a、b、最小损失、均值和Sxx须有限且绝对值不超过10¹²；非零转换结果不能低于最小正常浮点值。因此即使外部输入通过基本范围，也可能因参照量超出教学范围而拒绝。这是保守能力边界，不是数学上不存在解。

计算出的零损失还须通过存储输入的精确有理残差为零检查，防止乘法舍入伪造完美拟合。代码对非零乘积、平方和除法检查下溢；变成0或次正规值会报错。来自调用前的舍入、强制类型转换或已丢失的非零值无法恢复。均值和残差使用math.fsum减少求和取消，但仍不声称完全消除浮点误差。两项近似相等的损失相减不作为收敛图主量；quadratic_gap使用与舍入闭式锚点之间的非负二次式，仍不是任意病态输入的精确证书。

JSON解析从原始十进制词元检查，不接受重复键和非标准NaN/Infinity。CSV原始词元也先检查，1e-400会被拒绝，真实0e-400接受。字段严格匹配，末字段或未选组非法同样使整个运行失败。输入验证不使用assert，在-O模式仍生效。
