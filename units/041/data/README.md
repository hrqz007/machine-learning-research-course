# 第041讲数据字典

全部是本单元原创合成数据。没有私人记录或外部真实任务样本。CSV以UTF-8保存，逗号分隔，小数完整保留供重复核验；文件摘要见verification.json。

hand.csv四行，列id,x1,x2,y。id为唯一正整数索引；两个特征与响应均为无量纲刻度，具体值见正文。无截距，三列中心化。配置的默认Ridge λ=0.5、步长0.25、零初值；状态0、1、2完整前向都保存。OLS和Ridge参照分别为(1/2,1)、(5/11,9/11)。修改CSV以后，正文默认数值不再适用。

benchmark.csv有360行，列id,case,x1,...,x6,y。case依次是regular、collinear、scaled，各120行。每个病例独立调用NumPy2.3.5 default_rng，种子4110、4111、4112；先抽120×6标准正态矩阵Z。collinear另外抽120个标准正态，令第二列等于第一列加0.002倍该向量。然后抽120个标准正态噪声，生成y=Z@[1.2,-0.7,0.5,0,0,0.3]+0.6*noise。scaled病例把Z各列乘[1,50,0.02,5,0.2,10]形成X，标签仍由未缩放Z生成。其它病例X=Z。求解前每个病例分别中心化X、y，不做统计模型选择。不同病例样本独立，不能当成只改变一个因素的配对消融。

selection.csv有240行，列id,split,x1,...,x6,y。train72、validation48、test120，独立种子4140、4141、4142。每份先生成n×6标准正态Z，再抽n个标准正态把第二列设为第一列+0.08*noise。令X=Z*[1,8,0.2,3,0.5,2]+[2,-1,0,4,0,3]。最后抽标签噪声，y=1.4+Z@[1.3,-0.5,0.6,0,0,0.2]+0.9*noise。ID全文件唯一。generation.json只记录出处和已知模拟真值；选择函数不读取它，不能拿真系数选模型。

config.json不与任何隐藏默认字典合并，所有字段必须存在且无未知字段。schema_version为1；hand_lambda范围[0,10]、hand_step[1e-8,1]、initial为长度2且各分量[-10,10]；lambdas有2至20个互异非负值且包含0，上限100；max_epochs为1至5000的整数；batch_size为1至64整数且不超过病例行数；gradient_tolerance在[1e-12,1e-2]；adam_step在[1e-6,1]；seed在[0,2^32-1]；fd_steps有2至20个互异数且在[1e-14,0.1]；coverage_repetitions为30至5000整数。

API数值拒绝bool、字符串、复数及非有限量。CSV必然是文本，先用Decimal解析，再做数值校验；JSON原始数值转换时检测下溢。任何非零原值若转float为0，或绝对值小于1e-150，均拒绝；这包含更宽精度的NumPy longdouble输入。真正0及范围内的NumPy实数标量可用。手算数值范围[-100,100]，其它数据数值范围[-1e8,1e8]；每组至少8行。此入口范围是教学软件支持契约，不保证每个合法自定义设计都可识别、好条件或必收敛。

覆盖模拟不从以上测试集选方法。固定x为32个[-2,2]等距点，截距1、斜率0.8，训练噪声SD0.5；种子为config.seed+1。每次依次抽32个训练噪声、1个SD0.5新观测噪声、1个SD1.5偏移噪声。原始重复结果全部保存在experiment-result.json coverage.rows，默认重复600次。
