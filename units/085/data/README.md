# 原创离线数据

固定种子85086，先独立生成训练323条、验证157条与测试160条。每条样本先均匀抽取两个二元位，映射到二维±1角落，再加标准差0.32的独立高斯噪声；标签为加噪前两个位的异或。无真实个人数据，无在线下载，原创数据按CC0-1.0提供。

`dataset.json`保存所有X与y；`generation.json`记录种子、大小、职责、SHA-256。重新生成到新目录：`python generate_data.py --directory outputs/generated-data`。当前冻结数据SHA-256为608f4cbb6d27ea1e276fbabb605e6b1edcd1b32ab5a1bbafe57d5220730c1878。
