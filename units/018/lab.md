# 概率事件与条件信息实验指南

## 目标与验收

本实验用同一张合成设备列联表完成三种核验：先按整数手算，再用一般Bayes接口复算，最后从已知模型重新抽样，观察有限样本的条件比例怎样波动。通过标准是能解释每个分母、检查独立性假设、识别未定义比例，而非让所有随机输出都恰好等于理论答案。

直接先修为第2、8讲。只用CPU、Python、NumPy、Matplotlib与IPython，不需要GPU、真实设备数据、网络下载或付费API。整个实验不会连接外部服务。固定数据文件是教学构造；所有概率和计数都是无量纲的比例或台数。

## 五 用Bayes重新得到相同答案

```python
result = e.bayes([0.01, 0.99], [0.8, 0.05])
print(result)
```

先验向量长度为2，分别对应缺陷与合格；似然向量也长2，分别是各假设下产生报警的概率。似然的两项不必相加为1；先验必须相加为1。输出weights应为[0.008,0.0495]，evidence约为0.0575，posterior约为[0.1391304348,0.8608695652]。

程序采用绝对容差1e-12检查概率向量总和，不自动归一化；证据概率与每项后验仍须满足合法范围。有限浮点实现只用于中等尺度教学，正乘积为次正规数或下溢为0时明确拒绝。想研究极小似然时，应另行实现带严格检查的对数算法或Fraction版本，不能删除报错强行继续。

检查点L3：把两个向量顺序对应地同时交换，后验会怎样？如果只交换似然而不交换假设标签，为何是改变模型，而不只是排版？若似然全部为0，当前证据在该模型中意味着什么？

## 七 重复证据之前先问独立性

在缺陷组和合格组内，若两个检测通道条件独立，双报警的似然分别是0.8²和0.05²。计算e.bayes([.01,.99],[.64,.0025])，缺陷后验应为256/355≈0.721126761。

如果只是复制原来的报警，第二次信息在已知第一次后发生概率为1。先取得第一次posterior，再用似然[1,1]更新，应该仍为16/115。

检查点L5：解释为什么“两个通道在全部设备中独立”与“给定缺陷状态后独立”不是同一句话。哪一个假设允许本节的两个似然分别平方？如无法支持该假设，应保留哪一项条件？

## 八 用精确整数检查条件独立

```python
for name, counts in groups.items():
    print(name, e.independence_report(counts))
print("pooled", e.independence_report(groups["high"] + groups["low"]))
```

两组内交叉乘积之差ad-bc均为0。合并表为[[68,32],[32,68]]，ad-bc=3600，联合0.34与边际乘积0.25相差0.09。这里表被定义为精确有限分布，所以可以使用“独立”这个模型结论；若只是随机抽来的实测表，该差值不能替代统计检验。

检查点L6：手算P(H|X=1)和P(Y=1|X=1)，再用两组条件概率和新的组别权重算出后者。说明为什么混合前后得到不同结论。

Notebook还会建立四种公平开关组合，各一个计数，然后仅保留X=Y的两种组合。条件前交集和边际乘积都是1/4；筛选后分别为1/2与1/4。检查点L7：这个筛选过程是否修改了任一开关的值？条件独立与无条件独立可否互相推出？

## 九 独立与不相关用不同检查回答

读取三个等权对(-1,1)、(0,0)、(1,1)。逐项求平均x、平均y、平均xy，再用“平均xy减去平均x乘平均y”算协方差。结果应为0，但P(Y=0|X=0)=1而P(Y=0)=1/3。

检查点L8：零协方差是哪几项抵消得到的？能否仅看散点没有明显倾斜就判为独立？若X恒等于0，相关系数为何没有定义？

## 十 单次模拟后不要立刻下结论

```python
simulated = e.simulate_devices(n=100000, seed=20261004)
print(simulated)
```

本次实际四格为[[775,201],[4942,94082]]。总数为100000，总报警5717，后验经验比例为775/5717≈0.135560609。它比精确16/115略低，不是计算失败。两个独立均匀数先生成缺陷状态，再按状态生成报警；设备之间独立，单台设备的缺陷与报警通常依赖。

检查点L9：比较模拟与主表时，应该比较计数、比例还是两者？为何不能要求单次模拟也正好有1%的缺陷？若改用不放回抽取完整10000台，最后的四格还会有这种波动吗？

## 十一 400次重复给出有限样本波动

```python
repeat = e.repeated_simulations(n=2000, repeats=400, seed=20261006)
print(repeat["summary"])
```

每次重复生成四格计数，函数核对形状(400,4)、非负性和行和恰等于n。可计算后验按大小排列；第ceil(0.025R)与ceil(0.975R)个值作为经验端点。没有插值，没有把缺失比例填成0。

| n | 报警数中位数 | 经验2.5%点 | 经验97.5%点 |
| ---: | ---: | ---: | ---: |
| 200 | 12 | 0 | 0.4 |
| 2000 | 113 | 0.075630252 | 0.201834862 |
| 20000 | 1149 | 0.121387283 | 0.157534247 |

这三组种子依次为20261005、20261006、20261007。400次重复均有报警。它们的范围描述已知模型下估计比例的波动，不是“真参数以95%概率处于这个区间”，也不是现实设备性能的置信区间。

检查点L10：n=200那组可以得到0，是否证明缺陷概率为0？为什么同样的总n下，条件事件越稀少，条件比例往往越不稳定？增加重复次数与增加每次的n分别改变什么？

## 十三 故意提供非法输入

运行e.boundary_checks()。它覆盖：布尔与字符串概率、object数组、非有限输入、负数、概率大于1、空向量、先验不归一、非整数计数、负计数、全零表、错误形状、超限总数、交集超过条件、零条件、证据为0、极小正乘积、非法随机种子与重复次数。预期失败只捕获ValueError或ZeroDivisionError，不把任意异常都算作通过。

概率数值与控制开关要区分：write_outputs=True是布尔控制参数，它被明确要求为bool；prior=True则是伪装成数值概率，会拒绝。CSV在磁盘上必然是文本，但加载器先检查明确的十进制整数字段，再解析；这不同于数值API接受任意字符串。

检查点L12：尝试e.bayes([1e-300,1.0],[1e-300,0])。直接浮点乘法会把一个正权重变成0，为什么“没有NaN”还不足以保证答案正确？

证据上界的浮点合同与先验总和保持一致：若实际权重和raw_evidence仅在1e-12内略大于1，报告evidence限幅为1，并另存evidence_roundoff_adjustment。后验仍除以未限幅的实际权重和；不自动修改输入先验，超出容差仍报错。这样合法后验可再次接受全1似然更新，而不会因一个浮点末位误差被拒绝。程序包含这个顺序更新与越界回归检查。
