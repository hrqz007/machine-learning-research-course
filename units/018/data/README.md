# 第018讲合成数据

所有文件都是本讲原创的有限计数教学设置，无真实设备记录、个人信息、学生数据或外部数据下载。这里的编号、状态与计数不声称代表任何真实产品。未复制或再分发参考教材的数据。

## device_counts.csv

两行依次为defect、clean，两个数值列依次为alarm、no_alarm，组成(2,2)非负整数表[[80,20],[495,9405]]。总数10000。设备状态与报警状态对每个合成编号预先固定，从10000个编号均匀抽一台时，表内比例就是精确模型概率。缺陷基准率1/100，缺陷检出率4/5，合格误报率1/20。

## conditional_independence.csv

八行描述regime、x、y、count。regime为high或low；x与y是二元通道状态，1为报警，0为不报警。每组按(1,1)、(1,0)、(0,1)、(0,0)排序，high计数64、16、16、4，low计数4、16、16、64。每组总数100，合并200。该表与主设备表是两个独立教学例子，不能逐行拼接成同一数据集。

## uncorrelated.csv

三个等权状态为(x,y,count)=(-1,1,1)、(0,0,1)、(1,1,1)。即Y=X²且X在三个值上均匀。它用于精确计算均值、协方差和事件概率，支持集只有三个点，不包含点之间的连续取值。

## 解析与更改

CSV在文件中是文本；加载器先验证固定字段、顺序和十进制整数词法，再解析为整数并核对完整预期内容。数值API不会接受字符串概率、浮点计数、布尔计数或object数组。若要研究新参数，请调用函数并另存变体，不要覆盖这三个固定文件后继续使用本讲答案。

模拟的详细结果写在../outputs/，由experiment.py重新生成。重复结果中posterior_available为空表示报警计数为0时的未定义经验条件概率，不表示缺陷概率为0。程序同时保留该行的全部四格计数，因此可以重新检查分母与缺失次数。
