# 第018讲 概率事件与条件信息

核心问题：得到一条新信息之后，事件概率怎样更新？

本讲从一张10000台合成设备列联表出发，解释样本空间、事件、条件概率、全概率、Bayes公式、独立与条件独立。直接先修为第2、8讲；集合与有限加权平均在正文中定义，不要求先学随机变量或微积分。

## 学习顺序

1. 阅读lecture，先用纸笔核对每个分母。
2. 按lab完成计数、Bayes、基准率和独立性检查。
3. 运行experiment.py，再从清空内核顺序运行experiment.ipynb。
4. 完成正文12题与实验L1至L12后，核对answers。

目录中的lecture.md、lab.md、answers.md是可编辑源文；对应PDF分别为14页正文、6页实验指南和6页详解。figures中12幅原创解释图分布在正文相应段落。experiment.ipynb保留真实执行的文本与6幅PNG图像输出。

## 关键答案

主表为[[80,20],[495,9405]]，行是缺陷、合格，列是报警、不报警。缺陷基准率1/100，检出率4/5，合格误报率1/20；总体报警率23/400，报警后缺陷概率16/115≈0.139130435。检出率0.8与后验0.139130435使用不同分母。

NumPy 2.3.5、固定种子20261004、n=100000的实际模拟表为[[775,201],[4942,94082]]，报警后经验缺陷比例775/5717≈0.135560609。它是一次有放回独立抽样的结果，不必与固定总体比例精确相等。

n=200、2000、20000各重复400次，对应报警数中位数12、113、1149。可用后验的经验2.5%至97.5%范围为[0,0.4]、[0.075630252,0.201834862]、[0.121387283,0.157534247]。这些是已知合成模型下的经验波动范围，不是未知参数的置信区间。

n=5的400次重复中296次没有报警，比例为未定义，不能填0。outputs/repeated-simulations.csv保留所有四格计数；posterior_available空字段表示零报警分母，非合法的零估计。

## 输入合同与失败条件

数值概率须为有限实数且位于[0,1]；外部布尔、字符串、复数和object数组被拒绝。计数须为整数类型，非负，表形状(2,2)，总数在1至10^12之间。概率向量和的绝对容差为1e-12，不自动归一化输入。证据总和若只在这个容差内略高于1，报告的evidence限幅为1；raw_evidence与evidence_roundoff_adjustment保留原值和修正量。后验始终除以实际权重总和raw_evidence；超出容差仍拒绝。模拟n在1至10^6之间，重复次数在1至10000之间，随机种子为0至2^64-1的整数。

零证据的Bayes请求显式报错；汇总表中的不可用条件比例返回None。正概率转换下溢、正乘积下溢及次正规乘积会被保守拒绝。本程序不是支持任意极小似然的通用数值概率库。普通端点0与1仍有明确数学行为。
