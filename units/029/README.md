## 精确参照与已观察结果

四行主例A=[1,x1,x2]、y=(1,3,0,4)。精确解β=(1/2,3,0)，预测(1/2,7/2,1/2,7/2)，残差(1/2,−1/2,−1/2,1/2)。SSE=1，MSE=1/4，J=1/8，三列残差内积均为0。加入交互列后β=(1,2,−1,2)，训练SSE=0，不提供现实泛化或因果证据。

完全共线A=[1,x,x]只识别β1+β2=3。最小范数选(1,1.5,1.5)，其他拆分在训练行上一样；新行(1,0,1)能产生分歧。把后一列改成100x，最小范数斜率变成3/10001、300/10001，显示其单位依赖。原始lstsq residuals为空时，重算SSE仍为3/64。

近共线族使用互相正交的七维x、z、w，平方范数分别28、4、12。Aδ=[1,x,x+δz]、y=1+3x+δz+w/16；δ=2⁻ᵏ，k∈{0,8,16,24,32,40,48}。所有存储值逐项用Fraction验证，精确存储秩均为3，β=(1,2,1)，SSE=3/64。

本次NumPy 2.3.5默认lstsq有效秩依次为3、3、3、3、3、3、2。系数误差范数约为9.16e-16、3.89e-12、4.81e-7、7.96e-3、1.51e3、4.25e7、0.707；SSE仍接近0.046875。正规方程前3组恰好精确，第4组误差约√2，之后3组计算Gram矩阵奇异。不能概括成某算法永远更精确或显式逆每次误差最大。

固定响应扰动εz、ε=2⁻²⁰时，精确参数变化(0,−ε/δ,+ε/δ)，其范数√2|ε|/δ，训练预测变化范数2|ε|。k=48时斜率变化达到2²⁸，所以代码没有随意把所有输出系数限制在1e6以内。算法误差另外与实际存储数据的精确解比较。

## 实现与数值合同

- solve_ols对A和y逐元素完整检查，A只能是二维，y只能是(n,)，拒绝静默广播或flatten。A最多128行16列，普通数值输入绝对值不超过1e6，非零绝对值至少1e-100。
- float-facing入口接受普通Python int/float和不超过64位的NumPy整数/浮点类型；原始bool、文本、复数、Fraction、Decimal与扩展精度被拒绝。对于已转换过的普通数值ndarray，只能判断当前dtype/值，无法恢复此前被外部转换丢掉的bool或精度历史。
- exact_rank和exact_ols是单独的Fraction接口，精确小矩阵参考使用有理数消元，不是生产规模求解建议。stored_fractions首先验证当前浮点矩阵，再逐项转换其实际存储值。
- 默认rcond=None采用NumPy声明的自动规则；显式rcond限定[0,0.1]，非零还受最小输入幅度限制。截断非零方向会改变原OLS问题，报告保留阈值与有效rank。
- QR只在n≥p且声明的数值rank满列时使用；不满足则not_applicable。normal作为对照求解Gram系统，奇异时返回linear_algebra_failure，不填入0损失。SVD不收敛等未恢复的异常明确抛出，不掩盖为成功。
- 所有路线重新计算预测、残差、SSE和梯度。每个非零平方项必须为正常有限浮点数；若平方下溢、受平方范数检查的残差/梯度/参照误差分量绝对值超过1e100，或求解输出非有限，则拒绝并要求重缩放。1e100不是所有系数或预测的统一上限；有限的大系数可返回，并须结合条件数解释。真0平方合法。该合同有限且保守，不承诺任意尺度或任意病态问题的准确系数。
- condition_estimate是计算的奇异值比值，不是精确秩证据。真零矩阵等无法形成有限比值时用JSON null和说明，不输出非标准Infinity。接近秩亏时有限巨大条件数并不等于数学满秩。
- 每个配置字段、最后一个元素及未选择的rcond都在相关求解前验证。near_collinear_powers限0至48且不重复；noise_scale和response_perturbation在声明范围中必须是2的整数次幂；实际构造值仍逐项核对。任意改变组合后若某项发生输入舍入，程序明确拒绝。
- CSV只接受有界普通十进制文本，要求所表示有理数能由binary64精确存储。0.125可用，0.1不满足本讲精确存储合同；这不是一般机器学习的数据禁令。向量CSV固定为声明的七行模型。主例可改成满足范围/满列秩条件的同列数据，但Notebook会拒绝沿用旧基线答案。
- JSON原始数字token在浮点下溢前被检查；1e-400、NaN、Infinity和重复键均拒绝。真正0e-400可作为0，再接受字段范围检查。所有数据验证及完整结果序列化完成后才创建/替换输出，非法输入保护已有report.json且不创建新目标目录。
- scikit-learn固定1.8.0。原始X配fit_intercept=True与增广A配False对齐训练预测。默认带截距的rank_属于中心化X；该版本稠密tol不改变本次求解，positive=True属于另一问题。
