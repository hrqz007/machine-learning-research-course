# 合成设计与精确锚点

hand_regression.csv是四个教学角点，两个特征列，不是现实人物数据。显式设计A=[1,x1,x2]，y=(1,3,0,4)，唯一OLS解(1/2,3,0)，预测(1/2,7/2,1/2,7/2)，残差(1/2,−1/2,−1/2,1/2)，SSE1、MSE1/4。交互列x1*x2加入后四参数可精确插值(1,2,−1,2)，不代表现实泛化。

orthogonal_vectors.csv的x、z、w都与全1列正交且彼此正交。平方范数分别28、4、12。构造Aδ=[1,x,x+δz]，y=1+3x+δz+w/16；δ>0时唯一精确系数为(1,2,1)、SSE3/64。δ=0时秩2，只能识别β1+β2=3，最小范数分配为1.5、1.5。响应加εz使系数变化(0,−ε/δ,+ε/δ)，训练预测变化范数2|ε|。

配置采用δ=2^(−k)、k为0、8、16、24、32、40、48；ε=2^(−20)，噪声尺度1/16。这些是可核对的二进制有理构造。实际求解必须再核验存储值及其精确秩，不能拿可能被舍入的构造公式假装实际输入。数学秩、默认有效rank和显式rcond结果分别记录。

本实验无RNG，不需账号、网络或付费API。所有矩阵和设置都是有限机制示例，不代表大规模性能或现实预测准确率。列顺序、截距约定、单位和截断阈值必须随模型记录。
