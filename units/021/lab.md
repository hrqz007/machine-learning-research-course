# 联合分布与相关结构实验指南

## 第二十一讲 用精确账本 线性代数和有限模拟交叉核验

本实验回答三个问题：同样的边缘分布可以隐藏什么联合关系；协方差为什么必须半正定；条件高斯的简化依赖哪些假设。先读正文第一至十一节，再做有限模型；读完高斯与全方差部分后完成其余实验。无需GPU、账号或付费API，安装依赖之后运行不访问网络。

所有数据是无量纲合成模型。输入的六个状态是完整的有限概率模型，不是用来估计真实总体的六条观测。主实验每个模型生成12000条样本，所有种子固定并公开；模拟仅核验这次实现，没有现实性能、因果、独立性检验或极限定理证明的含义。

## 三 第一次核验先不用随机数

把相同数对的质量合并，应得到(0,0):1/3、(1,1):1/3、(2,1):1/6、(4,1):1/6。沿Z求和得到X边缘；固定Z=1后除以2/3得到X在1、2、4处的条件质量1/2、1/4、1/4。

调用finite_moments后均值应为(4/3,2/3)，协方差应为：

$$\Sigma=\frac19\begin{pmatrix}17&4\\4&2\end{pmatrix}.$$

不要先用同一个函数生成“参考答案”再与自己比较。test_experiment.py用Fraction按原始矩E[UV]−E[U]E[V]独立计算；实现按中心乘积累积。脚本还检查60个另外生成的有理数模型、各坐标元素与直接投影后的方差。改变CSV会改变模型；固定课程CLI会拒绝与正文参考不一致的数据。要探索新模型，请导入可复用函数并同步重算理论。

```python
from experiment import finite_moments, conditional_finite
rows = [[0,0],[0,0],[1,1],[1,1],[2,1],[4,1]]
p = [1/6] * 6
print(finite_moments(rows,p)["covariance"])
print(conditional_finite(rows,p,1,1)["mean"])
```

条件函数返回两个坐标的矩，已知的Z坐标方差为0。它不会自动把恒定列删除。条件查询按状态坐标精确匹配；模型概率为0的组会报错，不能把无样本或零概率都偷偷换成全0结果。

## 四 矩阵形状与协方差变换

将D看作n×d，C=D减去每列均值。计算C.T@C/n，应得到d×d；C@C.T/n得到n×n，是另一种Gram矩阵。NumPy核对必须明确rowvar=False、ddof=0。改成ddof=1后六行例子应整体乘6/5，这是不同统计对象的分母约定。

取A=[[1,1],[1,-1]]。linear_moments返回X+Z和X−Z的协方差[[3,5/3],[5/3,11/9]]。另一路把每个原状态先变成(x+z,x−z)，直接重算精确矩；这条路径不重复使用AΣAᵀ公式。平移b只改变均值，不改变协方差。

检验[[1,2],[2,1]]时应拒绝，因为方向(1,−1)给“方差”−2。再试三维对角全1、非对角0.9、0.9、−0.9的候选，最小特征值为−0.8。最后测试[[1,2],[2,4]]：它半正定且奇异，可以由显式因子构造，但不能送给本讲的普通密度或严格正定条件接口。

## 五 高斯生成与条件分布

主模型的下三角因子为：

$$L=\begin{pmatrix}2&0\\3/2&\sqrt{27}/2\end{pmatrix},\qquad LL^T=\begin{pmatrix}4&3\\3&9\end{pmatrix}.$$

以n×2独立标准正态矩阵E为输入，行样本应为E@L.T+μ。若误用E@L，协方差变成LᵀL，通常不同。先做因子重构，再看经验协方差，再看散点；三种检查提供不同证据。

本次种子2102、n=12000得到经验均值约(1.01684,−1.98733)，经验协方差约[[3.99825,3.02973],[3.02973,9.04068]]。它们不等于理论值(1,−2)及[[4,3],[3,9]]。不按看起来“更漂亮”的结果更换种子。

```python
from experiment import gaussian_conditional, sample_gaussian
condition = gaussian_conditional([1,-2], [[4,3],[3,9]], [0], [5])
print(condition["mean"], condition["covariance"])
sample = sample_gaussian(condition["mean"], condition["covariance"], 12000, 2107)
```

结果是均值1、方差27/4，标准差为√27/2。此代码直接生成精确条件模型；从联合样本筛选4.5<X<5.5得到的是一个有限宽条件事件，会额外混合区间内不同均值。不可把两种样本混为一谈。

分块接口把observed_indices指定的坐标视为B，其余坐标按原顺序返回为A。系数ΣABΣBB⁻¹通过solve求解；Schur修正通过白化后的Gram乘积对称地计算，不显式求逆、不静默补jitter。返回残差与已知坐标的交叉协方差，供核对理论的零矩阵。

## 六 两个不能靠相关系数发现的反例

对U等概率取−1、0、1且V=U²，精确协方差为0，但P(U=0,V=0)=1/3，不等于1/9。应先写事件分解失败，再展示图；看到弯曲散点只是辅助。

对G标准正态、S独立公平取±1，令H=SG。两个边缘均正态、理论协方差为0，但|G|=|H|。Notebook直接检验所有生成行的绝对值恒等式，并与真正独立的高斯点云对照。本次有限相关约−0.0153与−0.0131，二者都接近0，但不能据此把第一种判成独立。

本次实验没有统计独立性检验的显著性或检验效能声明。依赖来自构造与精确事件计算；有限样本图用于展示，不提供“任意未知数据是否独立”的判决规则。

## 七 三角模型与全方差

三角区域0≤Y≤X≤1内密度为2。边缘分别为2x和2(1−y)，均值为2/3、1/3；两个方差均1/18，协方差1/36。给定0<x≤1，Y均匀分布在[0,x]，条件方差x²/12。接口拒绝x=0，因为简单密度比值为0/0。

六态全方差的三项应是17/9、1、8/9。组内项按组概率加权，不能把0与3/2等权平均。三角模型的对应等式为1/18=1/24+1/72。平均关系不意味着逐组关系：90%质量放在恒为0的组、10%放在±10组，总方差10，后一组的条件方差却是100。

## 八 密度积分要拆开截断与网格误差

Notebook把高斯积分域取为μ+L[-6,6]²。对标准噪声坐标积分时，面积因子为det(L)=√27。域内解析质量为erf(6/√2)²，约0.9999999960536494；因此域外截断质量约3.94635×10⁻⁹。

每轴60和120个小区间的梯形积分分别约0.9999999955779859与0.9999999959327955。它们与域内解析值的绝对差约4.76×10⁻¹⁰和1.21×10⁻¹⁰，才是这两张网格的误差。不能把“积分小于1”全归因于实现错误，也不能把粗细网格之差无条件当作严格误差上界。这里使用math.erf，不依赖SciPy。

## 九 可复用接口与数值拒绝契约

finite_moments、conditional_finite与total_variance处理有限概率模型；sample_covariance专门处理按行的样本。covariance_matrix、correlation与linear_moments处理矩阵对象；sample_gaussian、gaussian_logpdf、gaussian_pdf与gaussian_conditional要求数值上良好的正定输入。sample_gaussian_factor接收显式因子B，可以构造奇异分布；triangle_density、triangle_conditional、sample_triangle处理三角模型。

所有数值输入在强制转换前逐项检查。Python混合列表中的bool、字符串、复数、None，以及object或complex型数组均拒绝。CSV文本属于明确的解析边界：先按已知字段解析，再对全文件数值与模型检查；这不意味着数值API接受任意字符串。错误形状、空数组、非有限数和不支持的索引也拒绝。未被条件选中的行及零权重状态仍完整检查，采样不能躲过非法状态。

浮点实现有意小于数学定义域：一般输入绝对值不超过10¹⁰⁰，非零输入不接受float64次正规数；每个非零协方差元素至少10⁻¹⁰⁰，维数不超过32，总数组元素不超过200万，采样数在1至20万之间。乘积、除法与累积检查非有限值及有意义的下溢；远尾普通PDF若将下溢或成为次正规数，应使用logpdf。高斯采样还拒绝均值尺度相对于非零标准差大于10¹²的情形，以免假装能解析已丢失的噪声。

输入协方差要求完整数组精确对称。计算特征值出现任何负值时不自动修复；正定接口另要求λmin/λmax>10⁻¹²，因此可能保守拒绝数学上有效但数值困难的矩阵。显式因子接口允许生成某些在特征值算法中数值难判的退化模型。输出Gram矩阵每个对称位置从同一求和结果赋值，这是计算对称公式，不是把不合法输入矩阵平均成合法矩阵。

概率列表采用统一容差8个float64机器精度，约1.78×10⁻¹⁵。只有每项在[0,1]且math.fsum与1之差不超过此容差才接受；接受后按实际总和作一次浮点标准化，并返回input_total、used_total、maximum_adjustment及tolerance记录。非法总质量不被“修好”。测试覆盖总和1+一个舍入单位、重复传入结果、全1条件事件与极小正概率复用。输入CSV的有理数概率仍要求精确和为1。

这些守卫保证明确的实现范围，不是任意尺度下正确舍入的通用数值库。输入在传入前已经舍入丢失的信息无法恢复；严重抵消、极高条件数或跨平台浮点细节需要专门分析。失败时应先看类型、形状、量纲与尺度，再决定重设实验；不要删除检查或加任意jitter让代码“通过”。
