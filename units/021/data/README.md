# 数据字典

全部数据是本讲独立设计的无量纲合成模型，不是观测样本或真实测量。

joint_states.csv 的每行是同一个状态同时产生的(x,z)数对，概率由整数分子、分母指定。A至F各1/6；z=0对应第019讲quiet，z=1对应active。状态不是要估计总体概率的六条样本。所有精确矩须按这些模型概率计算。

gaussian_model.csv 指定二维高斯的坐标顺序(x,y)、均值(1,-2)、协方差[[4,3],[3,9]]。covariance_x和covariance_y按行共同构成协方差矩阵，非相关系数矩阵。第二维标准差为3，而方差为9；x与y相关系数1/2。

概率模型输入与运行时生成的模拟结果须分开保存。改变文件必须同步改变理论参考、生成因子、支持集与检查，不能继续沿用本讲的固定答案。跨列重新配对数据会改变联合分布，即使每列直方图没变。


gaussian_sample_preview.csv是种子2102、n=12000高斯模拟的前20行，只演示x、y列格式。其余11980行由experiment.py生成；20行预览不用于正文的12000行经验矩核验。所有完整运行输出由脚本重建，不作为原始观测数据。
