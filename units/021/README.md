# 第021讲 联合分布与相关结构

核心问题：多个变量怎样共同变化，协方差遗漏了什么？直接先修为第010、012、018至020讲。本单元由一个六状态模型出发，连接联合与条件分布、协方差矩阵、多元Gaussian和全方差。

## 学习顺序

1. 阅读lecture.pdf，先理解同一次状态的配对、边缘与条件的区别，再做矩阵推导。
2. 按lab.pdf配置环境，运行experiment.py及test_experiment.py。
3. 在experiment.ipynb中重启内核并顺序运行全部16个代码单元，核对6幅实际生成图。
4. 独立完成answers.pdf的18题，再对照完整推导与失效条件。

## 文件

- lecture.pdf、lecture.md：13页正文，20个主题小节，12幅原创彩色机制图
- lab.pdf、lab.md：5页独立实验指南，输入输出、API、数值契约与复现步骤
- answers.pdf、answers.md：6页、18题完整题目与逐步详解
- experiment.py：可导入的联合分布、协方差、条件高斯及生成接口，也可独立运行
- test_experiment.py：独立Fraction、Decimal参考及拒绝用例，可在普通和优化模式运行
- experiment.ipynb：实际执行的Notebook，保留顺序输出和6幅PNG
- figures：正文使用的12幅原创图
- data：两个精确模型CSV、数据字典及20行高斯格式预览
- requirements.txt、environment.yml：教学运行依赖
- source-checks.json：八条一手来源记录及实际阅读范围
- test-result.json：运行、数值、边界、PDF和Notebook验证证据

## 快速运行

在021目录执行：

```text
conda env create -f environment.yml
conda activate ml-course-021
python experiment.py
python test_experiment.py
jupyter lab experiment.ipynb
```

脚本默认在自身旁创建outputs目录，保存JSON报告与八份完整样本CSV；--out可指定其他位置。数据路径基于脚本位置，因此从其他工作目录启动也可运行。没有运行时网络、账号、付费API或GPU要求。改变输入模型时，应导入可复用API并重算理论；固定课程CLI会拒绝与正文参考不一致的模型。

## 关键结果

- 六态均值(4/3,2/3)，协方差[[17/9,4/9],[4/9,2/9]]，相关4/√34
- 变换为X+Z与X−Z后，协方差[[3,5/3],[5/3,11/9]]
- 三角密度2：均值(2/3,1/3)，两个方差1/18，协方差1/36
- 高斯μ=(1,−2)、Σ=[[4,3],[3,9]]：Y给定X=x的均值−2+3(x−1)/4、方差27/4
- 全方差17/9=1+8/9；平均关系不保证每个条件组方差更小
- U与U²、G与SG分别展示零相关与正态边缘不能替代独立或联合高斯假设

固定n=12000、种子2102的高斯样本均值约(1.01684,−1.98733)，经验协方差约[[3.99825,3.02973],[3.02973,9.04068]]。这些是有限模拟值，不能强行改成理论矩，也不能用于现实任务表现宣称。

## 验证和边界

可复核测试包含1358个数值检查、115个拒绝检查，其中65个证明在创建随机流前拒绝非法输入。另从两个无关工作目录启动新进程，并在python -O下运行，JSON与八份CSV字节一致。九种非法CSV改动均未改变旧输出；输入失败也未创建新结果目录。所有24页PDF逐页渲染并查看，Notebook16个代码单元在新进程真实IPython InProcessKernel中顺序执行，6幅保留PNG逐幅查看。

输入先检查整个数组，再转换或采样，包括零权重和未选中的状态。bool、字符串、复数、object数组、非有限数、非法形状及不支持的数值范围均拒绝。概率总和采用统一8个机器精度容差，只对已在容差内的表示作有记录的浮点标准化；明显非法权重不被归一化。

完整协方差先检查精确对称。程序不投影、不加jitter；密度和条件接口要求λmin/λmax>10⁻¹²，可能保守拒绝数学上合法但数值困难的输入。奇异高斯可用显式因子生成。一般输入范围、次正规数、乘除下溢和远尾logpdf处理详见lab.pdf及函数文档。

未测试浏览器Jupyter界面、socket传输、读者机器上的Anaconda安装，以及不同NumPy版本的逐位复现。独立性、二阶矩存在性和高斯假设必须由模型及适用理论说明，不能由一次模拟或一张散点图证明。
