## 5. 第三步 看同一个统计量如何使用不同参考分布

```python
from experiment import known_sigma_test, paired_t_test
z = known_sigma_test(paired['values'], sigma=2)
t = paired_t_test(paired['values'])
print(z)
print(t)
```

两次观察统计量同为2√2。z双侧p约.004677735，95%区间[.614096,3.385904]。t使用7个自由度，双侧p约.025463562，95%区间[.327958,3.672042]。已知σ的区间较短不是选择它的正当理由；先证明信息来源与模型条件合适。

SciPy配对检验按第一数组减第二数组，独立核对时应调用stats.ttest_rel(b,a)，不是(a,b)。改变顺序会改变t符号；双侧p可能不变，仍不能忽略报告方向。不要用nan_policy='omit'自动删行。

验收：写出Student精确零分布的条件，并明确它在本讲作为定理接受。对常量差值[2,2,2]，paired_t_test返回退化状态、p与区间为None；不能把它改成p=0。外部正σ的z仍有定义。

## 7. 第五步 效应与功效分开记录

原始效应2教学分，标准化配对效应d_z=2/2=1。t区间横跨实用阈值1.5，所以排除零差异不足以确认超过1.5。先写这段解释，再去看模拟，避免让显著性标签替代实际问题。

已知σ模型理论功效由两侧尾部相加得到。固定δ=1、σ=2、α=.05，n=8、32、128理论分别约.292989、.807430、.999891。默认10000批模拟对应2999、8073、9998次拒绝；比例.2999、.8073、.9998，MC标准误约.004582、.003944、.0001414。


脚本直接抽标准化均值Z，而非为每批再生成n个观测；Gaussian条件下两者分布完全相同，节约CPU但没有创造额外证据。真实效应为0时理论拒绝率就是α，有限模拟不必恰好等于α。

当10000批全部拒绝时，插件MC标准误为0，但真实概率仍可能小于1。report还保留Wilson频率区间。极高功效可能因float64舍入显示1，单独保留的type_II仍是正数；不要把1减去已舍入的功效当精确漏检概率。

## 8. 第六步 把选择过程也当成程序

默认全部真零的20项独立比较，未校正理论家族率约.641514，模拟6441/10000=.6441。Bonferroni每项阈值.0025，独立模型理论约.048830，模拟504/10000=.0504。有限模拟超过.05并不反驳理论上界，因为模拟比例也会波动；相应Wilson区间约[.04628,.05486]。

证明Bonferroni时使用并集上界，而不是独立乘积。它能处理相关有效p值，但不能修复错误单项模型、伪重复或漏记比较家族。家族错误率是至少一次误拒，不是发现中假发现比例。

随后查看同一条零效应路径n=8、16、…、64。默认只看最后拒绝514条，任何时点过线拒绝1742条，即.0514与.1742。这里共享前缀，不能用独立重复公式代替模拟。事后选更小单侧尾再按.05拒绝的理论错误率.10，默认模拟.1012。

验收：把三个机制分别写成明确事件：“任一比较”“任一时点”“任选单侧方向”，说明究竟哪一步改变了原来的错误控制。不要把.1742说成所有中途查看计划的通用常数。

## 9. 第七步 故意输入坏数据

输入检查应在完整数据读取后、RNG创建前、写输出前执行。先复制CSV或JSON进行破坏，保留原始教学数据。可以试重复ID、末行NaN、多一列、漏一列、true混入JSON列表、最后一个样本量为浮点数8.0、最后一个效应超范围、差值非整数等。

```python
from experiment import moments, paired_t_test
for bad in ([1, 1, float('nan')], [1, True], [1, '2']):
    try:
        moments(bad)
    except ValueError as error:
        print(type(error).__name__, str(error))
print(paired_t_test([0, 0]))
print(moments([-1, 1, 1e-100])['mean'])
```

最后一个输出应为1e-100/3，而不是0。均值从原始值用补偿求和计算；先减一个锚点再相加可能把很小的非零残差丢掉。数值API刻意拒绝Fraction、Decimal、object数组、扩展浮点、bool、文本与复数；CSV则有专门十进制解析器检查原文字面量。完整三检验CLI要求CSV分数可被float64精确表示（如整数、.5、1.25），并且差值为整数；.1或在转换中消失的末位会明确拒绝。JSON原始浮点文字先检查非零下溢，普通.05等参数允许常规舍入；重复键与NaN/Infinity常量拒绝。若上游已经把True变成了1.0，当前接口无法恢复被丢弃的类型信息。

保护检查：先记录已有report.json字节或SHA-256，再用坏CSV运行同一输出目录。程序应失败且旧文件完全不变。不要把失败后悄悄留下的旧报告误当作新结果。新进程和python -O都应保留同样的显式ValueError检查。
