## 公共API及数值契约

所有输入检查使用显式require/ValueError，在python -O仍有效。先完整验证，后常量/零值分支；先完成所有设计组合和确定性检验，后创建RNG；全部计算与JSON序列化成功后才临时写入并原子替换report.json。不接受外部RNG或任意统计回调，没有回调隐藏状态。程序无加权统计API；符号翻转中零差值标签的重复质量完整保留。

### 标量与数组

只接受Python int、float，NumPy整数和float16/32/64标量。拒绝bool、文本、复数、Fraction、Decimal、任意对象和longdouble等扩展精度，避免高精度输入偷偷缩窄。数组只能是列表、元组或一维NumPy数值数组；object、bool、complex及大于8字节元素数组拒绝。所有元素包括最后一个都先检查。

通用值绝对值≤1e6，非零绝对值≥1e-100；NaN和无穷拒绝。若上游已经把True转换成1.0或把非零数变成0，接口无法恢复被丢弃的原始信息。普通float64舍入仍然存在，不能据此声称任意精度实数运算。

moments要求2..10000项；均值用原始值的math.fsum，不先减锚点。方差用补偿两遍求和并校正已舍入中心的剩余均值。非零平方离差必须是正常浮点数，非恒定方差不得为0或次正规值。完整常量输入返回精确sd=0。paired_summary完整检查两列与差值后再计算，长度相同，绝不排序重配或删除NaN。

### 检验与概率

known_sigma_test接受2..10000个差值，sigma在[.01,1000]，null在通用数值域，alpha在[.0001,.2]，计算的|z|≤30。paired_t_test同样至少2项，|t|≤30；完整常量返回status=degenerate_zero_sample_sd，统计量、p、区间、拒绝和d_z为None。其余有效输入返回双侧p与1−alpha区间。两个方法使用p≤alpha；闭区间恰好端点的逐点约定差异在连续模型下概率为0，详解明确说明。

exact_signflip接受1..16个整数值差值（整数类型或精确整数值的受支持float），全量检查后才转int；不把非整数四舍五入。总差和枚举由Python整数精确计算。α同上，保留全部2ⁿ标签，统计量为绝对总差，全零输入p=1。

gaussian_power：delta在[-100,100]、sigma在[.01,1000]、n为2..4096整数、α同上，|delta|√n/sigma≤12。返回功效、两侧正尾、单独第二类错误概率与舍入说明。应为正的概率若计算为0、次正规或非有限就明确报错，建议改用专门log-tail实现；不能当数学零发布。

family_error：m为1..1000整数，α同上；精确独立家族公式用log1p/expm1避免小数相减。bonferroni接受1..1000个[0,1]的p值，包括合法端点；所有位置先验证。binomial_summary接受1..1000000的整数R和0..R整数命中k，给插件MC误差和Wilson区间，不把全0/全1插件误差当数学确定性。

### CSV与JSON文件

CSV必须恰好三列，顺序为pair_id,score_a,score_b；2..16行，唯一ASCII ID以字母开头、余下至多31个字母/数字/下划线/连字符。禁止额外或缺失字段、空值、NaN、无穷和周围空格。保留原数字文本检查范围和非零下溢。

这个完整三检验教学CLI刻意要求CSV分数是float64可精确表示的十进制数，例如整数、.5、1.25；.1或1.00000000000000001会明确拒绝，避免原文的小差异在转换后变成整数或常量。其B−A还必须是整数值才能做精确符号翻转。需要一般十进制分数时，应独立使用z/t数值API并明确数值和模型精度，而非悄悄更改本次精确枚举目标。

JSON键必须与data/model_spec.json完全一致，无重复键；禁止非标准NaN/Infinity常量。浮点原始文本在转换前检查，非零1e-400等不得伪装成零；真正0e-400有效。普通十进制参数如alpha=.05允许标准float64舍入。seed为0..2³²−1−3000整数；repetitions为100..50000整数；known_sigma在[.1,100]；null_delta必须为0；practical_threshold在[0,100]。功效delta、n与家族列表各1..10项且不重复，n为2..4096，家族大小1..100；每个delta/n组合都需通过功效范围检查。总模拟元素预算R×(64+家族大小总和+功效组合数)≤15000000。验证后才建立随机生成器。
