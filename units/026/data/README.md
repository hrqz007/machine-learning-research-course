# 教学数据与预先设定

所有记录均为独立构造的合成教学数值，没有真实用户、真实设备或真实模型表现。每行是一个配对实验单位上的A、B两个分数，分数越大越好，单位为任意教学分。pair_id为唯一ASCII标识；同一行配对不可打乱。

八个B−A差值依次为3、2、4、1、−1、0、2、5，均值2，离差平方和28，样本标准差2。模型对照中的known_sigma=2是事先外部给定的总体标准差，不是从这八行估计的值；它恰好与当前样本标准差相同是人为教学巧合，不能用来证明现实中σ已知。

配对t检验使用差值模型独立同分布Gaussian(δ,σ²)，σ未知；精确符号翻转检验使用零假设下各对可独立交换A、B（或差值独立且关于零对称）的条件模型。仅有E差值=0不足以支持符号翻转。整数主例避免浮点相等边界被误计数。

model_spec.json为固定的教学设计：PCG64种子26026；每种机制独立模拟10000批；预先α=.05，δ₀=0。功效在δ为0、.5、1、2与n为8、32、128的Gaussian已知σ模型下比较。每批包含1、5或20项相互独立的真零假设，用于未校正和Bonferroni家族错误率。不同实验使用明确偏移种子，输出记录每个偏移。practical_threshold=1.5是教学决策阈值，不是行业标准。

原始CSV用于完整手算；随机生成的重复实验另存输出，不覆盖原始数据。改变比较方向、统计量、效应阈值、停止规则或比较家族时，应当在查看新的结果前说明，不以最小p值筛选结果。

读取契约：本讲完整三检验CLI要求CSV分数的十进制文字精确对应一个float64值，例如整数、.5、1.25；.1等非精确二进制值会拒绝，不悄悄缩窄。B−A必须是整数，供精确并列计数。ID唯一，缺值、额外字段和NaN均报错。JSON浮点数从原文字面量验证非零下溢与范围，普通.05等参数允许float64舍入；重复键和非有限常量拒绝，不能覆盖前面的坏值。RNG在完整配置及所有数据检查通过后才创建。
