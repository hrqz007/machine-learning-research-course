## 核心已知答案

- q(x)=1+x在[0,2]的积分为4；密度p=q/4；[1/2,3/2]上的区间量为1/2
- p(1)=1/2是高度；[0,1]上的区间量3/8，单点{1}的量为0
- Y=3X+1在[1,7]上的密度为(y+2)/36；对应区间[5/2,11/2]的量仍为1/2
- x²在[0,1]积分为1/3；n段梯形值为1/3+1/(6n²)，中点值为1/3-1/(12n²)
- e的负x次方截到B后，真实保留量为1-exp(-B)，尾部为exp(-B)，加密网格不会补回尾部
- B=4、n=8的梯形值约1.0020514，由约0.0203670的高估与约0.0183156的尾部遗漏抵消而来
- 三角形0≤y≤x≤1内常数密度2总量为1；n×n中点格按y≤x或y<x选择时得到1+1/n或1-1/n
- sin²(16πx)的真实积分为1/2，但n=8与16端点网格都可能给出近零值

这些是确定性合成机制，不能当作真实分布拟合或实际预测性能证据。

## 计算契约与验收

入口要求有限实数，拒绝bool、字符串、复数、非有限数据、重复或无序坐标与长度不匹配。样本接口要求一维list或tuple。等分网格下界必须严格小于上界，段数是1至100000的Python整数；三角网格上限512。数学上的逆向和零长度积分仍有定义，只是当前积分接口明确不接受；区间概率接口允许零长度区间。

整个网格先验证，再调用被积函数。回调值、每段贡献和总和还需通过有限性检查。有限结果仍可能有舍入或下溢误差；本实现是教学用有限公式，不是通用自适应积分器。

脚本通过497项交叉核对：377项有理数精确等式和120项浮点实现比较，以及46组边界或已知结果检查。额外独立检查包括256项Fraction对照的浮点积分和16组60位Decimal指数积分对照，最大绝对差均约1.11e-16。三次新进程执行包含两种无关工作目录和一次python -O；标准输出一致，两次常规运行的报告字节一致。

Notebook实际在新Python进程的真实ipykernel InProcessKernel中从头顺序执行，3张图片均保留且已检查。未覆盖浏览器UI、外进程socket传输或学习者Anaconda安装；有限测试不能证明任意函数的积分精度。详见 `test-result.json` 和 `verification.json`。
