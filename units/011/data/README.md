# 第011讲合成数据说明

main.csv 是本课程原创的确定性数学示例，没有真实人物、房产或观测记录。sample_id 是唯一行标识；x 与 y 都是无量纲实数。三行依次为 (0,1)、(1,2)、(2,2)。行顺序用于逐条核对，不表示时间。

实验用设计矩阵 A 的两列分别表示常数 1 与 x，参数顺序为截距、斜率。残差统一定义为 y − Aβ，不能与相反符号混用；残差平方和不受该符号选择影响。此处只研究同一固定数据上的线性代数与数值方法，没有训练/测试性能声明。

脚本只读取本文件；其他秩亏、近共线和扰动案例在代码中确定性生成。运行结果写入同级 outputs 目录，不覆盖本 CSV。
