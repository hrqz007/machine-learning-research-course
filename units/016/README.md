## 可以独立核对的答案

- 盒子[0,2]×[0,1]：投影(2,1)，平方距离2
- 原点半径2圆盘：投影(6/√13,4/√13)，平方距离17−4√13
- 直线z1+z2=1：投影(1,0)，平方距离8
- 盒子与圆盘交集：投影(√3,1)，平方距离13−6√3，约2.607695
- 先盒后球、先球后盒都可行，但平方距离约2.689165、2.784627，均严格较大
- 三维两等式例：投影(4/3,−1/3,1/3)，平方距离26/3
- 有限Jensen：输入1、2、4，权重1/2、1/4、1/4，左边4，右边11/2，差距3/2

“投影”返回最近点；目标值为平方距离的一半。严格凸保证至多一个最优点，存在性还需相应条件。有限网格没有发现更好点，不等于已经证明全域最优性；本讲真投影有独立解析证书。

## 数值契约与验证范围

输入必须为指定形状的有限实数；拒绝布尔、混合字符串、object数组、隐式广播、逆序界限、负半径、零法向量与不合法权重。权重和使用1e-12绝对容差，接受后不重新归一化。仿射接口只接受数值满行秩的小矩阵，拒绝一致冗余与矛盾方程组，这不表示冗余方程在数学上必然无解。

中间采样点必须在调用函数之前有限，回调返回值也必须有限。严重溢出、下溢或抵消不能可靠判断时明确拒绝；不声称是任意尺度稳健求解器。

脚本通过16组固定投影、71组边界检查，另以Fraction独立核对36个盒子、36个直线、36个半空间及27个仿射输入。新进程、不同工作目录重跑时，JSON和三份CSV内容摘要一致。Notebook已在新Python进程的真实ipykernel InProcessKernel中顺序执行，没有未处理异常并保留实际PNG输出。未测试Jupyter浏览器界面、外进程socket传输或读者本机Anaconda。完整范围见 `test-result.json`。
