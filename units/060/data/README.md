# 原创合成数据

## 独立行主实验

固定种子60060。生成720行8列标准正态输入，再令x2=x0+0.3×独立标准正态。标签概率为sigmoid(1.4x0+1.8x1−0.8x0x1)，再独立抽伯努利标签。前360行训练，后360行测试。

row_id为追溯编号，x0至x7为模型输入，y为0/1标签，true_probability是教学机制真值，禁止进入模型。相关代理x2不是独立信号；其余噪声列帮助比较特征子采样。

## 群组相关反例

group_train与group_test各60个独立对象，每个对象重复6行。组内三列输入及标签完全相同；组间标签来自独立公平硬币，与输入无预测关系。训练组编号0至59，测试组60至119，不交叉。group_id用于评价单位，不进入模型。

重复测量不增加独立标签证据。行级bootstrap会让同组副本同时出现在袋内和袋外；整组bootstrap以对象编号为抽样单位。本反例用来展示目标是新组时的评价泄漏，不能解释为现实数据性能。

所有数据为原创模拟，无真人信息或第三方数据许可依赖。CSV保留17位有效数字。重建到新目录：python generate_data.py --directory outputs/new-data；生成器拒绝直接覆盖data。实验不联网，四个CSV哈希记录在experiment-result.json。
