## 数学与实际结果

目标J=SSE/(2n)，残差预测减观测。主例A=[1,u,10v]，y=3+2u+3v+uv/2，u、v枚举±1。精确β*=(3,2,3/10)，J*=1/8，H=diag(1,1,100)。η=1/64前两轮参数为(3/64,1/32,15/32)、(381/4096,127/2048,105/512)。目标分别为89/8、64285/8192、224099341/33554432。

主例训练均值(0,0)、尺度(1,10)，标准化H=I，θ*=(3,2,3)。原坐标η=1/64、近似2/101在1252、1092次达到各自梯度阈值10⁻⁸；标准化η=1/64、1/2、1分别为1268、29、1。原坐标η=1/32不稳定，完成19次后下一候选超出参数保护上限。

相同数字的梯度容差不是跨坐标同一标准。用E_pred=‖A(β−β*)‖/√n≤10⁻⁸作为共同预测单位标准，前五条路径首次达标更新为1252、999、1268、29、1，不稳定路径未达标。beta必须映回原单位。quadratic_gap_raw直接从A(β−β*)计算，避免loss−loss*消去，仍以舍入闭式参数为锚点，不是任意病态输入上的精确误差保证。

correlated设计为[1,u,u+v/8]，原H条件数约258.012，标准化后257.996；相同方差没有消除相关性。constant设计为[1,u,7]，精确秩2，标准化后仍秩2。数值谱可能出现−1.1×10⁻¹⁶，报告保留它，同时用精确秩避免将其误当负曲率或正定保证。

query仅有特征(2,20)、(−2,30)，训练统计转换后(2,2)、(−2,3)，闭式预测13、8。没有测试标签，不报告泛化指标。λ=1且截距不惩罚时，原坐标普通L2得(3,1,30/101)，标准化普通L2映回(3,1,3/20)；正确变换的加权惩罚才能保持原目标。

## 实现接口

loss_gradient(A,y,theta)返回同一状态的预测、残差、目标、梯度和梯度范数。向量必须为一维。trace_path(A,y,spec)使用实际NumPy整批更新，没有每轮代入闭式轨迹；history含初始状态，所以长度=updates_completed+1。达到容差、预算耗尽、下一候选越过参数上限、无容差停滞和两点循环分别记录，只有gradient_tolerance_met标success=true。

exact_reference把输入实际存储float转为Fraction，独立构造AᵀA与Aᵀy并精确消元。满秩时提供精确系数与损失字符串、浮点显示值；欠秩时仅给精确秩，不假装参数唯一。此方法仅适合小型教学数据。geometry给H、浮点谱、条件数和稳定步长上界；精确欠秩或数值最小特征值非正时condition_number为null。

fit_scaler只接受训练特征，均值和方差从实际存储值以有理数计算，ddof=0；保留mean_exact以处理真正均值位于相邻float之间的情况。transform对所有后续数据复用同一精确均值和已舍入的正尺度，先相减再除。常数列用除数1并返回zero_variance=true。to_scaled和to_raw同时处理均值引起的截距变化，不只改变斜率。

compile_report先验证所有场景、query和全部路径，再开始拟合统计、求谱或更新。run先保护输入与包内源文件，完成全部计算和有限JSON序列化后，才创建输出目录、写同目录临时文件、原子替换报告。原子替换不是断电等灾难下的持久性承诺。

## 保守输入与数值合同

原始类型仅接受Python int/float、普通NumPy整数和float16/32/64。拒绝bool、np.bool_、文本、复数、Decimal/Fraction、object与扩展浮点；原类型先检验，再转换。整数转float必须保持整数精确值。列表、元组或普通数值ndarray可用；矩阵2至200行、1至8列，加截距时特征最多7列；不接受ragged行或隐式reshape。文件实验固定hand、correlated、constant三个场景，各2至200行、两个特征；query也是两列且至少两行。

一般外部数值绝对值≤10⁶，非零绝对值≥10⁻¹⁰⁰。学习率0至2、梯度容差0至1、预算0至10000、参数保护1至10⁶、路径1至12条。0步长、0容差、0预算专为边界实验允许；它们不自动表示成功。迭代内部状态不再套外部1e−100下限，但计算结果仍要有限且不为非零次正规数。某些内部结果送到公共映射接口时仍需满足该接口范围，因此极端缩放可被保守拒绝。

乘积、平方、除法产生的非零下溢以及正方差转float的下溢都受检查；loss恰为0还需核对实际存储值的精确残差确为0，防止舍入制造完美拟合。浮点求和取消不保证完全消除；谱与映射仍有舍入。精确参照的浮点显示系数/损失绝对值≤10¹²且非零不低于最小正常值，否则拒绝。已经在调用前丢失的信息不能恢复。

JSON和CSV从原始十进制词元检查：非零1e−400、NaN、Infinity、重复JSON键、错列、末条坏配置均被拒绝。0e−400是真零可接受。检查使用异常而非assert，python -O不会关闭保护。
