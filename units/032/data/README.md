全部为原创确定性合成数据，不含个人资料，不代表现实任务。

cases.csv字段严格为case,x1,x2,y。每行一条样本；当前每个场景4行。hand使用u,v四角[(-1,-1),(-1,1),(1,-1),(1,1)]，x1=u、x2=10v、y=3+2u+3v+uv/2。correlated改成x1=u、x2=u+v/8；constant改成x1=u、x2=7，两者y不变。case只接受hand/correlated/constant，全部场景先验证，不因未用于GD而跳过。

query.csv字段x1,x2，当前两行(2,20)、(-2,30)。无标签，不做测试性能估计；只展示训练统计的复用。query不参与fit_scaler。x1/x2的量纲为示意单位，y为示意响应单位。

model_spec.json固定objective=SSE/(2n)，initial按原坐标[a,b1,b2]给出。scaled路径会先将同一初始预测函数转为标准化坐标。梯度阈值是每条路径自己工作坐标中的欧氏范数；报告另外给原坐标梯度和共同预测误差。原minimax步长存储最近双精度值0.019801980198019802，理论2/101与其实际存储值明确区分。

所有raw数值词元在转float前检查，拒绝非零小于1e-100、超范围、非有限或格式错误。零的指数写法可接受。Notebook锁定全部三文件的原始字节，修改格式也会改变哈希；通用脚本支持合同内自定义输入。默认数据本身全是能被二进制精确表示的整数和八分数/二分数；0.3是闭式显示的舍入结果，不是默认CSV输入。
