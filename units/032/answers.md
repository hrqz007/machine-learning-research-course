# 032 练习详解 多维梯度下降与尺度

## 1. 形状与广播

有d个特征时，X为n×d，加截距后A为n×(d+1)。令p=d+1，β和梯度为p维列向量的数学对象，NumPy采用形状(p,)；预测、y、r均为(n,)，H为(p,p)。Aᵀ形状(p,n)，所以Aᵀr形状(p,)，才能与β相减。

若预测shape=(n,)、y.shape=(n,1)，广播按尾轴对齐，差值变成(n,n)：第i行第j列实际是预测ⱼ−yᵢ，而不是逐样本配对。后续平方求和可以给出一个实数，不能靠结果是数来发现错误。答案应包含显式形状验证，而非简单reshape掩盖来源。

## 2. 链式法则与同步更新

定义ℓᵢ=(ŷᵢ−yᵢ)²/(2n)，ŷᵢ=ΣⱼAᵢⱼβⱼ。沿ℓᵢ→rᵢ→ŷᵢ→βⱼ三步，导数依次为rᵢ/n、1、Aᵢⱼ，乘积为rᵢAᵢⱼ/n。对全部样本求和即gⱼ=ΣᵢrᵢAᵢⱼ/n。

各分量排列后为g=Aᵀr/n。由于所有样本共享同一参数，贡献相加；不是逐行赋值覆盖。由于g必须是同一点βₜ的完整梯度，先用旧βₜ算所有r与g，再一次写βₜ₊₁=βₜ−ηg。用改过的b₁再算b₂导数会改变算法，其误差矩阵不再是I−ηH。

## 3. 主例闭式参照

列1、u、10v的和除截距外均0，u与v的乘积和也0。平方和4、4、400。因此AᵀA=diag(4,4,400)。逐列与y做内积，得到Aᵀy=(12,8,120)。解三个方程4a=12、4b₁=8、400b₂=120，得β*=(3,2,3/10)。

四行预测为3−2−3=−2、3−2+3=4、3+2−3=2、3+2+3=8。减去y得到(−1/2,1/2,1/2,−1/2)，平方和1，J*=1/(2×4)=1/8。最优梯度为零可再次逐列核对：残差和0，乘u后和0，乘10v后和0。

β₀=0使四条预测为0。r₀=(3/2,−7/2,−3/2,−17/2)，样本损失(r²/8)=(9,49,9,289)/32，总和89/8。

第一行ŷ₁=3/64−1/32−10×15/32=−299/64；第二行仅把10项换正，得301/64；第三行u项正、v项负，得−295/64；第四行都正，得305/64。逐行减去y得(−203,77,−391,−239)/64。平方再除8为(41209,5929,152881,57121)/32768。总和257140/32768=64285/8192。每条样本的损失并不都必须下降；整批目标下降才与当前推导对应。

## 6. Hessian与误差矩阵

gⱼ=ΣᵢAᵢⱼ(ΣₖAᵢₖβₖ−yᵢ)/n，对βₖ求导得到Hⱼₖ=ΣᵢAᵢⱼAᵢₖ/n，合为H=AᵀA/n。任意v有vᵀHv=‖Av‖²/n≥0，故半正定。A满列秩当且仅当零空间只有0，此时v≠0使上述量严格正，H正定。

最小二乘正规方程Aᵀ(Aβ*−y)=0。从g(β)=Aᵀ[A(β−β*)+(Aβ*−y)]/n消去第二项得g=He。更新后eₜ₊₁=eₜ−ηHeₜ=(I−ηH)eₜ。本题依赖训练A、y固定以及平方目标，不能直接移植到任意变化的Hessian。

## 7. 特征方向和稳定范围

对称H=QΛQᵀ。定义z=Qᵀe，左乘更新得到zₜ₊₁=(I−ηΛ)zₜ，所以第j方向zⱼₜ=(1−ηλⱼ)ᵗzⱼ₀。正定时，所有初值收敛等价于每个乘子绝对值严格小于1：−1<1−ηλⱼ<1，即0<η<2/λⱼ，交集为0<η<2/L。

η=0停住；η=2/L使最大曲率方向乘−1，不衰减；η>2/L使该方向幅度增长。初始误差恰好没有不稳定方向分量时，该单条路径可能仍收敛，因此完整表述必须带“所有初值”。初始已最优更是所有梯度更新都保持原点的例外。零特征值方向乘1，参数初值分量保留；最小二乘中它不影响训练预测。

## 8. 最坏倍率和条件数

正交Q保持欧氏范数。各方向独立，故更新算子的2范数是ρ=maxⱼ|1−ηλⱼ|，‖eₜ‖≤ρᵗ‖e₀‖。谱在[m,L]内，绝对值仿射函数凸，最大值在端点，ρ=max(|1−ηm|,|1−ηL|)。

η过小时两端都偏大；在两个端点一正一负的范围内，降低其中较大的值会直到它们相等。令1−ηm=ηL−1，得到η*=2/(m+L)，ρ*=(L−m)/(L+m)=(κ−1)/(κ+1)。这是固定标量步长、最坏初始方向、正定二次函数的结论。目标超额Σλⱼzⱼ²/2至多乘ρ²ᵗ。

主例m=1、L=100，η*=2/101、ρ*=99/101。κ=1时ρ*=0，所有特征方向同时消失。不能把这个特殊式子当作未知非二次问题的直接步长处方。

## 9. 不折返也可以很慢

η=1/100时，两个λ=1方向乘99/100，λ=100方向乘0。故b₂第一步到0.3，而aₜ=3[1−(99/100)ᵗ]、b₁ₜ=2[1−(99/100)ᵗ]仍慢。没有负乘子不等于收缩充分。

参数误差沿慢方向每轮乘0.99，其对应目标超额每轮乘0.99²=0.9801。一般整体参数误差或损失由多个方向叠加，未必每轮恰为同一个固定比值；ρ和ρ²通常是上界。主例两种非零谱分量尚未消失时，应按两项求和而不是假定单一倍率。

## 10. 平均因子与复制检验

正确g=Aᵀr/n，漏除n得到g̃=ng，更新等价于有效步长nη。主例η=1/64、n=4，有效步长1/16，陡方向乘1−100/16=−21/4，幅度增大。第一步参数=(3/16,1/8,15/8)，和正确第一步恰好差4倍。

复制每行一次后A′ᵀr′=2Aᵀr，n′=2n，因此正确平均梯度不变；求和梯度翻倍。若目标明确改为SSE/2，则乘n是有意的，同时η应除n才能匹配路径。损失定义、梯度实现、学习率必须三者一致。

## 11. 非零均值下的完整坐标变换

z=S⁻¹(x−μ)，ŷ=α+zᵀγ=α−μᵀS⁻¹γ+xᵀS⁻¹γ，所以b=S⁻¹γ、a=α−μᵀS⁻¹γ。令β=Tθ，T的第一行为(1,−μᵀS⁻¹)，其余块为(0,S⁻¹)。Aₛ=AT，于是Jₛ(θ)=J(Tθ)。

第k个新坐标导数Σⱼ(∂J/∂βⱼ)Tⱼₖ，合为gₛ=Tᵀg；再求导得到Hₛ=TᵀHT。θ更新后乘T，βₜ₊₁=βₜ−ηTTᵀg。μ=0时斜率方向有效步长η/sⱼ²；μ≠0时TTᵀ有非零截距耦合。

例如一特征μ=2、s=3，T=[[1,−2/3],[0,1/3]]，TTᵀ=[[13/9,−2/9],[−2/9,1/9]]。单看斜率除9会漏掉截距−2/9的耦合项。由于T非正交，它并不保持H的谱或梯度欧氏范数。

## 12. 标准化一步到位的逐样本复算

主例μ=0、s=(1,10)，标准化行特征为(1,u,v)。从θ₀=0出发残差仍为(3/2,−7/2,−3/2,−17/2)，损失仍89/8。截距贡献为(3,−7,−3,−17)/8，u贡献为(−3,7,−3,−17)/8，v贡献为(−3,−7,3,−17)/8，分别相加为−3、−2、−3。

η=1给θ₁=(3,2,3)，预测为3+2u+3v，即(−2,4,2,8)。新残差为(−1/2,1/2,1/2,−1/2)，每条损失1/32，总损失1/8。新梯度贡献的每列均相消，得到0。映回β₁=(3,2,0.3)。

原因是本例Hₛ=I，所有方向乘1−η。保留η=1/64时每轮乘63/64，仍慢；任意相关数据即使列方差都1，Hₛ也未必是I。一步到位既需要结构又需要选步长，不能归功于“标准化”三个字。

## 13. 共同停止指标

gₛ=Tᵀg，T改变分量尺度，所以‖gₛ‖≤τ与‖g‖≤τ不是同一条件。默认scaled_half在29轮满足工作坐标阈值10⁻⁸，但映回后原梯度约5.63×10⁻⁸。程序没有算错，只是检查了不同量。

采用E_pred=‖A(β−β*)‖/√n可保持训练预测单位一致。等价目标超额为E_pred²/2；β一定先映回原坐标。默认E_pred≤10⁻⁸首轮计数为raw_dyadic 1252、raw_minimax 999、scaled_same_rate 1268、scaled_half 29、scaled_one 1。raw_unstable未达到，不能拿19当收敛轮数。参数误差另报，并注明不同参数单位混合的欧氏范数也依赖坐标。

## 14. 相关例的谱

x₁=u，x₂=u+v/8。均值0，方差1和65/64，协方差1。标准化相关系数ρ=1/√(65/64)=8/√65。斜率H块[[1,ρ],[ρ,1]]乘(1,1)给(1+ρ)(1,1)，乘(1,−1)给(1−ρ)(1,−1)。连同截距特征值1，最小与最大为1−ρ和1+ρ。

κ=(1+ρ)/(1−ρ)≈257.996，原始约258.012。对每列单独除标准差，无法消除二列近乎相同的问题。ρ→1时小特征值趋0；ρ=1时秩缺失，不允许继续写有限κ。满列秩下H=AᵀA/n，其特征值为σⱼ(A)²/n，所以κ(H)=κ₂(A)²。

## 15. 零方差和微小负特征值

训练第二列全7，μ₂=7、方差0。定义scale₂=1，标准化训练值为0；不是把标准差误称为1，而是单独规定除数避免除0，zero_variance必须为true。query出现9时变换为(9−7)/1=2，不重新fit。

含截距的constant设计中第二特征列是截距列的7倍，因此数学秩2；标准化后成为零列，仍秩2。浮点eigvalsh可能返回约−1.1×10⁻¹⁶，精确AᵀA证明仍半正定。可报告数值与精确秩的差异，不能由舍入小负数判定非凸，也不能随意加绝对值制造正曲率保证。

## 16. 查询变换与泄漏

训练统计μ=(0,0)、s=(1,10)。query(2,20)→(2,2)，query(−2,30)→(−2,3)。标准化预测3+2z₁+3z₂分别为13和8；原预测3+2x₁+0.3x₂相同。

把query并入fit后，第二列均值变为50/6=25/3，训练均值不再0。这已经让训练处理依赖未来特征。没有标签不代表没有信息流；交叉验证必须每折只对训练fit。同一无正则、精确满秩OLS在可逆重参数化下可能保持预测，这个特殊不变性不能推广到有限步优化、正则化或其他模型。

## 17. 正则化坐标变化

原惩罚λ‖b‖²/2，在γ坐标中b=S⁻¹γ，故应变为λΣγⱼ²/sⱼ²/2。标准化坐标直接用λ‖γ‖²/2，映回原坐标则是λΣsⱼ²bⱼ²/2；它是另一个目标。

主例λ=1且截距不惩罚。原J的斜率导数为b₁−2和100b₂−30。加原L2后方程2b₁−2=0、101b₂−30=0，得b₁=1、b₂=30/101。标准化Jₛ导数为γ₁−2、γ₂−3，加普通L2后得γ₁=1、γ₂=3/2，映回b₂=3/20。

保持原问题的惩罚是(γ₁²+γ₂²/100)/2，第二方程γ₂−3+γ₂/100=0，得γ₂=300/101，映回30/101。三种模型截距都是3。原L2四条预测为(2−300/101,2+300/101,4−300/101,4+300/101)；标准化普通L2预测为(0.5,3.5,2.5,5.5)，确实不同。

## 18. 失败测试的完整思路

原始类型：分别给y、X、初值或学习率传True、np.bool_、复数、object数组、longdouble、Decimal、Fraction、字符串、NaN、Infinity；应在转float前失败。形状：列向量y、ragged行、缺列、样本数不匹配应失败。数值：直接函数接收的1e−101越过下限；文件中的非零1e−400需在原词元上拒绝；0e−400可被识别为真实零。

完整输入顺序：坏值放在最后一条路径、query最后一格或constant场景最后一行，所有数值计算函数替换成“若调用即报错”的测试哨兵，确认失败先由验证触发。JSON重复键和NaN必须拒绝。输入检查不写assert，-O模式仍逐项生效。

轨迹：初值已满足容差时0轮成功；非最优初值且预算0为budget_exhausted；η=0且梯度非小为stagnated_without_tolerance；已存状态再次出现形成两点循环时单独标示；下一候选超限则parameter_limit_reached，history不记录未提交候选。每种情况下记录数=完成更新+1。

输出：先给旧报告写sentinel，再用坏数据运行，退出非0、stdout无数值，旧内容保持。坏输入指向新目录时不建目录。源CSV、配置、脚本和包内正文被指定为输出时拒绝。最后从两个当前目录分别执行普通和-O新进程，四份完整JSON字节相同，再重启真实内核逐格执行Notebook。固定Notebook须先核对全部默认字节，不能在检查之前先画一个静态“正确答案”。这些有限检查能发现具体错误，并不等于形式证明或独立审查通过。


### 一个可直接运行的输出保护检查

在本讲目录启动Python，下面只在新的临时目录制造坏配置和旧报告，不改动包内输入。将末条学习率改成原始词元1e-400，测试的重点是“不能转成0后当合法停滞实验”。正常与-O各运行一次；任何非预期接受、数值输出、覆盖旧文件或创建新目录都使测试失败。

```python
from pathlib import Path
import subprocess, sys, tempfile
import experiment as e
script = Path(e.__file__).resolve()
raw = (script.parent / "data/model_spec.json").read_text()
with tempfile.TemporaryDirectory() as temporary:
    folder = Path(temporary)
    bad = folder / "bad.json"
    bad.write_text(raw.replace("0.03125", "1e-400"))
    for options in ([], ["-O"]):
        old = folder / "old.json"
        old.write_text("sentinel")
        fresh = folder / "must_not_exist" / "report.json"
        for target in (old, fresh):
            result = subprocess.run(
                [sys.executable, *options, str(script),
                 "--config", str(bad), "--output", str(target)],
                cwd=folder, capture_output=True)
            e.require(result.returncode != 0, "bad input accepted")
            e.require(result.stdout == b"", "unexpected numeric output")
        e.require(old.read_text() == "sentinel", "old output changed")
        e.require(not fresh.parent.exists(), "new directory created")
print("Both modes preserved outputs")
```

该小检查不是完整审计的替代：还要分别覆盖CSV、query、重复键、原类型、形状和所有停止状态。正向运行也不可省，否则一个永远报错的程序同样会通过上面的负向测试。把正确运行与失败保护配对，才说明接口既能做任务，也能在不支持的输入上诚实停止。
