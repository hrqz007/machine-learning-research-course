# 046 分类指标与排序评价答案

本答案册对应讲义练习 E1 至 E10、读图题 G1 至 G9、实验题 L1 至 L10。所有答案使用同一份12行固定教学数据；阳性标签为1；判定规则为评分大于等于阈值。混淆矩阵始终按行是真实、列是预测、类别顺序为0和1。

## 1 讲义练习的完整答案

### E1 两个决策怎样比较

阈值0.55时，A、B、C、D、E、F、G预测阳性，H、I、J、K、L预测阴性。A、C、G是TP，共3；B、D、E、F是FP，共4；没有FN；H到L是TN，共5。因此：

$$
P=3/7,\quad R=3/3=1,\quad F_1=6/(6+4)=3/5.
$$

准确率为 $(3+5)/12=2/3$，FPR为 $4/9$。全预测阴性时 TP = FP = 0，FN = 3，TN = 9，准确率为3/4，召回率和F1为0，精确率未定义并按本讲约定报告为0。较高准确率没有找出任何缺陷，故不能脱离任务说它更好。

与0.80相比，0.55把E、F、G三个原先预测阴性的记录改为阳性；新增2个FP、1个TP。召回从2/3升为1，精确率从1/2降到3/7，F1从4/7升到3/5，准确率从3/4降到2/3。方向可以不同，不矛盾。

### E2 两个不同的条件

0.80处精确率为 $2/(2+2)=1/2$，含义是“在预测阳性的4件中，真实阳性占比”。$1-\mathrm{FPR}=1-2/9=7/9$ 是特异度，含义是“在真实阴性的9件中，被正确预测阴性的占比”。分母一个是预测阳性，一个是真实阴性，没有一般恒等式。

用条件概率记号，前者为经验 $P(Y=1\mid\hat Y=1)$，后者为经验 $P(\hat Y=0\mid Y=0)$。互补关系只在相同条件下成立：$1-P$ 是 $P(Y=0\mid\hat Y=1)$，不是 FPR。

### E3 阈值区间和等号

按 $s\ge t$，选中A、B、C、D且不选E的必要条件为：C、D评分0.80不低于阈值，所以 $t\le0.80$；E评分0.70必须小于阈值，所以 $t>0.70$。合起来为 $t\in(0.70,0.80]$。

若规则改为 $s>t$，C、D入选要求 $t<0.80$，E不入选要求 $t\ge0.70$，所以变成 $[0.70,0.80)$。改变比较运算符而仍报告同一个0.80阈值，会实际排除C和D；不能把这个实现差异藏起来。

### E4 两条独立路径重算 AUC

非零梯形贡献：B对应 $1/27$；C、D同分组对应 $1/18$；E、F各对应 $2/27$；H至L五个阴性合计 $5/9$。统一到分母54，是 $2/54+3/54+4/54+4/54+30/54=43/54$。

配对路径：A胜9、平0、负0；C胜7、平1、负1；G胜5、平0、负4。合计胜21、平1、负5，共27。给平局半分得 $(21+1/2)/27=43/54$。

若平局算0分，AUC变成 $21/27=7/9$，比正确值低 $1/54$；若平局算1分，变成 $22/27$，比正确值高 $1/54$。半分与经验ROC中同分组斜线的梯形积分一致；它不表示把并列阳性偷偷排在前面。

### E5 两种 PR 面积

AP按召回增量乘该步精确率。只有A、C和G入选的组增加召回，每次增1/3，精确率分别1、1/2、3/7，所以 AP = $1/3+1/6+1/7=9/14=81/126$。

梯形PR面积三段有宽度的贡献为 $1/3$、$1/6$ 和 $\tfrac13(\tfrac13+\tfrac37)/2=8/63$。相加为 $79/126$，比AP小 $2/126=1/63$。G入选这一步精确率上升，前后平均精确率小于步后精确率，所以这里梯形比AP矩形小。只有阴性入选的垂直PR段宽度为0，不贡献面积，但仍反映阈值下的精确率变化。

不能把这两个数都叫同一种“PR-AUC”而不说明积分约定，也不能断言梯形插值始终更高。结果依赖精确率变化轨迹；本例是一个明确反例。

### E6 阳性率为0.10的完整重算

原阳性率 $\pi_0=1/4$，新阳性率 $\pi=1/10$。阳性权重 $w_+=(1/10)/(1/4)=2/5=0.4$，阴性权重 $w_-=(9/10)/(3/4)=6/5=1.2$。0.80处四格为：TP = $2\times0.4=0.8$，FP = $2\times1.2=2.4$，FN = 0.4，TN = 8.4，总权重12。

精确率 $0.8/(0.8+2.4)=1/4$；召回率 $0.8/(0.8+0.4)=2/3$；FPR = $2.4/(2.4+8.4)=2/9$；F1 = $1.6/(1.6+2.4+0.4)=4/11$。准确率为 $(0.8+8.4)/12=23/30$。最后两个数非题目必需，但能提醒你其他阈值指标也可能改变。

用贝叶斯形式核对：$\pi a=(1/10)(2/3)=1/15$，$(1-\pi)b=(9/10)(2/9)=1/5$，精确率为 $(1/15)/(1/15+1/5)=1/4$。

A、C、G三组的步后精确率分别为1、1/4、1/5，AP = $(1+1/4+1/5)/3=29/60$。ROC每个点保持不变，AUC仍为43/54。这里保持的是两类各自内部的评分分布；真实数据若有类内变化、标签噪声改变或选择偏差，则没有这个保证。

### E7 平均顺序决定问题

类别0作为关注类时，TP0 = 7、FP0 = 1、FN0 = 2，故 precision0 = 7/8，recall0 = 7/9，F1,0 = 14/17。类别1的相应值为1/2、2/3、4/7，支持度分别为9和3。

宏 F1 = $(14/17+4/7)/2=83/119$。微平均合并后 TP = 9、FP = 3、FN = 3，所以 micro P = micro R = micro F1 = 3/4。支持度加权 F1 = $(9\cdot14/17+3\cdot4/7)/12=181/238$。

一般证明：完整单标签任务中，每个正确预测给真实类带来一个TP，每个错误预测给被预测类一个FP、给真实类一个FN。若正确数为 $c$，错误数为 $n-c$，合并后的 F1 为 $2c/[2c+(n-c)+(n-c)]=c/n$，即准确率。若排除类别、多标签或拒识机制改变计数，此证明的前提不再满足。

宏 P = 11/16，宏 R = 13/18。它们的调和平均为 $2(11/16)(13/18)/(11/16+13/18)=143/203\approx0.704433$，不等于宏 F1 的 $83/119\approx0.697479$。这直接展示“先平均”与“先做非线性运算”不可交换。

### E8 排序与概率不是同一种质量

立方函数在 $[0,1]$ 严格递增，所有大于、等于、小于关系都保持。因此ROC AUC和AP不变。若希望保留原 $s\ge0.80$ 的预测，应改为 $s^3\ge0.80^3=0.512$，仍选A、B、C、D。

若在变换后仍用0.80，只有A的 $0.95^3=0.857375$ 越过阈值，B的 $0.90^3=0.729$ 未越过，C和D都为0.512。此时TP = 1、FP = 0、FN = 2、TN = 9，P = 1、R = 1/3、F1 = 1/2、accuracy = 5/6，显然不是原行动规则。

对数损失和Brier关心概率数值。一个真实阳性被赋0.95与0.857375，虽次序不变，所受惩罚仍不同；阴性亦然。AUC无法识别这个差异。因此高AUC不能证明评分已校准；基于概率与错误代价选择阈值还需要概率可信、代价明确、评价总体匹配。

### E9 修正研究流程

应先明确主目标和约束，如“在复核容量内优先提高召回率”，或预先指定阳性F1；用独立验证集选阈值与并列选择规则，再锁定阈值，在未参与选择的测试集报告结果。已经看过测试集并挑阈值，就不能把这同一测试集的最高值当作未选择偏差的性能估计。可以诚实标成探索性结果，并另找新的封存测试或采用恰当嵌套设计。

比较不同数据集的AP时，报告各自阳性率、样本构成、标签定义、采样方案和不确定性。若有充分理由假设类条件评分分布稳定，可在共同目标阳性率下重加权做敏感性比较；必须展示假设和权重，不能偷偷改阳性率。AP差异本身不足以归因于排序模型变好或变坏。

一份改进报告应同时给出固定阈值混淆矩阵和P/R/F1、完整排序指标、每类支持度与平均方式、阈值选择来源、数据限制。不要用增加指标数量代替对主结论的限定。

### E10 四种端点情况

全部同分且两类存在：可实施的纯分数决策只有全阴性和全阳性；AUC = 1/2，AP = 阳性率1/4。ROC端点间的直线是积分与混合解释，不能靠另选数值阈值实现所有中间点。

无警报但两类存在：TP = FP = 0，recall = 0，F1 = 0，accuracy = 阴性率；precision = 0/0未定义。本讲标量填0并保留未定义标志；PR画图额外端点用1，二者服务不同目的。

全部预测阳性：TP = 3、FP = 9、FN = TN = 0，precision = 1/4，recall = 1，FPR = 1，accuracy = 1/4，F1 = 2/5。

没有真实阳性：召回率分母为0，阳性阴性配对无法形成，ROC AUC失去两类条件。本包装函数拒绝这种输入，不能伪造一个阳性补齐。实际报告应标为不可估或依据预先定义的规则处理，而非把库返回约定当作有信息的性能。

## 2 九幅图的完整解读

### G1 固定评分图

C和D的分数相同。只依赖分数和同一阈值的规则没有理由区别对待它们，所以必须同时入选或同时不入选。用真实标签决定先后会泄露评价答案。评分处于0到1并不说明已经校准，不能从0.95直接推断A有95%的真实缺陷概率。

### G2 两个混淆矩阵

新进入E、F、G，其中E、F是阴性，G是阳性。TP由2变3，FP由2变4，FN由1变0，TN由7变5。准确率从9/12降为8/12，召回从2/3升为1。矩阵展示原始计数，而不是按不同分母归一化后难以比较的颜色。

### G3 阈值图

0.60到0.55时，精确率从2/6升为3/7。最高F1为3/5，出现在0.55决策；最高准确率为10/12，出现在0.95决策。图中横轴按不同阈值依次排列，不是连续均匀评分刻度。若这是测试集，看到最高点只能作描述，不能用该点同时选择阈值并声称得到无偏测试成绩。

### G4 ROC图

横坐标是“真实阴性中误报的比例”，所以分母为9。2/4是警报中的假阳性比例，等于 $1-P$，不是FPR。整体AUC相同的两条ROC可以在局部交叉；尤其当部署只容许极低FPR时，必须考察那个区域的工作点、样本支持和不确定性。12行数据中最小非零FPR已是1/9，不能凭插值宣称准确估计0.01处性能。

### G5 配对矩阵

交换C和D在文件中的顺序不改变分数和标签配对，27个比较关系完全不变。AUC仍为43/54。把平局算全胜使总分增加1/2，AUC增加 $(1/2)/27=1/54$。正确的同分约定要写在协议里，而非由排序库偶然返回顺序决定。

### G6 PR面积图

G加入时，前一个点精确率为1/3，后一个为3/7。AP使用后值3/7覆盖召回增量1/3；梯形用前后平均，后者较小。其他有召回增量的段没有造成差异，因此 AP 比梯形面积大1/63。全同分全部一次入选，召回从0跳到1，步后precision为1/4，所以AP=1/4。

### G7 先验变化图

不能仅凭precision变低判定排序器退化。该实验没有改变任何类内评分顺序或分布，只增加阴性在混合人群中的比例。50%阳性率验证集上的precision为3/4，不能直接搬到10%人群；后者在相同TPR/FPR下只有1/4。还需验证类内稳定假设，若不成立就连这个换算都不能保证。

### G8 平均方式图

0.7605是支持度加权F1，受数量更多且较易识别的阴性类别影响。阳性F1只有0.5714。只写一个F1值会隐去任务关注类和权重。列每类F1与真实支持度，可以看到各类表现差异，并解释为什么macro、micro、weighted不同。任何一种汇总都不会替代任务定义。

### G9 概率和排序图

立方变换改变分数的数值尺度。相同数值0.80不再代表同一组记录；需把阈值也变为0.512才维持原决策。AUC不依赖阈值，也不识别概率是否校准，故不能单独确定期望代价最小的部署行动。图中log loss和Brier是损失，越低越好；不能因某个损失柱比AUC柱矮就说性能更差。

### L3 精确率并非单调

0.70到0.60加入阴性F，TP仍为2，预测阳性从5增为6，所以P从2/5降为1/3；真实阳性被找到的数量没变，R仍为2/3。0.60到0.55加入阳性G，P从2/6变为3/7，R从2/3升到1。“必然”不成立：降低阈值会让入选集合扩大，但新进入的标签构成决定精确率方向。

### L4 端点和数组方向

ROC阈值为 `[inf, 0.95, 0.90, 0.80, 0.70, 0.60, 0.55, 0.50, 0.40, 0.30, 0.20, 0.10]`，两个坐标数组也各有12项。正无穷对应全预测阴性的原点。

PR阈值为 `[0.10, 0.20, 0.30, 0.40, 0.50, 0.55, 0.60, 0.70, 0.80, 0.90, 0.95]`。Precision/Recall各有12项，第一个坐标为 $(P,R)=(1/4,1)$，最后一个为 $(1,0)$，末点无阈值。ROC阈值降序、PR阈值升序，若按同一索引拼接会将不同决策错配。应按真实阈值值匹配，或明确反转并处理额外端点。

### L5 独立参照为什么有用

A胜9平0负0；C胜7平1负1；G胜5平0负4，得到43/54。全同分每一对给半分，AUC=1/2；AP只有一个召回增量为1的组，精确率=3/12，因此AP=1/4。

独立枚举没有复用待检查的扫描代码，能发现双方同一实现缺陷。分数用原始整数比较，分数计算用Fraction，因此手算锚点是精确值。两类都存在是ROC与配对解释的必要条件；没有真实阳性时无法形成阳性阴性配对，包装函数提前拒绝更清楚。

### L6 阳性率敏感性

权重分别0.4与1.2，四格TP=0.8、FP=2.4、FN=0.4、TN=8.4；P=1/4、R=2/3、FPR=2/9，AUC=43/54，AP=29/60。贝叶斯重算步骤见E6，它不需要再调用曲线库。

三个阳性进入步骤的精确率1、1/4、1/5，平均后29/60。改变的是不同类别的混合比例，未改变每类内部的评分分布。因此precision下降不能归因于排序器退化；若现实场景连类内分布也变了，则需新的评价数据。

### L7 四种 F1

依次是阳性 F1 = 4/7≈0.571429，macro = 83/119≈0.697479，micro = 3/4=0.75，weighted = 181/238≈0.760504。阳性F1关注指定事件，macro给两类同等权重，micro合并所有类别计数，weighted按真实支持度加权各类F1。支持度是标签数量9与3，不是模型预测为各类的数量8与4。

### L8 立方变换的结果

AUC和AP仍为43/54、9/14。固定数值0.80只选A，四格变为TP=1、FP=0、FN=2、TN=9；映射阈值0.512选A、B、C、D，恢复TP=2、FP=2、FN=1、TN=7。

实际概率损失由库计算：原评分log loss为0.7328093503，Brier为0.2579166667；立方后分别为0.4616158711和0.1609851276。`experiment-result.json` 与Notebook同时保留这些值，不需靠肉眼估柱。改变后分数更靠近0：部分阴性误判损失减小，一些阳性的损失增大。总体损失是这些变化的合计，不是单凭“更极端”三个字就能判断方向。精确运行数值见随包结果；本例的立方变换使log loss和Brier均下降，但没有建立对真实总体的校准结论。

### L10 示例报告与失效条件

可接受的示例：“对12件合成零件的固定评分，缺陷为阳性，共3件。按评分≥0.80触发复核，TP=2、FP=2、FN=1、TN=7，阳性P=1/2、R=2/3、F1=4/7。按同分组扫描全部阈值，ROC AUC=43/54，非插值AP=9/14。F1使用binary方式，未作测试集阈值优化；样本只用于教学，不代表生产总体。”

失效条件可以举：在同一批评价标签上选最佳阈值却不披露；把0.80的比较从大于等于改成严格大于；把支持度加权F1误标成阳性F1；更换阳性率却直接声称AP变化来自模型；删除困难样本；按真实标签破除同分。任意一个都改变了原协议或结论范围。

## 4 自检后的结论边界

代码通过、Fraction参照一致、图像与表格一致，证明的是本包约定下计算实现与展示的一致性。它们不证明数据有代表性、标签无偏、真实部署效果稳定或某个阈值适合业务。正式研究还要检查样本设计、依赖结构、不确定性、阈值选择过程、目标人群与真实代价。

本讲最重要的检查顺序是：先确认问题与分母，再确认计数和阈值，接着确认排序与面积约定，最后讨论一个数字可以支持到什么程度。答案不是“总有一个万能指标”，而是能说清每个数字实际回答的是什么问题。
