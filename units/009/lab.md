# 向量内积与距离 实验手册

第九讲 从手算投影到可解释的近邻距离

本实验用同一个二维例子核对内积、范数、夹角与投影，并比较单位改变前后的近邻排名。你需要第五讲的 NumPy 形状、轴和广播，以及第八讲的代数、求和与条件判断，不需要微积分。全部输入都是小型合成数据，CPU 离线运行，无 API、无付费服务、无外部数据下载。

完成后应能解释：投影系数、投影向量与残差各是什么；为什么零向量有长度却没有角度；为什么改计量单位可能改变未经尺度处理的近邻；为什么有限次数的程序检查不能代替数学证明。

## 二 纸笔答案必须先写

写下 $x=(4,1)$、$y=(3,4)$，在不看代码输出时完成以下计算：

- 内积：先把相同位置相乘，再求和。
- 两个向量的平方长度与 L2 长度。
- 投影系数：内积除以方向向量 y 的平方长度。
- 投影向量：系数乘以 y。
- 残差：原向量 x 减去投影。

正确答案应为：内积 16，平方长度 17 与 25，投影系数 16/25，投影 `(48/25,64/25)`，残差 `(52/25,-39/25)`。不要只记下小数 0.64；分数使每一步的精确关系更容易追踪。

再算残差与 y 的内积，应恰为零。计算投影与残差的平方长度，应为 256/25 和 169/25，相加为 17。若某一步不符，先检查是否把分母误写成 x 的平方长度。程序中一个“看起来差不多”的系数不能替代这项核验。

## 三 使用 Fraction 保留有理数答案

Python 标准库中的 Fraction 表示分数。用整数构造，例如 `Fraction(16,25)`，可以保持这次计算中的有理数精确值。不要先计算近似小数再塞入 Fraction，然后假定它自动恢复原来的简单分数。

```python
from fractions import Fraction
xf = [Fraction(4), Fraction(1)]
yf = [Fraction(3), Fraction(4)]
dot = sum(a*b for a,b in zip(xf,yf))
yy = sum(v*v for v in yf)
coefficient = dot / yy
projection = [coefficient*v for v in yf]
residual = [a-b for a,b in zip(xf,projection)]
print(dot, coefficient, projection, residual)
```

这里仍然在做第四讲熟悉的函数调用、循环和列表构造，没有新增模型训练。Fraction 能精确处理这些有理数，不意味着它把任意平方根或任意实数都变成了有限分数。例如根号 17 不是有理数，本讲仍以数学符号或近似浮点数表示它。

## 四 对照数组与标量输出

在 Notebook 中创建一维数组 `x` 和 `y`，确认两者 shape 都是 `(2,)`。分别查看 `x*y`、`(x*y).sum()` 和 `np.dot(x,y)`。前者为 `[12,4]`，形状 `(2,)`；后两个为数值 16，输出是标量。

```python
import numpy as np
x = np.array([4.,1.])
y = np.array([3.,4.])
print("逐元素乘积:", x*y)
print("求和后的内积:", (x*y).sum())
print("一维 dot:", np.dot(x,y))
print("L1 与 L2:", np.abs(x).sum(), np.linalg.norm(x,ord=2))
```

L1 应为 5，L2 应约为 4.1231056。随后核对两点 x 与 `(1,5)` 的差向量为 `(3,-4)`，L2 距离 5，L1 距离 7。距离与平方距离不同；0、1、2 三个一维点能显示平方距离不满足三角不等式，不能因为两者常给出同样近邻排名就混用性质。

## 五 投影与最近点恒等式

用浮点数组重做纸笔投影，得到系数 0.64、投影 `[1.92,2.56]`、残差 `[2.08,-1.56]`。残差与方向的内积应在很小的舍入容差内接近零，平方长度分解应在容差内相等。

```python
from experiment import project_line, dot_checked
alpha, p, r = project_line(x,y)
assert p.shape == r.shape == x.shape
np.testing.assert_allclose(p,[1.92,2.56],rtol=0,atol=1e-12)
np.testing.assert_allclose(dot_checked(r,y),0,rtol=0,atol=1e-12)
```

选择几个系数 c，例如 -2、0、0.5、0.64、1、2，分别核对：左侧是 `x-c*y` 的平方长度，右侧是残差平方长度加上 `(alpha-c)**2` 乘 y 的平方长度。它们应一致，且每个候选的平方距离不小于最佳残差平方长度。

这几次检查用于验证程序实现。覆盖任意实数 c 的理由来自讲稿中的恒等式以及非负平方，不来自“六个点都通过”。把“数值核验”和“数学证明”在实验记录中分成两句话。

把方向 y 换成 2y、-3y，再次投影。投影点应不变，系数分别除以 2 和 -3。原因是过原点的整条直线没有改变。若结果跟着方向长度改变，检查是不是漏除了方向平方长度。

## 六 归一化 角度与安全边界

y 的单位方向应为 `[0.6,0.8]`。正倍数归一化后不变，负倍数反向。检查三个基准角：同向为 0 度，垂直为 90 度，反向为 180 度。主例 x 与 y 的余弦约为 0.776114，夹角约为 39.093859 度。

```python
from experiment import unit_direction, cosine_checked, angle_degrees
print(unit_direction(y))
print(cosine_checked(x,y))
print(angle_degrees(x,y))
```

`np.arccos` 返回弧度，本实验用 `np.degrees` 转为度。不要把弧度数直接贴上度数符号。归一化内积只记录 0 到 180 度的非负夹角，不给出顺时针或逆时针方向。

测试零向量时，应拒绝归一化和角度，不能把它默认解释为 90 度。投影方向为零也应拒绝；被投影的 x 为零而 y 非零则完全合法，结果为零。

浮点夹取只处理已验证公式中的极小越界。实验函数允许 `1+5e-13` 在明确容差内夹回 1，却拒绝 1.01 与非有限数。若你把所有余弦结果无条件 `clip` 到范围内，可能掩盖维数错误、公式错误或异常数值。不要把“没有 nan”当成算对的证据。

随附程序还演示极端浮点范围。单位方向采用先缩放再平方的方法，可处理 `[1e-300,0]` 这类很小非零输入；直接投影分母发生数值下溢时会报告应重新缩放方向。大数乘积溢出也明确报错。其余小规模实验使用温和数值，不把这些教学函数当成适用于所有极端范围的通用数值库。

## 七 批量结果必须保留样本轴

构造三行两列的非方阵：`X=[[4,1],[1,-2],[0,0]]`。每一行是一个二维向量。与方向 y 分别求内积，应得到 `[16,-5,0]`，形状 `(3,)`。批量投影系数形状 `(3,)`，投影与残差形状都为 `(3,2)`。

```python
from experiment import row_dots, row_projections
X = np.array([[4.,1.],[1.,-2.],[0.,0.]])
before = X.copy()
coefficients, projected, residuals = row_projections(X,y)
print(row_dots(X,y))
print(coefficients.shape, projected.shape, residuals.shape)
np.testing.assert_array_equal(X,before)
```

内部系数乘方向时使用 `coefficients[:,None] * y`，因为这一次确实要给每个样本生成 d 个投影分量。第五讲的广播陷阱说明不是所有补轴都有错，而是必须解释补出的轴代表什么。最终应逐行与 `project_line` 的结果比较，不能仅比较所有元素的总和。

再传入 `X[:1]`，结果仍应保留一个样本，系数 `(1,)`、投影 `(1,2)`。传入 `X[0]` 则不符合批量接口，应拒绝。单特征批量也要保持 `(n,1)`，不能随意压平。使用非方阵能帮助发现轴混淆，使用单样本能帮助发现索引丢轴。

NumPy 的 `np.linalg.norm(X,ord=2,axis=1)` 表示每行一个向量的 L2 范数；不指定 axis 时对二维输入可能进入矩阵范数语义，不是本讲要的逐样本长度。先问输出应该有几个数，再选择轴参数。

## 八 改单位 重算排名

查询 Q 为 `(50,5)`，候选 A 为 `(51,15)`、B 为 `(56,6)`。第一列面积平方米，第二列楼龄年。原始数值距离约为 A 的 10.049876、B 的 6.082763，因此 B 更近。

把面积乘以 100 转为平方分米，查询和候选必须一起改。未经尺度处理的距离约为 A 的 100.498756、B 的 600.000833，因此 A 更近。数据的物理信息没变，是原始数字的距离权重变化了。这两个原始距离混合了不同单位，没有统一物理长度单位。

```python
from experiment import row_distances
Q = np.array([50.,5.])
candidates = np.array([[51.,15.],[56.,6.]])
factor = np.array([100.,1.])
scales = np.array([10.,5.])
old = row_distances(candidates,Q,scales)
new = row_distances(candidates*factor,Q*factor,scales*factor)
np.testing.assert_allclose(old,new,rtol=0,atol=1e-12)
print(old,new)
```

同步把面积参考尺度 10 平方米改为 1000 平方分米后，无量纲距离保持 A 约 2.002498、B 约 0.632456。只有数值单位改变时，尺度也必须同单位变化。主动把尺度改成其他物理大小则是改变距离定义，不是纯粹单位转换。

再试参考尺度含零、负数或错误长度，接口应拒绝。不要用完整数据偷偷估计尺度后再宣称评估没有泄漏；本讲尺度由教学例子事先规定，数据驱动尺度的训练边界留给后续流水线。
