# 第九讲 向量内积与距离

核心问题：多个特征怎样成为几何对象，相似与大小如何定义？

直接先修为第五讲 NumPy 数组、第八讲函数与代数。本讲依次建立实向量、线性组合、内积、L1/L2 范数、距离、正交、直线投影、Cauchy-Schwarz、三角不等式、归一化和夹角，最后解释单位和参考尺度怎样改变近邻比较。不需要微积分。

## 运行

在本讲文件夹中，用已激活的 Anaconda 环境运行：

```bash
python experiment.py --output my-test-result.json
```

应显示 status=passed、checks=17。运行只需 NumPy 与 Python 标准库，CPU 离线，无 API 或付费接口。已核验 Python 3.12.14、NumPy 2.3.5。Notebook 还需要本机已有的 Jupyter 与 Python 内核。

关键答案为：内积 16；投影系数 16/25；投影 `(48/25,64/25)`；残差 `(52/25,-39/25)`；平方长度分解 `17=256/25+169/25`；夹角约 39.093859 度。面积换单位会翻转未经尺度处理的近邻排名，同步转换参考尺度后无量纲距离不变。

## 输入与数值范围

向量输入使用非空 `(d,)` 实数数组，批量输入使用非空 `(n,d)`，样本维度与特征维度必须明确。列表与元组在转换前递归拒绝布尔值，布尔 dtype 数组也拒绝。已有数值 dtype 的 ndarray 只按当前数值类型验证，无法恢复它之前是否由布尔值构造。字符串、复数、空输入、非有限数、非正尺度与错误形状均拒绝。

零向量的长度、距离和作为被投影对象的输入合法；作为单位方向、角度输入或投影方向则不合法。本讲程序限定实向量，没有实现复数共轭内积。

程序为小规模教学计算设计。单位方向和单向量 L2 使用先缩放的方法；直接内积、批量距离平方与直接投影公式仍受 float64 范围与舍入限制。投影方向分母数值下溢、大数乘积溢出会在相应测试中明确报告。这里不承诺覆盖所有极端数值范围。
