# 第九讲数据字典

vectors.csv 保存本讲无量纲二维几何坐标，component_1 是横坐标、component_2 是纵坐标。它们是数学演示向量，不对应真实人物或房屋。x 为被投影向量，y 为非零方向，z 用于距离，orthogonal_to_x 与 x 正交，zero 为合法零向量。

houses.csv 全部为合成教学记录。area_m2 为面积，单位平方米；age_years 为楼龄，单位年；Q 是查询，A、B 是候选。它们不含价格或预测标签，不用于说明真实近邻效果。

面积换为平方分米时，将第一列乘以 100，楼龄不变。参考尺度事先设为 10 平方米与 5 年；换单位时面积参考尺度同步设为 1000 平方分米，楼龄尺度仍为 5 年。尺度没有从测试数据估计。

脚本和 Notebook 直接写出这些小型数据，使计算与纸笔对应。CSV 用于人工核对、复用和后续读表练习。没有外部下载或私有数据。
