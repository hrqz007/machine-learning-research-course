## 1 先写实验问题，再打开代码

本实验比较三种正态随机游走步长，其他条件保持一致：目标后验、四个起点、每链总长度14000、预热2000、保留12000、对应链随机种子7800到7803。这里改变的原因变量是提议步长，观测的结果是接受率、轨迹、ESS、split-Rhat与解析均值误差。这样的受控计算比较有助理解机制，但不是关于真实人群或设备的因果研究。

预先写下三个预测：步长太小会怎样影响移动距离；步长太大会怎样影响拒绝次数；四链初值不同会怎样暴露探索不充分。不要先看指标再编一个看似准确的解释。合理预测可以被结果否定，实验报告应保留这一过程。

另有两组对照。重要性采样比较提议标准差0.2与2，测试覆盖不足和权重退化。Gibbs比较相关系数0.2与0.95，测试后验几何如何影响逐坐标更新。三种算法不共享一种ESS含义：重要性采样看权重集中，MCMC看时间相关。

## 3 数据与解析基准

八个无单位读数的总和为8.4，样本均值为1.05。先验N(0,4)稍微把后验均值向0收缩，得到1.01818。噪声方差1与先验方差4都被当作已知，这会低估现实中未知噪声时的完整不确定性；本实验只验证当前指定模型，不泛化为真实测量方案。

动手步骤：先不用采样器，手算精度8+1/4=8.25；再取倒数得到后验方差；最后乘读数总和得到后验均值。将你的结果与analytic_posterior比较。若此处不一致，先修复数学或数据读取，不能继续拿错误基准评判采样器。

```python
import json
from pathlib import Path
from samplers import analytic_posterior
model = json.loads(Path('data/model.json').read_text())
mean, variance = analytic_posterior(model['observations'])
print(mean, variance, variance ** 0.5)
```

输出应接近1.0181818、0.1212121、0.3481553。这里函数默认噪声和先验尺度与数据文件一致；若修改数据文件中的尺度，需要显式传入noise和prior_sd，不应只改元数据却沿用旧默认值。本讲固定实验未更改这些尺度。

## 4 先审计一个MH更新

打开metropolis函数，找到四个动作：提出候选、计算对数密度差、随机接受、记录状态。检查记录语句是否在if块外。如果只记录接受分支，返回的就不是原转移核对应的时间序列。通过统计相邻相同状态数，可以验证拒绝确实保留；相同值在连续随机游走里主要来自拒绝。

然后检查种子创建位置。每条链只应创建一次生成器，不应在循环内部反复重置种子。相同设置和同一种子应逐元素重现同一数组；不同种子则是不同随机实现，不要求每个摘要指标完全相同。固定种子便利调试，但不能代替独立种子下的稳健性分析。

运行normal目标测试，它检查采样均值接近0、方差接近1。阈值是确定种子下足以发现明显实现错误的工程容差，不是统计定理。测试通过说明这些受控例子符合预期，不能证明任何新目标都混合充分。

## 5 比较三个步长，先看轨迹再看合并均值

读取outputs/result.json中的mh。为每组整理四链接受率、各链ESS、split-Rhat、均值误差和两个标准误。tiny组的四链在保留阶段仍偏离，合理组在同一区域反复往返，huge组出现停留平台。图中为减小文件体积每8步显示一次，但诊断使用全部12000步，不能把绘图降采样误认为算法抽稀。

固定结果中，合理步长均值约1.02177，误差0.00359；tiny组均值约1.08908，看起来差距不算夸张，却是不同方向的严重链偏差在平均后部分抵消。单独一个平均值会隐藏问题。tiny组split-Rhat约6.305，因此即使均值偶然更接近真值，也不能通过验收。

huge组split-Rhat约1.004，比tiny组好得多，但每链ESS仅约182–322，比合理步长少近一个数量级。诊断接近1与计算效率高低又是两个问题。如果任务要求很小的MCSE，huge组仍需更多计算或更好的提议。

## 6 验证“相关不等于独立”

合理组naive_se约0.00158，mcse_heuristic约0.00340。请手动重新计算：每条链样本方差除该链ESS得到其均值方差近似；四条独立链等权平均的方差是这些量之和再除16；最后开平方。独立链的随机种子不同，初值不同；但这仍依赖各链混合前提及ESS估计的质量。

改变max_lag为500、1000、2000，观察tiny组ESS是否敏感。缓慢衰减的相关被过早截断可能使ESS偏乐观；非平稳又使ACF本身难以解释。正确结论是诊断范围不足或运行不合格，而不是挑选给出最好ESS的max_lag。

扩展实验可重复10个独立种子，检查均值误差的经验波动是否与MCSE量级一致。预先固定预算和报告全部种子，不能看到某次结果差就只换种子重跑直到满意。这是区别可复现实验与结果筛选的关键。

## 7 重要性采样与Gibbs对照

对重要性采样，先画目标和提议密度。标准差0.2的提议虽然支持整条实线，但目标中心1.018距离它自身均值超过五个提议标准差。有限12000次抽样往往找不到足够目标主体。报告均值0.6044、权重ESS约28以及最大归一化权重0.0905时，应把它称为覆盖失败，不是“后验说明θ偏小”。

对Gibbs，检查rho=0.95对应的条件标准差√(1−0.95²)约0.31225。把它与边缘标准差1比较，就能理解为何逐坐标更新很小。输出经验协方差应接近[[1,ρ],[ρ,1]]，但相关越强，有效样本越少，经验误差可能更明显。不要强行要求两个ρ设置的经验均值相同。

选做：将系统扫描改为同时使用旧x、旧y更新，然后比较经验协方差。先写出这已经改变算法，再运行受控对照；不得覆盖正式正确实现。若看见边缘仍近似正态而相关不正确，说明只检验一维直方图不够。
