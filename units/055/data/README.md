# 数据字典与边界

全部为合成二分类数据，不含真实个人资料。六个种子5500至5505，每份7200行4列，标签独立Bernoulli(0.08)。负类X均值全0，正类均值(1.4,0.8,0,0)，类内协方差单位阵。前2000行训练、2000至3199验证、3200至7199测试。

- X0至X5：7200×4的float数组。y0至y5：7200个真实0/1标签。
- observed0至observed5：2000个布尔标注开关，仅训练适用。
- obs_prob0至obs_prob5：生成器已知标注概率，负类0.6；正类x0<1时0.15，否则0.8。oracle IPW的额外真值，现实一般不可直接知道。
- noisy_y0至noisy_y5：2000个翻转后训练标签。正转负概率0.25，负转正0.02，给定真类后与X独立。
- protocol.json：固定成本、阈值网格、划分、抽样与概率修正规则。

过采样行来自训练原始ID0至1999，完整source_ids存入结果。修正目标先验使用原训练比例，不用测试比例。确认保持真实自然标签和自然类别比例，不平衡、不删负例。

generate_data.py默认另存outputs/regenerated-data。真概率公式由已知类条件正态推导，oracle不是现实免费可用信息。标签制度对照和噪声对照是独立改变，不假装在同一路线同时修复所有问题。
