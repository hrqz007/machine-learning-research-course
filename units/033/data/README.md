# 第033讲数据与配置

全部为独立构造的确定性数学例子，不含个人或真实业务数据。

quadratic.csv指定两个坐标、对应曲率和初值，定义f(w)=Σqⱼwⱼ²/2。默认q=(1,4)、初始(2,1)，最优点0，最小值0。坐标具有统一的无量纲数学单位，未声称现实参数物理尺度相同。

model_spec.json分别给出有效与故意无效的L/μ声称、预算、学习率和辅助函数初值。claimed_L_values/claimed_mu_values中的无效值是明确标记的反例实验，必须输出不满足假设的标签，不得作为有效收敛证书。没有隐藏随机种子或额外数据下载。

辅助凸函数h(w)=√(1+w²)−1，L=1、最优0，无全局正μ；辅助光滑非凸函数f(w)=1+cosw，L=1、下界0，初值0是驻点最大值。边界步长对照以二次主例的高曲率轴初值(0,1)单独计算。

Notebook固定叙述和手算参照依赖完整默认文件。修改输入应另存实验并同步修改推导、图和解释，不能留下旧答案。
