# 二分类原创教学数据

observations.csv为主例：4行、单特征x=[−2,−1,1,2]、二元标签[0,1,0,1]。B1–B4只是行标识。参数顺序明确为截距b、斜率w；不额外标准化。此例不完全分离，存在有限MLE。

separable.csv保留相同特征，标签明确改为[0,0,1,1]，S1–S4为另一个数据集行标识。它只用于完全分离的独立压力测试，不能与主例悄悄混用。model_spec.json为预声明控制参数。所有数据原创、合成，不代表现实样本或人员。

预测概率指标签1的条件概率。阈值并列规则为p≥τ判1；独立库predict的边界并列行为应单独核验。无额外类别权重或样本权重，截距默认不惩罚。只有0/1两个标签被这份教学合同接受，训练拟合须两类均出现。
