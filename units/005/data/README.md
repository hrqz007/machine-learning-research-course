# 第五讲数据字典

三个 CSV 都是合成教学数据。sample_id 仅表示固定样本身份；表中行顺序就是本讲数组顺序。实验代码直接写出同样的小数据，使初学者无需先掌握 CSV 读取；CSV 用于人工核对和后续读表练习。

house_training.csv 有四个样本。area_m2 为面积，单位平方米；price_wan 为标签，单位万元。与第一讲、第三讲相同。

house_test_fixed.csv 有两个样本，是第一讲已披露的固定测试数据。第五讲仅复核既定 B 规则的结果，不使用测试标签改变规则，不把已见数据重新称为未知封存数据。

multifeature_demo.csv 有三个样本和两个特征。area_m2 单位为平方米；room_count 为房间数，以间计；rule_prediction_wan 是按 2 × 面积 + 5 × 房间数 + 10 计算的教学输出，单位万元。它不是独立采集的真实标签，也不是模型泛化证据。系数含义为 2 万元每平方米、5 万元每间、偏置 10 万元。

没有外部下载，没有真实房源、地址或个人信息。
