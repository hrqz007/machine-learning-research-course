# 数据字典与来源

全部为本课原创确定性数学数据，无外部下载、无个人信息、无训练许可限制。作者将本目录生成的CSV数据以CC0方式提供，可任意重建使用。源代码的发布许可依所在仓库统一规则。

- xor.csv：4行，x1、x2为二进制输入，y为恰有一个输入等于1的指示值。顺序(0,0)、(0,1)、(1,0)、(1,1)。这是完整定义域，不作训练/验证/测试划分。
- square-grid.csv：1025行，x=i/1024，i从0到1024；y=x*x。用于核验固定平方插值构造，无拟合或选模。

运行python generate_data.py --directory outputs/generated-data重建。生成器不含随机步骤。实验另有随机仿射等价性检查，种子83021仅控制该检查，绝不参与选择XOR参数。CSV哈希保存于experiment-result.json；换行由csv.writer统一写出，生成器返回字节SHA256。
