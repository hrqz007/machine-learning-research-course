## A 先预测：层数增加了，什么还没变

在纸上写出$h=W_1x+b_1$、$y=W_2h+b_2$，不要直接引用结论，实际展开第二式。记录合并矩阵与偏置分别需要哪些乘法。特别标记$b_1$要先乘$W_2$，而$b_2$不需要。

用讲义中的整数例子检验：$W_1$两行为(1,2)、(3,4)，偏置(5,6)，$W_2=(7,8)$，输出偏置9。输入取(1,0)及(0,1)，先逐层算，再代入合并式。两次结果分别应由你自己计算，不要先看程序输出。

```python
from experiment import affine, collapse
W1, b1 = [[1, 2], [3, 4]], [5, 6]
W2, b2 = [[7, 8]], [9]
W, b = collapse(W1, b1, W2, b2)
for x in [[1, 0], [0, 1]]:
    print(x, affine(affine(x, W1, b1), W2, b2), affine(x, W, b))
print(W, b)
```

验收：能说明为什么W是1行2列；能解释随机浮点实验中的$10^{-16}$量级差异不推翻代数恒等式；能指出此实验没有证明两种参数化的梯度下降路径相同。

## F 用折线近似平方函数

先以n=2手写$p_2(x)=x/2+\operatorname{ReLU}(x-1/2)$，检查x=0、1/4、1/2、3/4、1。再对n=2、4、8、16运行，记录最大误差，并比较理论式$1/(4n^2)$。

```python
from experiment import interpolate_square
for n in [2, 4, 8, 16]:
    error = max(abs(interpolate_square(i/1024, n)-(i/1024)**2) for i in range(1025))
    print(n, error, 1/(4*n*n))
```

解释为什么这次网格包含所有段中点；如果改用1000等分网格，通常只能说网格最大误差，而不能凭数值保证恰好找到区间最大值。程序里的hidden_hinges只数n-1个内部折点；若用标准无跳连ReLU网络实现x/n这条支路，还需在当前非负区间添加ReLU(x)单元。
