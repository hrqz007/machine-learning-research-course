# 原创数据与字段字典

这些JSON表是人工指定概率模型，不是实际设备或天气测量，没有抽样种子，也没有下载来源。generate_data.py可逐字节重建models.json、joint-tables.json；generation.json记录字节数和SHA256。实验加载时对照生成器内容，避免静默修改模型。

| 字段 | 含义与单位 |
|---|---|
| nodes | 有顺序的变量名称列表；同时规定每张表的父状态排序 |
| edges | [父节点,子节点]列表；边的列表顺序不改变含义 |
| cpds | 节点名到P(该节点=1\|父状态)的列表；数值无单位 |
| state | 某个完整状态的字典；所有变量取0或1 |
| probability | 完整状态的联合概率，非负、无单位；全部行加为1 |
| chain | 人工设备链A→B→C；A高负荷、B发热、C告警 |
| collider | 人工湿地模型R→W←S；R雨、S洒水器、W湿 |

所有状态0=否、1=是。W有父R、S，条件表索引按(R,S)为00、01、10、11。在数表以外还使用D表示W的后代传感器节点，仅检验图结构，不虚构D的观测数据。无向链势函数定义在graph_models.py，AB同态3/异态1，BC同态2/异态1。
