# 第038讲数据与模型

regression.csv为独立构造的四行无量纲数据，沿用036的数据值以保持概念连续，非真实个人或业务数据。id是唯一教学行号；x是单特征，y是标签。行依次为(−2,−1.5)、(−2,−0.5)、(2,2.5)、(2,3.5)。

同一数据明确配两种不同模型：线性ŷ=a+bx；平方参数ŷ=a+b²x。两者均取残差预测减标签、F=Σr²/(2n)，n=4。不能混淆线性系数b与非线性模型中的实际斜率b²。线性最优(1,1)，非线性最优(1,±1)，最低目标均1/8。

model_spec.json预声明初始化、线搜索、移位、曲率阈值与有限历史设置。非线性主手算从(0,1.5)出发；不正定反例从(1,0.25)出发，驻点非最小反例从(1,0)出发。三者只是不同初始状态，不更换数据。

benchmark_dimensions/repetitions/seed声明另外生成的维度扩展线性设计；它不替代四行手算，不参与泛化比较。构建方式、目标、停止标准、线程、一次性成本与内存含义必须在实验中完整说明后才可报告结果。
