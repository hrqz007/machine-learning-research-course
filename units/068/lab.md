# 第068讲 实验指导书

## 1 实验任务与交付物

本实验比较常数概率、逻辑回归、随机森林和K近邻对一个原创模拟质检任务的预测。你需要保留完整九配置验证记录、锁定选择、测试概率、区间、校准、成本及失败样本。参考实验选择15近邻；测试上的最佳数字来自森林。请保留这两个事实，不要为了让故事整齐而改变选择记录。

预计需要90至150分钟，其中多数时间用于读协议、手算和解释。数据规模900行，普通CPU即可，不需要GPU、付费接口或联网下载数据。先读lecture.pdf第2至5节，再执行代码；所有源文件可编辑，但参考报告应保留作比较。

## 2 环境与文件

建议Python3.12。requirements.txt固定numpy2.3.5、scipy1.17.0、scikit-learn1.8.0、matplotlib3.10.8以及Notebook依赖。首次安装需要联网，运行实验使用本地数据。建立环境后，从本单元目录运行：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py --out outputs/my-run/result.json
python test_experiment.py --report outputs/my-run/result.json --out outputs/my-run/tests.json
python -O test_experiment.py --report outputs/my-run/result.json --out outputs/my-run/tests-O.json
python plots.py --report outputs/my-run/result.json --directory outputs/my-run/figures
python execute_notebook.py --out outputs/my-run/experiment.ipynb
```

Windows可将激活命令替换为该环境对应的Scripts激活方式。不要把不同Python的pip与解释器混用。environment.yml另提供Conda安装入口，但交付包的实际验证是在已有固定版本Python环境中完成；独立干净Conda安装没有额外验证。

完整PDF重建还需build-requirements.txt、package.json所列MathJax及系统Pango与Noto CJK字体。bash build_all.sh按实验、两种测试、图、Notebook和PDF的顺序重建到outputs/rebuild。通过PYTHON_BIN选择解释器，通过NODE_PATH提供外部MathJax模块路径。脚本不会自动安装依赖，也不覆盖顶层冻结材料。

## 3 数据字典与隔离规则

| 字段 | 类型和含义 | 允许用途 |
| --- | --- | --- |
| id | case_加四位原始样本编号 | 核查拆分、连接失败记录 |
| x0至x5 | 六个无量纲正态传感器值 | 训练、验证、预测 |
| y | 0或1，Bernoulli标签 | 相应拆分的监督与评价 |
| p_true | 生成器中真实发生概率 | 仅事后解释，不作特征或调参输入 |

train.csv为450行，validation.csv和test.csv各225行。generation.json保存字节摘要；common.load_data同时比较生成器输出，阻止“改完数据再改摘要”伪装成原实验。generate_data.py可将原始字节重新生成到新的目录。不要直接编辑冻结CSV做扩展实验；另存修改版生成器和新协议。

x0与x1通过乘积影响标签，x2线性影响标签，其余输入无关。模型并不知道这个生成公式。所有输入在预测前可用；没有时间序列或同组重复实体。迁移到真实数据之前，必须重新核查这些假设。

## 4 先用纸笔验证指标

写下y=(1,0)、p=(0.8,0.3)。分别计算两行负对数似然，再平均；Brier分数先逐行平方再平均。参考值为0.2899092476与0.065。改变预测为(0.51,0.49)，两个分类仍正确，但概率质量降低。

随后检查experiment.py中的point_losses。注意它先拒绝长度不一致、空向量、非法标签、非有限概率和超出[0,1]的概率，再做浮点裁剪。输入检查是API契约，不能依赖在python -O中会消失的assert。

## 5 核查搜索而不是只运行模型

打开select函数，确认参数表是逻辑回归三个C、森林三个最大深度、近邻三个k。森林的树数固定80，叶子最少5个样本，随机种子固定68。每个Pipeline中的StandardScaler只在fit训练集时学习均值与标准差。

运行实验后，查看candidate_rows。它必须有9行，同一方法族3行。每行包含配置名称、参数、验证对数损失和真实拟合秒数。通过最小验证损失和名称破同分规则独立重算winner；本次应为knn_1，其参数为15。

测试集的指标只能在选择锁定之后用于审计。代码为了公开研究比较，也报告另外两个方法族的验证最优代表，但这些测试数字不再参与选择。不要看完测试结果后把winner字段手动改成forest_2；测试会拒绝这种篡改。

## 7 实验记录模板

在自己的报告中逐项填写：任务与预测时点；独立样本假设；拆分种子和ID；候选配置数；主指标与阈值；验证选择；测试指标与区间；校准图与箱样本量；失败样本；模型大小和批预测协议；限制及下一步。每个结论对应一个可重算数字或图，不写“模型效果很好”这样无法审计的话。

至少解释两个观察：为什么不含交互特征的线性模型受限；为什么森林测试损失更低，却没有取代预先选中的近邻。再说明常数概率基线的ECE为何可以很低。

## 8 允许的扩展及其边界

扩展A：建立全新实验，事先为逻辑回归添加乘积特征x0x1，并给所有候选统一的新评价预算。预计线性模型的失配会减轻，但不要将新结果混入原来的九配置表。

扩展B：增加无关输入维度，观察近邻的验证损失和预测成本。这是新数据生成机制，应保存新种子、新拆分和完整结果，不应在原测试集上不断试直到得到想要的故事。

扩展C：把模型选择改成“验证损失在最优值某个预设容忍范围内时选择最小模型”。必须先写容忍范围及成本度量，不能看完结果才挑刚好让自己偏好的模型获胜的阈值。

## 9 故障排查与测试覆盖

找不到模块时，先用python -c打印sys.executable，确认激活的环境与安装位置一致。数据摘要不匹配时，保留错误文件调查，不要仅更新摘要；在新目录重新生成并比较。Notebook运行器启动真实IPython InProcessKernel；执行结果含图像和计数，不是只填了看似运行过的编号。Jupyter浏览器界面与外部socket内核传输没有列为已验证。

63项显式检查在普通与优化模式均应通过，覆盖独立手算、库指标对照、完整报告重算、拆分与预算、概率端点、空箱、单类切片、非法输入，以及CSV/摘要/报告篡改和符号链接、硬链接输出保护。测试通过说明这些契约被满足，不是证明现实世界中不会出错。
