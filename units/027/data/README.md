# 合成模型与目标

所有模型均独立构造，用于研究估计规则的重复抽样误差，不是现实预测准确率。目标固定为总体均值μ，默认μ=1/2。基本精确模型单次观测X=μ+ε，其中ε为等概率±1，三次相互独立，八个有序样本等概率。two_point_model.csv用分子/分母保留精确表示，不把两条总体状态误当成一份n=2的观测样本。

三条规则是样本均值、奇数n的样本中位数、固定缩至0的半均值。主例n=3时，前两者均无偏，但方差分别1/3和1；半均值偏差−1/4、方差1/12、MSE7/48。这个两点分布的总体中位数不唯一，不能把通常唯一中位数一致性结论直接搬过来。

模拟另用Gaussian(μ,1)和对称污染混合0.9Gaussian(μ,1)+0.1Gaussian(μ,100)。第二参数始终表示方差，NumPy normal的scale应分别使用标准差1和10。混合模型的均值和唯一中位数都仍为μ，总体方差10.9；因此比较均值与中位数时没有偷偷改变目标。该对称污染不代表任意现实污染，不能推断中位数在所有分布都估计均值。

默认每个样本量3、15、63各独立生成10000批，行是一份完整数据，列是一条观测。固定c=.5与随n变化c_n=n/(n+3)必须分开，前者通常不一致，后者偏差渐消。risk_centers供理论敏感性曲线使用，不是从模拟结果中事后选择最佳真值。经验风险分解的方差分母使用R，以便与经验MSE精确相容；需要无偏样本方差时单独标明R−1。
