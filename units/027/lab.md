## 3. 用纸笔列全八种可能

固定μ=1/2，单次噪声取±1各一半，n=3且相互独立。先写八个有序符号三元组。每行依次计算观测、平均值、中位数、半均值，以及三者相对μ的平方误差。每一行权重是1/8。

按正号个数K汇总时，四种K的权重变成1/8、3/8、3/8、1/8。不要把去重后的四行等权。核验代码如下：

```python
from fractions import Fraction
import experiment as e
exact = e.exact_two_point(Fraction(1, 2), 3, Fraction(1, 2))
for row in exact['rows']:
    print(row)
print(exact['statistics'])
```

通过条件：均值MSE=1/3，中位数MSE=1，半均值MSE=7/48。后者偏差−1/4、方差1/12。请用直接平均八个平方误差核验一次，再用偏差平方加方差核验一次，避免两条代码都依赖同一个错误公式。

思考：均值取5/6的那次样本上，三个规则各离μ多远？这个本次排序能否代替长期风险排序？再解释这个两点总体的中位数为什么不唯一。不能把此例推广成所有中位数估计都不一致。

## 5. 检查有限模拟的分母

先不用随机数，只给估计值列表t=(0,1,2)，目标θ=.5。手算平均估计1、经验偏差.5、经验方差2/3和MSE11/12。若用R−1为分母，样本方差是1，必须乘2/3才能回到风险恒等式。

```python
s = e.risk_summary([0, 1, 2], .5)
print(s)
e.require(abs(s['mse'] - 11/12) < 1e-14, 'finite MSE')
e.require(abs(s['identity_residual']) < 1e-14, 'finite identity')
```

risk_mcse是平方损失平均的模拟标准误；它与估计器标准误sqrt(variance_R)的对象不同。前者回答“这次用R批估计的风险有多精确”，后者回答“单次估计规则随数据变化多少”。在真实风险未知时，前者仍只是有限模拟估计，并依赖平方损失方差有限。

## 6. 按完整数据集重复模拟

读取data/model_spec.json，默认每个模型、每个n有R=10000个独立样本批次，n为3、15、63。数组形状(R,n)，行是一份训练数据。四种规则在同一行上计算，所以方法比较是配对的，不能把它们当成四组彼此独立的实验。

两种总体都以μ=.5为均值和唯一中位数。Gaussian的σ=1；污染机制每个观测独立以.1概率使用标准差10，其余使用1。混合方差是10.9，均值MSE为10.9/n。NumPy scale表示标准差，传10，不能传100。

默认运行的Gaussian n=15均值经验MSE约.0675728，中位数约.1016626，固定半均值约.0805226；n=63时均值约.0159761，固定半均值约.0661508。污染n=15下均值约.7236205，中位数约.1254564。主例表明方法排序依赖分布和样本量。它没有证明任何有限次模拟中的排序必然成立，也没有证明中位数对任意污染都估计同一个目标。

通过条件：每一行的经验偏差平方加经验方差与经验MSE在浮点误差内相容；均值理论风险在Gaussian为1/n，在混合为10.9/n。理论风险与经验风险无需完全相等，请同时报告MCSE，不要修改种子直到误差条恰好好看。±2 MCSE是直观模拟误差条，不被当作小样本严格95%区间。

## 7. 区分固定收缩与渐消收缩

固定c=.5不会随着n增加而回到1。另一个规则使用cₙ=n/(n+3)。当n=3时两者相同；n=15时cₙ=5/6，n=63时为21/22。对每个n画完整理论风险，并用模拟结果覆盖对应点。

通过条件：固定半均值在μ=.5时MSE极限为1/16；渐消收缩的偏差和方差都趋零。有限模拟曲线可能上下浮动，不要求每个相邻样本量的经验误差都下降。再用Tₙ=X₁说明无偏不保证一致，用罕见事件反例说明一致不保证MSE趋零。

## 8. 预测一个真正的新观察

脚本在每批训练数据之外独立产生Y，再计算(Y−T)²。均值等线性规则的理论预测风险等于参数MSE加总体噪声方差；中位数的参数风险没有本实验使用的闭式，所以相应理论预测字段为空，而不是填一个模拟值冒充定理。

默认两点精确例子可核对：均值新点风险4/3，中位数2，半均值55/48。Gaussian n=3均值预测风险应为4/3。有限预测模拟可能波动，尤其在宽尾混合下，因此不要要求一次预测误差恰好等于参数经验风险加10.9。

额外核验：枚举原样本和独立新符号的16个联合情形，直接求预测风险。然后将Y换成训练样本第一点，看看交叉项为什么不再为0。请标注评估目标的这次改变。

## 9. 失败输入应先被拦住

数值API先检查完整列表和全部配置。包括未用来画图的risk_centers、最后一个样本量、Gaussian分支暂不使用的污染尺度。支持范围和预算在README中；不要靠隐式转换把True变成1。

```python
bad_calls = [
    lambda: e.risk_summary([0, 1, True], 0),
    lambda: e.mean([0, float('nan')]),
    lambda: e.shrinkage_risk(.5, 1, 3, '0.5'),
    lambda: e.risk_summary([0, 1e-200], 0),
    lambda: e.exact_two_point(.5),
]
for call in bad_calls:
    try:
        call()
    except ValueError:
        print('rejected')
    else:
        raise RuntimeError('invalid input accepted')
```

JSON解析保留原始小数token检查，1e-400不能先变成0再通过；重复键一律拒绝，包含相同值的重复。真正0e-400可以表示零。测试一份最后一行分母为0的CSV、一份重复center键的JSON，并确认运行失败后已有report.json的原始字节不变，也没有新输出目录。所有输入验证应发生在RNG构造和文件写入之前。

浮点实现不等于所有实数上的数学公式。特别小的非零离差平方或平方损失方差不能表示时应报错并建议换单位，不能返回0再宣布估计器稳定。已变成普通float的0无法恢复来源中被丢失的信息。
