# 027 估计误差与偏差方差

固定一个总体参数，比较完整估计规则的重复抽样表现。精确两点模型揭示无偏不等于低MSE；Gaussian与对称污染模拟比较均值、中位数、固定收缩与渐消收缩。主要推导包括MSE分解、固定收缩风险、一致性反例、有条件的标量信息下界、独立预测风险和有限模拟恒等式。

## 精确锚点

μ=1/2、n=3、独立等概率±1噪声，共8个有序样本。

- 样本均值：期望1/2、偏差0、方差=MSE=1/3。
- 中位数：期望1/2、偏差0、方差=MSE=1；此两点总体中位数不唯一。
- 固定半均值：期望1/4、偏差−1/4、方差1/12、MSE7/48。
- 独立新点预测MSE分别4/3、2、55/48。
- 固定半均值只在|μ|<1时比均值风险小；μ=2时风险13/12。
- oracle系数3/7、风险1/7，使用未知μ，不能当作可用算法。
- 数据规则c(x)=1{|平均|>1}在全部8样本上重算后风险11/32。
- t=(0,1,2)、θ=.5的有限经验MSE11/12=偏差平方1/4+方差2/3；样本方差R−1版本为1。

固定系数c的风险为(1−c)²μ²+c²σ²/n。渐消系数n/(n+κ)在有限方差条件下MSE趋零。X₁-only无偏但不一致；Tₙ=n1{U<1/n}依概率趋0却MSE=n，说明矩条件不可忽略。

## 实际模拟与解释边界

种子27027，PCG64子流；每个模型、每个n=3、15、63生成10000批独立完整数据。四种规则在同一批上配对比较。Gaussian标准差1；对称污染以.1概率使用标准差10，总体方差10.9，两种总体的均值与唯一中位数都为.5。

默认Gaussian n=15的均值、中位数、固定半均值、渐消收缩经验MSE依次约.0675728、.1016626、.0805226、.0544975。n=63均值约.0159761，固定半均值约.0661508。污染n=15均值约.7236205，中位数约.1254564；对应风险MCSE约.013367和.001818。详细偏差、分母R方差、MSE、风险MCSE、理论值与独立新点预测结果都在运行报告中。

均值的理论风险为总体方差/n；线性收缩用完整理论公式。中位数有限样本风险仅由本次模拟估计，相应理论字段为null，不用模拟数字假装闭式定理。误差条±2 MCSE用于说明模拟精度，没有严格小样本95%保证。多方法共享数据造成相关，不能把误差条当独立比较检验。单侧污染可能改变均值与中位数的共同目标，需要另作定义。

## 公共接口与数值契约

所有教学API用显式require/ValueError，不依赖python -O会删除的assert。普通实数API接受Python int/float及不超过64位的NumPy整数/浮点，拒绝bool、文本、复数、非有限值、Fraction、Decimal、扩展精度浮点和任意迭代器。先完整验证再转float64；已经在上游转换丢失的原始类型或数值无法恢复。

- real、vector、mean、median：一般数值绝对值不超过1e6，非零绝对值至少1e-100；向量只能为list/tuple或一维NumPy数组，长度1..100000。所有元素均验证，真正常量均值直接返回其值；其他情况用原始值的math.fsum，保留[-1,1,1e-100]中的小非零均值。median在偶数长度时取中间两项平均。
- risk_summary：至少2个估计值，truth也全量验证；方差分母R，另给R−1版本和平方损失平均的MCSE。每个非零平方项必须是正常有限浮点数；包含估计误差、中心化估计与中心化平方损失。特别小的非恒定数据可能因四阶量无法可靠表示而拒绝，应重选单位。恒定估计等于truth时所有风险分量精确为0；全部平方损失相同（包括恒定估计对错误目标）时MCSE精确为0，不能把求和舍入当成波动。
- shrinkage_risk：μ在[-100,100]、σ在[.01,100]、n为1..1000000整数、c在[0,1]。vanishing_risk另要求κ在[.01,100]。oracle_risk明确标记使用未知真值。这些是教学实现范围，不是理论公式全部定义域。
- exact_two_point：专门的精确Fraction接口，μ和c都必须显式Fraction；|μ|≤100，c∈[0,1]，约分后分母≤10000；n为1..9奇数，枚举2^n个完整序列，不生成随机数。概率固定1/2，噪声固定±1，结果以有理数字符串保存。
- simulation：不接受外部可变RNG或任意回调。seed为0..2^32−1整数；R为20..20000；样本量列表1..8项，必须互异奇数且在3..501；R乘样本量之和≤300万。center在[-100,100]；Gaussianσ在[.1,10]，污染σ在[.1,30]，污染概率与固定收缩系数在[0,1]，κ在[.01,100]；risk_centers长度1..31且各值在[-100,100]。包括未选字段和列表最后一项，都在RNG构造之前检查。
- JSON：键须严格匹配；所有重复键拒绝，即使值相同。浮点原始token先检查，拒绝非零1e-400下溢、溢出和NaN/Infinity非标准常量；真正0、-0、0e-400可表示零。普通可支持小数允许正常binary64舍入。
- CSV：固定两状态模式，整数token保存分子/分母；分母正、状态顺序low/high、相同中心、偏移−1/+1、概率各1/2。不能把CSV两行当作一份n=2观测；缺列、多列、重复状态、错误概率或最后一项无效都拒绝。

浮点计算对正常范围仍有舍入，有限恒等式按声明容差核验，不声称任意实数精确运算。外部高精度输入需要明确的另一种算法，不能先强制float后声称保持原值。
