# 第十二讲数据说明

两个 CSV 都是原创合成教学数据，不含真实个人或业务记录。

`main_matrix.csv` 有表头 `x1_coefficient,x2_coefficient`，3行2列数值依次为 `[2,1]`、`[1,2]`、`[1,-1]`。每行是一个输出通道对两个输入的线性系数，不是三名被试或三次独立抽样。第三行测量输入差异。

`synthetic_field.csv` 无表头，32行32列，每个元素代表固定网格位置的合成强度。数值范围为0.0390625到0.9609375。生成式写在 `experiment.py` 的 `synthetic_field` 函数中：确定性正交符号条纹对应奇异值16、8、4、2、0.5、0.25，各项相加。每个元素为整数除以128，CSV保存8位小数足以精确表示。本数据无缺失值，无随机抽样，也没有训练/测试划分。

强度的平方和被称为本实验的“能量”，不代表物理量或任务语义。代码核验数据与生成式一致，改动数据文件后可能触发断言，这是预期的审计保护。
