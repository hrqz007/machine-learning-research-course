# 第102讲 实验：参数×数据的受控规模比较

## 1. 研究问题与边界

问题：同一小型语料、同一分词、相同80次更新下，更宽模型与更大训练池如何影响验证损失？不是：固定计算预算下哪个模型最优，也不是：大模型能力何时涌现。

<div class="key">完整实验为3种宽度×2种数据量×3种子=18次网格训练，再按验证均值选配置，以固定种子7重建该配置并只报告其测试结果。因此共19次训练，额外复训不包含在18条runs中。每条6ND只核算该次运行，不是含选型/额外复训的全项目成本。所有实验均为真实CPU运行。</div>

## 2. 运行与文件

```bash
python -m pip install -r requirements.txt

```

PDF重建另需npm install，随后python build_pdf.py。主要文件：lm_common.py提供数据、分词和训练；experiment.py定义实验网格；outputs/results.json保存全部运行及学习曲线；figures/results.png是由这些真实值绘制的图。实验不访问外部模型服务，不下载训练语料。

## 3. 先做预算表

手工列出六个配置，宽度取12、24、48，训练文档数取120和1800。每个配置有相同优化器、学习率0.01、24篇文档批量、80步；三个种子是7、19、31。词表使用完整训练分区拟合后固定，小数据配置只限制模型训练池。

练习A：写出本课参数公式，代入词表大小和h=24，与结果中的parameters核对。练习B：对每次运行计算processed_target_tokens/unique_train_target_tokens，解释为什么小数据组会更频繁重复相同文档。

## 4. 核查数据边界

三分区完整文本互不重叠，所有配置共用400篇验证文档。测试776篇，不进入任何训练和超参数选择。120篇子集来自训练分区前120篇，不从验证集中补样本。

练习C：如果把1800篇每篇复制十次，新“数据量”是18000还是1800？分别从文件行数、唯一文档数与训练暴露次数回答。当前哈希去重能检测改一个标点的近重复吗？写明边界。

练习D：挑一个配置列出三个原始损失，不只报告最好的一次。找出最低平均验证损失配置，再核对selected_setting。测试集必须在选择之后读，不能用测试再替换获胜者。

## 6. 计算和时间不是一回事

读取每次运行的compute_proxy_6ND，用参数数和累计有效目标数重新计算，确认数值一致。再比较train_seconds。相同代理不保证相同时间；当前训练时间还含评估开销，不能当内核benchmark。

练习E：若希望大模型的代理预算与小模型相同，粗略应该按什么比例减少训练token？设计一个新的等预算方案，必须给出步数舍入与可变长度误差处理。当前提供结果不包含这个新增实验，不要把设计写成已执行事实。

## 7. 检查经验拟合

读取descriptive_log_fit。脚本对大数据组的三个参数规模拟合log损失直线。复算系数，说明它隐含E=0，只有三个尺度点，没有外推检验。

练习F：若三个点拟合得很好，能否预测参数再增加100倍的损失？至少列出四个可能失效条件。练习G：若要拟合E+A N的负指数形式，为什么三个点难以同时识别E、A和指数？

## 8. 验收报告

报告必须包含实际参数量、唯一数据量、累计处理token、学习率、更新次数、三个种子、验证与测试划分、计算代理定义、实际耗时以及不能外推的边界。测试需确认：数据互斥、实验网格完整、有限数值、参数计数正确、token预算重算正确、每条学习曲线终点是80步、测试选择不由测试结果驱动。

可选扩展：重复抽取三个不同的120篇子集，让子集变化与初始化变化分开；或者做等代理计算预算比较。先写出要改变的因素与停止条件，再开展实验，避免看完结果才改研究问题。
