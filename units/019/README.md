## 精确答案与实际有限结果

六个模型状态等概率，X依次为0、0、1、1、2、4。PMF为0:1/3、1:1/3、2:1/6、4:1/6，均值4/3、二阶矩11/3、方差17/9。把去重后的四个值等权会错误地得到均值7/4。

quiet含前两态，质量1/3、条件均值0；active含后四态，质量2/3、条件均值2。全期望是4/3，错误的等组平均为1。最佳常数平方风险17/9，使用已知组别的条件均值预测风险1。这是已知教学模型内的比较，没有训练或真实性能宣称。

连续密度(1+t)/4在[0,2]上总质量1，均值7/6，二阶矩5/3，方差11/36。反CDF稳定式为8u/(sqrt(1+8u)+1)。实际固定种子190777的30000次样本均值为1.1691337475914578，按n归一化经验方差0.3054184069058165；它们是估计，不替代理论值。

离散模拟对n=30、300、3000、30000各运行24次，全部种子为190000+100n+r（r=0至23）。额外n=2、种子199000至199063的64次模拟中，6次没有active观测，样本条件均值记为None，模型条件均值仍存在。有限模拟范围不是置信区间。

对原值加1e12，直接二阶矩减均值平方实际得到-134217728.0，参考平移算法得到1.888888888888889，与精确17/9相符。加1e18后输入仅剩一个不同浮点值，任何事后算法都无法恢复已丢失的信息。

## 输入合同与数值边界

数值接口接受普通int、float和Fraction，拒绝bool、文本、复数、非有限数、空或嵌套序列、错误形状。概率非负且math.fsum(p)==1.0；不自动归一化。CSV还用Fraction检查精确总质量。

保守拒绝非零subnormal输入、被检测到的乘积下溢及中间溢出。某些本可通过特殊缩放计算的极端问题也可能被拒绝。回调前验证完整模型或网格，回调后验证输出；不能从已错误舍入的有限返回值中推断任意回调内部发生过什么。模拟入口先验证全部六态及标签，再创建随机数生成器；不能依赖种子恰好抽中坏状态才报错。零质量模型状态不调用期望回调，零模型概率的条件事件报错。不存在的经验空组用None区分。

moments先减参考值再求偏移的中心平方，避免两个巨大原始矩相减。保留浮点精度与实际输入表示的限制；不把负方差截为0伪装修复。

## 实际验收

脚本内置1120项交叉核对：160个有理模型各5条精确恒等式及2项浮点比较；49项预期拒绝与7项端点或回调哨兵检查。独立实现另做1440项有理模型比较、192项Fraction梯形对照、99项80位Decimal反CDF对照（最大绝对差2.22e-16）及100批精确经验全期望检查。

三个新Python进程包含两种无关工作目录和python -O，标准输出与report.json逐字节相同。损坏输入CSV在独立副本中被拒绝，既有报告没有被覆盖。全部检查使用显式异常，不依赖可被-O删除的assert。

Notebook从新Python进程中的真实ipykernel InProcessKernel顺序执行，4幅PNG保留并逐幅检查；全部20页最终PDF逐页目视。浏览器Jupyter界面、外进程socket传输和学习者Anaconda安装未实际测试。有限测试不证明任意输入或任意函数都准确。独立复核状态见verification.json。
