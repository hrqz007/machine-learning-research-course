# 第036讲原创合成输入

regression.csv四行均为原创数学构造。模型ŷ=a+bx，θ=(a,b)，F=Σ(ŷ−y)²/(2n)，n=4。x=(−2,−2,2,2)，y=(−3/2,−1/2,5/2,7/2)，也可写y=1+x+z/2，其中z=(−1,1,−1,1)。故F=1/8+(a−1)²/2+2(b−1)²，最优θ=(1,1)，F*=1/8，H=diag(1,4)。它只隔离优化器状态机制，不是现实预测数据。

model_spec.json显式给出演示超参数。Adam主手算用η=1/4、β1=1/2、β2=3/4、ε=1、无惩罚/无衰减，从(0,0)开始。ε=1是为了让数值稳定项在两轮手算中可见，不是推荐实际训练默认；ε=10⁻⁸作为另一个标记清楚的诊断。平方根外加ε。

weight_decay用于单独比较耦合L2和AdamW解耦机制。该比较从非零初值(1/2,−1/2)出发，mask=(0,1)表示本例不衰减截距a、衰减斜率b；并不是自动豁免所有bias的库规则。主优化器比较使用λ=0，以保证同一原始目标。

根本目标、各样本索引及归一化在全部实验保持一致。学习率网格只用于机制研究；未使用测试集，也不声称最小训练损失代表最佳泛化。目标乘100的实验只在无正则Adam上检验梯度尺度与ε的代数关系。resume_split要求保存全部优化器状态和步数，不能只保存参数。
