## 数学与实验契约

默认x=(−2,−2,2,2)，y=(−1.5,−0.5,2.5,3.5)，ŷ=a+bx，F=Σ(ŷ−y)²/8。闭式F=1/8+(a−1)²/2+2(b−1)²只是独立诊断，所有实际梯度由四行旧前向得到。η=0.25、β₁=0.5、β₂=0.75、RMSProp α=0.75、ε=1在平方根外；这些是教学设置。

Adam第一步θ=(1/8,1/5)、F=5721/3200，第二步θ≈(0.2437004841250088,0.3898541226435905)、F≈1.1555504621664184。精确Fraction与Decimal100根号结果和真实binary64求解器分开保存，不把展示舍入反馈进去。

四种无正则方法使用相同初值和400次样本梯度预算。主路径保留每一步全部逐行量与优化器状态；预声明网格保留每步参数和目标。额外新前向诊断单列工作量，未测硬件时间。GD不使用ε，因此网格中两个ε分支会重合。稳定闭式目标差只在数据逐值等于默认四行时提供；自定义数据返回null，不假定(1,1)仍最优。

耦合/解耦比较另用非零初值(0.5,−0.5)、λ=0.1与显式mask=(0,1)。L2进入Adam的两个矩；AdamW使用数据梯度的矩，并按旧参数缩减(1−ηλP)θ。F和F+L2分别记录。没有“AdamW自动豁免bias”的假设。对零梯度/None的库语义及完整状态恢复也有明确可复现实验。
