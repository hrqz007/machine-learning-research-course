# 教学数据说明

这些房屋记录完全为课程手工构造，不对应真实房屋、个人或市场交易。面积单位为平方米，价格单位为万元，仅用于演示第一讲的计算和证据边界，不用于估价或投资。

train.csv 四行用于比较预先列出的候选 A、B、C。test_inputs.csv 是两条教学测试输入；test_labels.csv 单独保存答案，让第一次练习可先算预测再打开标签。由于本教程与仓库公开答案，这只能帮助练习隔离流程，不能提供真正保密的独立测试集。实际研究应另取得不参与开发、权限合适的数据。

候选 A 为 2*x，B 为 2*x+10，C 为 1.5*x+40。训练 MAE 分别为 10、0、7.5 万元。B 的测试 MAE 为 5 万元；固定训练价格均值 150 的基线测试 MAE 为 15 万元。

无外部数据下载，无个人信息，无第三方数据许可依赖。
