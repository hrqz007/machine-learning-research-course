# 第028讲教学数据

cases.csv 是本课程原创的确定性合成数据，不包含真实个人、机构、设备或测量记录。每一行是一条场景内观测，case 区分独立实验，不能把五组混合拟合。共25行。

字段：case 为固定场景名；id 为全文件唯一的行标识；x 为输入，采用载荷 N 的教学单位；y 为输出，采用读数 V 的教学单位。单位仅帮助检查量纲，不表示模拟了真实传感器的工程特性。斜率单位为 V/N，SSE 与 MSE 单位为 V²。

- hand，H01至H05，5行：x 为0至4，y 为1、2、2、4、6。精确最优 a=3/5、b=6/5、SSE=8/5。
- curved，C01至C07，7行：x 为−3至3，y=1+x+x²/2，无随机噪声。最佳线为3+x，SSE=21，残差呈U形。
- influential，I01至I06，6行：前5行复用 hand 的数值，末行是(20,0)。这是独立场景的对照，不是在 hand 里重复加权。
- perfect，P01至P04，4行：x 为0至3，y=1+2x，精确共线。用于未知正方差高斯似然没有有限最大值的边界。
- constant_x，K01至K03，3行：x 全为2，y 为1、2、4。参数满足 a+2b=7/3，不能识别其他 x 处的唯一预测。

CSV必须按 case,id,x,y 排列，不允许重复 id、缺失/额外列、非有限数字或词元下溢。每组至少2行、最多2000行。数字转换前检查原始十进制词元；真正的零允许，1e-400 这类非零但超出数值合同的值拒绝。

model_spec.json 包含且只能包含六个字段：known_sigma 是假定已知噪声标准差V；seed 为局部模拟种子；simulation_repeats 为重复次数；prediction_x 为对 hand 作预测的输入N；candidate_lines 为截距V和斜率V/N的候选；focus_case 控制候选比较。即使不被选中，所有其他场景和每个字段仍必须有效。

默认模拟固定真实均值为0.6+1.2x，在 hand 的输入位置生成独立零均值正态噪声，标准差来自 known_sigma。CSV本身不由该模拟产生，hand 五点也不被宣称为从该正态模型随机抽出的样本。实验用该模型单独展示重复抽样机制，必须区分拟合数据和模拟假设。
