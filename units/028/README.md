## 关键答案与解释

五点 hand 场景：x=(0,1,2,3,4)，y=(1,2,2,4,6)。精确答案为截距3/5 V、斜率6/5 V/N、Sxx=10 N²、Sxy=12 N·V、Syy=16 V²，残差为 (2/5,1/5,-1,-1/5,3/5) V。SSE=8/5 V²，MSE=8/25 V²，训练 R²=0.9。

配平方恒等式为 SSE(a,b)=8/5+5(a+2b−3)²+10(b−6/5)²，适用于这五点的任意实数候选 a、b。候选 (1,1)、(3,0)、(0,1.2) 的 SSE 分别为2、16、3.4。SSE 与 MSE 仅相差同一个正的样本数因子，最优参数相同。

constant_x 场景的全部最优解满足 a+2b=7/3，最小 SSE=14/3；程序给出代表 a=7/3,b=0，并明确标为参数非唯一。curved 场景的最佳线为3+x，残差呈 U 形，SSE=21。influential 场景新增 (20,0)，新斜率为−33/280、截距173/56，远端点杠杆163/168；它具有高影响，但残差并不是最大。

perfect 场景为 y=1+2x。未知正方差高斯模型中，精确零最小 SSE 导致似然随 sigma→0 无界增大，没有有限最大似然解；variance_mle 返回 null，状态为 no_finite_maximum_sigma_to_zero。正的最小 SSE 时，方差 MLE 近似为 SSE/n。本讲 MSE 始终指 SSE/n，不是某些统计软件表中用于残差方差估计的 SSE/(n−2)。

训练输入范围为0到4 N。x=2.5 时预测3.6 V，x=6 时预测7.8 V。已知 sigma=1 V 且正确直线模型成立时，均值标准误约0.47434和1.34164 V；它们未包含未知机制在范围外改变的偏差。关联斜率不自动等于干预效果。

## 主要函数

fit_line(x,y) 接受等长一维数值序列，返回参数、均值、中心化和、逐行拟合值与残差、SSE/MSE、正交与分解误差、杠杆、退化标志和未知方差 MLE 状态。常数输入返回一个明确标注的代表解，不支持由该代表推断不可辨识的范围外关系。常数输出时，普通定义的 R² 返回 null。

evaluate_line(x,y,a,b) 比较指定候选，不重新优化参数。gaussian_nll(x,y,a,b,sigma) 计算给定正标准差下的高斯负对数似然。prediction_diagnostics(x,y,query,sigma) 先拟合再返回插值/外推标志及条件标准差；它拒绝常数输入的不可辨识预测。统计标准差只有在正文写明的模型成立时才有对应解释。

read_config 与 read_cases 严格验证文件；compile_report 在全部输入与确定性计算完成后才建立局部随机生成器。run 完整计算并序列化结果后，原子替换指定的 JSON 输出。默认只写一个报告，不创建图文件或改变输入。Notebook 中的演示图保留在输出单元内。

## 保守数值合同

本实现是可审计的有界教学程序，不是任意精度或任意尺度的通用回归库。外部标量只接受 Python int/float、NumPy整数以及 float16/float32/float64。明确拒绝 bool、np.bool_、文本、复数、非有限数值、外部 Decimal/Fraction、对象标量与扩展浮点。序列只接受 list、tuple、1维 ndarray；数组当前 dtype 必须为整数/无符号整数/普通浮点且宽度不超过8字节，拒绝 object、bool、complex 与扩展精度数组。嵌套、矩阵、空序列和长度不一致也拒绝。

每个数值 x、y、查询点和候选系数须在 [−10⁶,10⁶] 内，非零绝对值至少10⁻¹⁰⁰。一般拟合每组1至2000行；文件格式另外要求五组各至少2行。已知 sigma 在0.01至1000间；查询点1至100个；候选直线1至100条；模拟次数为10至2000的整数；种子为0至2³²−1的整数。拟合得到的截距与斜率绝对值不得超过10¹²；过大时明确报错，建议重新评估单位和条件数。

验证发生在 float 转换之前，避免将混入的布尔值或不支持的原始精度类型静默降精度。CSV 的数字先检查十进制词元，JSON 的 parse_float 也直接接收原始词元；非零的 1e−400 会被拒绝，真正的 0e−400 会被接受。重复 JSON 键、非标准 NaN/Infinity、缺失/额外配置字段与无效最后一项均拒绝。JSON整数保持 Python整数后按字段验证，不会先变成浮点。CSV数字不允许空白、千分位分隔或单位后缀。

均值通过原始数值的 math.fsum 求和，保留例如 [−1,1,10⁻¹⁰⁰] 的小非零均值，避免减锚点造成的信息丢失。对已验证的存储值，内部使用小型Fraction算术求真实有理均值、fsum均值的舍入余项和中心化差值，再转回浮点计算。x_mean/y_mean保留原值fsum结果，x_mean_offset/y_mean_offset单独记录余项；拟合、中心化残差、解释平方和、杠杆、查询和模拟使用同一中心化口径。仅修正Sxx而保留未修正dx会让相邻浮点数的归一化诊断失真，本版已加入回归检查。平方和与交叉和另作残余求和修正；SSE由中心化残差平方直接求和，不用两个大平方和相减。

非零乘积、平方、非恒定离差和与 MSE 如果下溢到0或次正规数，会报错；不会改判成真常数。代码会精确检查所有存储二进制值的共线性，作为最小 SSE 精确为零的证书，此检查内部使用 Fraction，不改变外部类型合同。数值 residuals 和 sse 仍是浮点结果；数学最小 SSE 为零时，浮点残差可有微小舍入痕迹，精确标志与 numerical SSE 不应混淆。该证书不证明原始测量无噪声。

即使范围检查通过，浮点误差也不会完全消失。极端抵消、病态布局与外部已经舍入的数据仍需要高精度或专业数值方法；本程序不承诺给出每一位正确数字。Python或NumPy在调用前已将值改成0/整数后，接口无法恢复原历史。对极小正确结果做测试时，不要使用会把0也判成正确的巨大绝对容差。

## 文件与随机性保障

程序对全部场景、全部候选线、全部查询点和全部配置字段进行验证，包括 focus_case 没选中的组以及末行。非法数据在创建局部 RNG 和任何报告替换之前失败。旧报告保持原字节不变。成功计算之后，用同目录临时文件与原子替换交付 JSON；这不等于对断电等系统灾难提供持久性保证。

输入门槛不用 assert，正常模式和 -O 模式都保留。固定种子只让相同环境下的小型模拟可重复，不代表对现实数据稳健，也不自动解决泄漏。默认600次模拟的真实机制参数被明确固定为0.6、1.2，输入布局来自 hand，sigma 来自配置；若自行改变 CSV，模拟仍按这一声明的机制进行，不会悄悄把拟合参数当成真实参数。

## 科学与计算核验

本版用240组独立 Fraction 数据核对参数、SSE、均值、残差正交和全局配平方恒等式；用独立 Decimal 高精度运算检查混合尺度与小均值。正常与 -O 各通过3,693项检查，新增56组相邻浮点布局的杠杆、R²、拟合值与标准误回归，以及固定Notebook/自定义脚本合同检查。两次从不同当前目录发起的新脚本进程输出报告逐字节一致。Notebook 从清空状态在新进程实际顺序运行19个代码单元，保留8张图。所有最终 PDF 页面及 Notebook PNG 均逐张视觉检查。

这些检查是有限证据，不构成对任意输入的形式证明。更详细的版本、页数、哈希与验证范围见 verification.json；一手来源核查见 source-checks.json。公开包不含构建依赖、构建脚本、审计临时数据、渲染页、缓存或运行输出。

## 固定教学Notebook与自定义脚本

Notebook的图、分数手算和标题对应两份默认输入。首个代码格在任何打印或图之前核对cases.csv和model_spec.json的原始字节摘要；合法但不同的配置、数据或重新排版也会明确拒绝。通用experiment.py仍支持合法自定义数据/配置，包括不同sigma、模拟次数和非整数观测。请把自定义报告解释为新实验，不沿用固定教学图的默认数值。

相邻输入x=[1,nextafter(1,2)]、y=[0,x[1]−1]的准确诊断是斜率1、截距−1、SSE0、R²1、杠杆[1,1]，sigma=1时训练点均值标准误[1,1]。这是中心化细节会影响归一化结果的回归例；输出的单个浮点均值可能舍入，单独的余项避免把这一表示限制误当作数据差异。
