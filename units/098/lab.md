## 2 环境和入口

Python 3.12为本次验证环境。创建自己的虚拟环境，在本讲目录运行：

```bash
python -m pip install -r requirements.txt
```

实验默认CPU单线程，不下载任何数据。outputs下文件会重建，若要保留修改实验，请先复制本讲目录。Notebook也可在Jupyter中由上到下运行；execute_notebook.py使用同一Python进程中的IPython真实执行并保存输出，不依赖网络内核。

PDF重建另需build-requirements.txt列出的Python依赖、Node.js和npm install安装的MathJax。运行python build_pdf.py，结果写入outputs/pdf。已发布PDF可直接阅读，学习实验无需安装排版依赖。

## 3 先做不依赖训练的检查

打开lstm_step，逐项标注四个gate切片。用lecture的单坐标例子手算c与h，然后把门顺序故意改错，运行test_cell_reference，记录失败含义。恢复代码后继续。

检查masked_loss：先得到每个位置损失，再乘mask，最后除以有效位置总数。不要改成先求平均再乘mask。把两个样本的有效长度写在纸上，数出有效token总数5，检查代码的valid.sum()也是5。

## 4 核对数据不会泄漏

打开data/sequences.npz，核对train_x形状为[192,12,1]，每种测试输入为[256,length,1]。检查首位符号与标签一一对应、训练和测试种子不同、其他位置存在小噪声。

任务刻意让标签可以从首位读出，不是数据泄漏；关键在于模型只能在末端输出且中间需传递状态。不要把标签再拼进每个时间输入，那会把记忆任务改成局部分类。

## 5 运行九次训练并保留所有结果

默认3模型×3初始化，共9次训练。每次200次更新，记录epoch0到200每10次的损失；epoch0是更新前评估，epoch200是完成200次更新后评估。所有模型用同一训练数据，长序列测试不能用于选择最优轮数。

填写一张结果表：模型、参数量、长度12/24/48准确率均值、种子间标准差。若某模型失败，也保留结果并检查梯度和学习曲线；不要只发布最好种子。

## 6 破坏性测试A 错读最后位置

比较m(x,lengths)与追加随机padding后的相同有效读出，应近乎一致。然后改为m(x)统一读最后位置，追加padding会改变结果。解释为什么“补零”也不能保证状态保持不变。

这项实验只适用于这里的单向网络。扩展到双向时，先说明反向分支读入顺序，再设计打包测试，不要复用一个没有审查的信息边界假设。

## 7 破坏性测试B 错误损失分母

把有效损失写成(losses*valid).mean()，计算追加3列padding之前和之后的值。记录分母变化造成的缩放，而不是笼统写“浮点误差”。恢复正确实现，要求test_masked_loss_padding通过。

再把mask全置零。正确代码应明确抛出ValueError，不能产生NaN后继续训练。空样本究竟丢弃还是报错属于数据管道策略，本讲选择报错。

## 8 小研究题

选一项独立修改：噪声标准差0.10改0.30；训练长度12改24；或把隐藏宽度改成参数量更接近的一组。只改变一类变量，保存新目录、新配置和完整结果。

预测结果前先写假说及能反驳它的观察。例如“更大噪声会降低长序列表现”是可检验假说；“LSTM一定最好”不是合理验收标准。扩展实验不应覆盖随课程发布的基线文件。
