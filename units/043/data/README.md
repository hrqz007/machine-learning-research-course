# 八行多分类教学数据

observations.csv为原创固定合成机制例，不是现实采集数据，不含个人信息。id是稳定行标识；x是无单位的一维特征，仅取-1和1；y为甲、乙、丙三类的索引0、1、2。每行恰好一类。

x=-1处四行计数为(2,1,1)，x=1处计数为(1,1,2)。重复数值是有意保留的有效教学观察，共同决定经验频率；不可随意去重。所有八行用于参数拟合与科学核验，没有封存测试或泛化评估。

model_spec.json固定学习率0.6、最大600次更新、梯度阈值1e-10、零参数、差分扫描、共同平移、极端得分和信息论比较分布。默认CLI会先核对data_integrity.json绑定的输入SHA256。需要修改时先复制输入并通过--data和--config显式传入；非默认数据不附带八行解析证书。
