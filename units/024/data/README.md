# 合成Bayes更新数据

observations.csv包含八个带唯一身份的合成二分类观察，3次成功、5次失败。first批有1次成功，second批有2次成功。用于比较不重叠分批更新与一次更新，不得把同一ID重复作为新证据。

priors.csv记录五种人为选择的先验。alpha、beta必须严格大于0。main为Beta(2,2)，更新成Beta(5,7)；其余用于敏感性与边界教学，不表示对真实设备或用户的判断。boundary的密度在两端无界但可积，不能当成非法概率。

模拟后验参数及整批预测时必须记录随机种子、批数和每批未来试验数。每个预测批次只抽一次共同theta，再在给定theta下生成该批全部Bernoulli结果。输出不属于真实业务记录。
