## 3. 数据验证与两个批次

查看CSV表头和八个ID，核对第一批四次只有一次成功，第二批四次有两次。CSV的success只接受字符0或1，解析后数值API接受整数0或1。下面的代码可以在Notebook首格之后执行：

```python
rows = e.load_observations()
print(rows)
print(e.sequential_update(2, 2, rows))
print(e.posterior(2, 2, len(rows), sum(r['success'] for r in rows)))
```

两条结果应分别显示Beta(3,5)、Beta(5,7)，以及最终(5,7)。更新函数会先检查所有观察与唯一ID，不能因为某条记录没落入某批而绕过验证。故意复制O08时应明确失败。

再算e.posterior(5,7,8,3)，得到(8,12)。这是重复证据的反例，不是合法新增信息。比较两个后验的宽度；更窄的图不能证明数据变多。记录唯一ID只能发现显式复制，不能从数值本身证明试验独立。

## 4. 分母、证据与精确核对

用e.beta_fraction(2,2)和e.beta_fraction(5,7)得到1/6与1/2310。把二者相除应为1/385，再乘56得到8/55。调用e.evidence(2,2,8,3)及count_only=True版本，核对对数证据和普通概率。

两种数据记录规则的证据不同，但后验相同，因为56不依赖θ。不要把似然除以峰高就称为后验；那种操作只能比较相对形状。

```python
from fractions import Fraction
print(e.beta_integer_interval(5, 7, Fraction(1,2), Fraction(1)))
print(e.beta_moments(5, 7))
print(e.beta_mode(5, 7))
```

第一行应为281/1024，约0.274414。这是参数超过1/2的后验概率；下一次成功的预测概率是5/12，约0.416667。解释两者为什么不同，不能只比较小数大小。

## 5. 面积与奇异边界

中点求积用n个等宽小格，每个密度值乘格宽1/n。运行e.quadrature(5,7,n)，令n依次为20、100、1000。默认实际面积依次约0.9999991764、0.999999999947、1.000000000000001。最后的浮点尾差不表示数学面积真的超过1。

再改为Beta(1/2,1/2)。中点避开了无穷端点，但边界奇异仍会降低收敛速度；不能看到不报错就认定精度足够。用θ=sin²(t)后，密度乘Jacobian恒为2/π，积分区间为(0,π/2)。对这个常数积分得到1，是独立的数学检查。

不要在0与1处直接做普通梯形求积再删除无穷项。删除端点贡献既没给出误差控制，也掩盖了问题。代码中的beta_pdf把端点极限作为明确分支：0、有限值或无穷；这些是密度极限，不是端点概率质量。

## 6. 点估计与坐标

在一张后验曲线上标出MLE=3/8、MAP=2/5和均值5/12。然后画后验平方风险v+(d−q)²。最低点在q，说明平方损失决策与密度最高点不是同一个优化问题。

逐一运行e.beta_mode(1,1)、e.beta_mode(1,3)、e.beta_mode(.5,2)、e.beta_mode(.5,.5)。检查返回语义，不要把None看成程序坏掉：它表示没有唯一有限内部峰值，具体原因在kind中。闭端点延拓约定与开区间上确界需要分开写。

最后令η=log[θ/(1−θ)]。画η坐标密度时必须乘θ(1−θ)。其峰映回θ为5/12，不是2/5。保持相容的是对应区间概率，不是两种坐标的密度高度。

## 7. 后验预测必须保留共同参数

用e.exact_predictive(5,7,4)获得五个精确分数；手工求和为1，求期望为5/3，再求方差为140/117。与e.plugin_pmf(4,5/12)比较：插件模型均值一样，但方差为35/36。

模拟函数先完整检查a、b、m、重复次数与种子，然后抽取形状为(R,)的后验θ数组。正确结构中，一个θ生成一批四次的总成功数。反例结构中，先抽(R,4)个独立θ，再给每个单独试验使用不同θ。不要把矩阵的行与列颠倒。

默认R=20000、PCG64种子24024的实际结果：共享参数批总数均值1.67285、方差1.1856228775；逐次重抽参数均值约1.66545、方差0.9756262975。它们分别接近5/3与对应理论方差，但不会恰好相等。这里使用除以R的经验分布方差；不是用它声称无偏估计。

将R改成2000、50000时，说明变的是模拟精度；真实后验与理论预测不变。固定种子帮助复现这个实现，不保证跨NumPy版本随机流逐位一致。

保留同一n=8,k=3，分别代入Beta(1,1)、Beta(2,2)、Beta(20,20)、Beta(2,8)。画后验曲线并报告均值，前面三个对称先验结果为2/5、5/12、23/48，最后一个为5/18。

接着固定成功比例3/8，设置(n,k)为(8,3)、(40,15)、(200,75)。同一先验下，先验权重s/(s+n)下降。明确这是确定性的公式实验，没有抽到一条随机路径；不能用它估计置信区间覆盖率。不同先验比较揭示选择的影响，并不自行判定哪个来自可信的外部知识。

## 9. 失败测试与验收

e.reference_checks()执行1405项精确或浮点参考对照。e.boundary_checks()当前包含55项预期拒绝和17组接受边界。它们使用明确require检查，在python -O下仍保留。

浮点数值接口只接受普通Python或不超过64位的NumPy实数标量，拒绝bool、文本、复数、扩展精度、Fraction与非有限量；不能精确表示的整数也拒绝。Fraction用于明确的精确接口。理论允许所有a,b>0，当前实现只支持a,b≥0.25、a+b≤10000；计数通常不超过1000。调用需要的后验或预测形状也必须落在范围内。指数化后的逐项正概率或密度若下溢为次正规数，普通概率接口明确报错，保留对数接口用于诊断。边界无穷是独立数学分支，不与内部浮点溢出混为一谈。非恒定样本的正平方或平均方差贡献下溢也报错；真零权重与端点不可能事件仍为零。

构造两点先验θ∈{0,1}、等权，配合混合成功失败的数据。e.discrete_update([0,1],[.5,.5],8,3)应报告零证据，而不是返回两个NaN或自动加入新支持。

验证旧结果保护：先成功生成报告，另存重复ID、NaN先验或最后一行非法数据的CSV，用--observations或--priors指向坏文件并使用同一输出目录。应退出失败，旧报告字节不变。再从另一工作目录运行新进程，比较结果；最后重启Notebook内核从头执行，不能只重跑最后一格。
