主函数的约定是 $f:[0,4]\to\mathbb R$，$f(x)=2x+1$。输入是无单位的工作量数值；输出作为预测时长的分钟数。观测记录只是教学构造，不能用来评价任何真实设备。

## 二 先用纸笔写出四种表示

先不要点击运行。写下文字：“合法工作量在 0 到 4 之间，含两端；乘 2 后加 1。”写出对应公式 $\hat y=2x+1$。在纸上列出输入 0、1、2、3、4 的输出，并在表格中新增输入 $3/2$。最后写出 Python 表达式 y_hat = 2 * x + 1。

新增行应该输出 4。请解释每一步：$2\times(3/2)=3$，再加 1 得 4。接着把括号故意改成 2 * (x + 1)，在同一个输入计算它得到 5。这说明程序表达式看起来相近也可能实现不同规则。

数据中两个观测时长都为 6，但它们属于不同样本，必须保留两个位置。不要把观测列表改成集合来自动去重；本实验计算的是五条记录的差异，不是在统计出现过多少个不同数值。

## 三 定义域与代数条件

先判断输入 0、4、-1、4.001 是否允许。前两者应接收，后两者应拒绝。这里拒绝的理由是模型声明的定义域，不是因为表达式无法算出数字。程序用 ValueError 明确报告不符合约定；预期的拒绝也是正确结果。

另一个检查是 $(x^2-1)/(x-1)$。用 $x=1/2$ 和 $x=2$ 核对它与 $x+1$ 相等，再试 $x=1$。原式必须拒绝，不能因为化简式给出 2 就抹去分母条件。实验使用 Fraction 进行这些小分数运算，所以相等采用精确比较。

请写下 x 为 1 与 3 时两种复合的结果。$g(t)=t^2$；x 为 1 时，$g(f(x))=9$，$f(g(x))=3$。x 为 3 时，前者为 49，后者会把 9 送入受限函数 f，因此应拒绝。这个错误点在中间结果，不在原输入能不能平方。

## 四 对数规则的定义域审计

每次看见 $\log_b u$，先检查 $b>0$、$b\neq1$、$u>0$。实验还要求机器输入为有限数值，拒绝 NaN 和无穷值。NaN 可以暂时理解为浮点系统中“不代表一个普通数值”的特殊标记；它不是本讲实数定义域里的新数字。

在纸上算四项：$\log_2 8=3$、$\log_2(1/8)=-3$、$\log_{1/2}8=-3$、$\log_2 1=0$。再判断底数为 1、0、-2 或真数为 0、-4 时为何不能使用本讲的实数对数。

Notebook 会运行 360 项合法输入上的有限数值核验，包括乘积规则、商规则、幂规则、指数对数往返和换底。它使用四种底数：0.5、2、10 和 e；这些不是所有可能底数，只是一组清楚记录的测试输入。幂指数包含负数、零、分数和正整数。

浮点核验设置相对与绝对容差均为 $10^{-12}$。两侧足够接近才通过，不要求最后一位二进制表示完全一样。输出的最大绝对差只描述本次网格，不能当成所有实数输入的误差上界。数学恒等式的依据仍是讲义中的条件与推导。

然后看两个故意失败的式子。$\log_2(1+1)=1$，但 $\log_2 1+\log_2 1=0$，所以普通加法不能按乘积规则拆开。$\log_2((-2)^2)$ 合法，但 $2\log_2(-2)$ 不合法；如果改成 $2\log_2|-2|$ 则得到正确结果。第一个是合法数值不等的反例，第二个首先是定义域不匹配。

## 五 让索引和样本保持一致

五条输入为 0、1、2、3、4，观测为 1、2、6、6、9，预测为 1、3、5、7、9。手算预测减观测，得到 0、1、-1、1、0。平方后得到 0、1、1、1、0，总和为 3，平均为 $3/5$。带方向差的和是 1，其平方也是 1，不能与平方差之和 3 混同。

数学索引从 i 为 1 开始，Python 位置从 j 为 0 开始。数学第 4 条应读取 xs[3] 与 ys[3]，并得到预测 7、观测 6、差 1。若只给其中一个列表移动位置，计算仍可能返回数字，却比较了不同样本。

本实验把输入和观测的长度不一致视为错误，也拒绝空数据平均。空求和为 0、空乘积为 1 是可用约定，空平均却仍需要除以 0 个样本，不能由前两条约定推出合法值。

请在输出 CSV 中核对数学索引 i 与 Python 位置 j 每一行都相差 1，再回到原始 CSV 按 sample_id 核对同一条记录。不要只检查最后平均数，因为错位计算有时可能碰巧得到相同汇总。

## 六 量词顺序的有限穷尽

取输入集合 X 为 0、1、2，参数集合 B 为 0、-2、-4。逐格计算 2x+b 是否为 0。每行都至少有一个成立格，说明每个 x 各自能选择一个 b。但没有任何一列全成立，所以不存在一个共同 b 适合所有 x。

Notebook 分别执行这两个条件，预期输出 True 和 False。请用自己的话写出差别：第一个条件可以看到输入后再选参数，第二个必须先固定同一个参数，再应对所有输入。本例对有限集合进行了完整精确穷尽，因此足以决定这两个有限命题；它没有判断任意未指定输入或参数空间。

## 七 五点一致的反例

将另一条函数定义为 $p(x)=2x+1+x(x-1)(x-2)(x-3)(x-4)$。先说明为什么在五个整数输入上，乘积项都为零。然后用 $x=1/2$ 手算该乘积为 $105/32$，所以 p 与 f 的差为 $105/32$，p 的值为 $169/32$。

Notebook 用 Fraction 核对这个差，不依赖浮点容差。五个旧测试全通过，新反例仍然出现，因此“通过五点检查”不足以证明“在整个区间相同”。如果任务只声明五元素定义域，全部检查就覆盖了它；若任务声明连续区间，测试范围没有覆盖全部主张。

你可以在副本中增加更多采样点，观察图形与结果。但再多有限点也不自动变成全区间证明。报告要写“本次新增测试点未发现差异”或“发现一个反例”，不要改写成“已经保证任意输入”。

## 八 归纳证明与程序核验

程序用精确整数检查 n 为 1 到 100 时，前 n 个正奇数之和是否等于 $n^2$。这 100 项都应通过，最后一个和为 10000。计算量很小，不需要高速数组或加速硬件。

另外在纸上写完整证明：n 为 1 时两边为 1；假设前 k 项和为 $k^2$；前 k+1 项和等于前 k 项和再加 $2(k+1)-1$；使用假设并整理为 $k^2+2k+1=(k+1)^2$；由起点和任意推进步骤得到所有正整数结论。缺一部分都不能用“已验证 100 项”补成证明。

讲义中奇数序列是新定义的数学对象，不是在把设备模型经验范围扩展到任意工作量。请在报告中明确这一点，避免将公式规律和真实预测适用性混同。
