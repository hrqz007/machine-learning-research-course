# 数据与配置字典

observations.csv 是本单元原创的四行确定性合成教学数据，不来源于真实个人或机构。没有随机生成步骤、训练测试划分或隐藏预处理。

| 字段 | 原始语义 | 类型与范围 | 数组中的用途 |
|---|---|---|---|
| id | 固定行号 | 连续整数1至n，当前n=4 | 只作配对和报告索引，不进入设计矩阵 |
| x | 无量纲合成测量刻度 | 有限实数，教学入口范围[-100,100] | 仿射预测的一个特征 |
| y | 合成二元目标标记 | 只能为0或1 | 平方误差目标；分开的logit实验沿用同一列 |

数据行固定为 (1,-1,0)、(2,0,0)、(3,1,1)、(4,2,1)。参数顺序始终为[b,w]。设计矩阵每行为[1,x]，不是CSV整行。平方目标为每行半平方损失的样本平均。稳定性分支明确换成二元对数损失，不暗换数据。

experiment_config.json 是完整配置，不与任何隐含默认值合并。

| 键 | 默认值 | 含义及允许范围 |
|---|---|---|
| schema_version | 1 | 必须为整数1 |
| initial_parameters | [0,0] | 用户初始[b,w]，两项均在[-10,10] |
| learning_rate | 0.5 | 正常、符号、广播路径学习率；[1e-12,1000] |
| max_steps | 100 | 各路径最多尝试更新次数；整数1至1000 |
| gradient_tolerance | 0.000001 | 梯度二范数阈值；[1e-16,1e-2] |
| step_tolerance | 1e-12 | 新旧参数实际差值的相对更新阈值；[1e-16,1e-2] |
| loss_tolerance | 1e-14 | 相对绝对损失变化阈值；[1e-16,1e-2] |
| fd_steps | 0.1到1e-16共16项 | 差分扰动，非训练学习率；2至32个不重复实数，范围[1e-16,0.1] |
| fd_parameters | [0.2,-0.3] | 差分固定检查点[b,w]，范围[-10,10] |
| stress_parameters | [[0,40],[0,1000],[0,-1000]] | 1至8组独立压力参数；每项范围[-2000,2000] |

两个故障路径的固定干预明确写在源码和报告中：tiny_step 用1e-12替换学习率，large_step用10替换学习率；其余配置和数据不变。sign反转送往更新器的梯度，broadcast改为n×n交叉配对目标。

拒绝未知或缺失配置键、布尔值冒充数值、字符串冒充数值、非有限量、原始非零绝对值低于1e-150，以及JSON重复键。教学入口限制不是数学定理。内部有限更新参数可超出初值范围；内部保护范围为绝对值不超过1e100，以避免后续乘平方失去可解释性。内部指数尾项允许下溢并记录，不能与原始输入悄悄下溢混淆。

默认Notebook对本CSV、完整JSON与四个执行模块作全字节摘要校验。自定义数据/配置需要另存文件，使用脚本显式指定路径并保留独立报告。
