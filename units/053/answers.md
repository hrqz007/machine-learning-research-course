## 1 使用方式

本答案包含正文E1至E12、全部读图G1至G7以及实验L1至L8。数字来自交付experiment-result.json；另行运行的计时可以变化。先写你的推理，再核对差异，尤其不要把负结果改成预期胜利。

## 2 E1至E3 参数 组合与采样

E1：线性系数通常在给定训练目标下由fit求解，正则强度通常由验证流程选择，因此前者是训练参数、后者是超参数。但若把某系数固定成若干候选值并由验证选，则它在该外层流程里就是超参数。名称不是永久数学属性，必须说明哪个过程在决定它。

E2：四个参数每个10值共有10×10×10×10=10000种组合。三折是每组合训练3次，因此30000次搜索拟合。若最终选择一个并在全部开发集重拟合，总次数再加1；这不包括数据预处理、调度、失败或额外确认实验的成本。

E3：令u在[−4,0]均匀，λ=10的u次方。区间[0.0001,0.001]、[0.001,0.01]、[0.01,0.1]、[0.1,1]各占u的一单位长度，因此各有1/4概率。若直接在[0.0001,1]均匀抽λ，第一个区间长度0.0009，概率约0.00090009，远小于1/4。选择哪一种需要尺度知识，不能说其中一种永远公平。

## 3 E4与L1 预算逐项复算

网格每折6×60=360棵，三折1080。随机相同。淘汰第一轮12×15×3=540，第二轮4×30×3=360，第三轮1×60×3=180，合计1080。最终模型另用240行训练60棵，所以每方法每份数据1140棵。

六份数据三方法，搜索请求树总数为1080×6×3=19440，重拟合总数60×6×3=1080，两者合计20520。单独的失败演示另外请求15棵、完成0棵，不能混同已完成的主要实验工作。

严格续训反事实：第一轮540；第二轮只为4个幸存者每折新增30−15=15棵，故4×15×3=180；第三轮1×(60−30)×3=90。搜索共810棵，最终另60，共870。当前fit_record每次新建模型并从头训练，必须使用1080而非810。

网格和随机每份18次搜索拟合，淘汰51次。六份总搜索拟合为(18+18+51)×6=522，加18次最终重拟合为540次成功主要拟合。等树数不等秒数，因为深度、特征候选数、停止条件、输入排序和调度开销可以不同。

## 4 E5 淘汰与平局

A平均(1+2+3)/3=2；B平均2；C平均1；D平均3。排序为C、A、B、D，其中A和B按预先编号平局裁决。保留两个时为C和A。不能只比较最好的折，也不能在平局时偷看测试答案。

下一轮必须为所有幸存候选使用同一新增资源口径。本包从头拟合30棵，不是给A30而给C60再混排。若某候选失败，保留状态和异常，排名置后；全部失败则停止并报告。不能让None或NaN进入普通数值排序后意外胜出。

## 5 E6与G4 慢热反例

正文给定fast=(0.4,0.35,0.34)、slow=(0.7,0.3,0.2)。第一轮只留一个会选fast，第三轮若两者都有机会则slow更好。这个数字例子证明“早期最佳一定最终最佳”不是逻辑真理。

可提高起始资源、降低淘汰比例、用多个预算支架，或分析资源与最终质量的相关性。它们都增加成本，而且仍不能保证对任意未知学习曲线不出错。图4没有来自模型拟合的数据，因此不能拿它估计本实验淘汰误杀率。要知道本实验被淘汰者的最终分数，需额外完整训练并单独记账。

## 6 E7与G5 选择噪声

一个估计无偏，并不保证从多个估计中选最小者仍无偏。两候选都真实风险1，估计0.8与1.2，挑出0.8只说明该候选在这次估计更低。它的真实风险仍是1。由于选择偏爱负噪声，最低验证损失通常会显得过好。

图5每次重复让64个候选真风险都为1，添加标准差0.15的独立正态噪声，取前k个最小值。k越大，可能出现很小负噪声的机会越多。下降曲线不表示模型被改进。实际CV候选误差相关，不能把此图精确用作真实研究的偏差校正公式。

10000次是人造噪声机制下的独立模拟，不是真实的10000个不同领域数据集；其规模只减少本示教模拟均值的随机误差。嵌套评估或新的测试集能评价选择流程，但不能把有限数据训练的不确定性全部清除。

## 7 E8 Bayesian优化的两点EI

当前最好损失b=0.5。点甲损失确定0.6，max(0.5−0.6,0)=0，因此EI=0。点乙一半概率0.2，一半0.8，改善分别0.3与0，平均0.15。因此在这个明确代理分布下，EI偏好乙。

这并不意味着乙真实模型一定更好。代理是关于未知损失的估计，可能失配；采集函数只根据该估计分布决策。代理拟合和选择下一个点有开销，廉价模型中这部分不一定划算。本实验没有运行Bayesian优化，因此没有它的实测排名。

## 8 E9至E12 研究结论

E9：树数是离散的近似资源单位，深树和浅树消耗不同，特征候选数不同也会改变每个节点的搜索成本。等树数不能写成等FLOPs或等时间。若目标是限定30秒，就应直接设计墙钟截止和未完成任务处理规则，并报告机器与并行设置。

E10：最少账本应含运行与方法ID、数据版本、折/种子、配置、请求资源、实际完成资源、状态、耗时、错误与重试、最终重新拟合成本。失败不能简单删除。缓存和共享预处理是否计入要预先说明；有些比较允许共享固定输入变换，但不能只让一方免费。

E11：本次网格均值3.209982，随机3.290078，淘汰3.219101。不能支持随机或淘汰普遍更好。能支持的是：在已声明同一机制、同预算口径和固定候选政策下，这六份数据得到了这些完整结果。随机基线的研究价值不要求在每个小实验中胜出。

E12：若根据目前测试结果改变搜索空间、预算、候选数或报告策略，当前测试已参与开发，不能继续作为不受选择影响的最终确认。新一轮需要新封存数据或事先设计的外层评估；旧结果仍应保留作为探索记录。

## 9 G1至G3 信息图 候选图与曲线

G1：偷看测试误差调学习率会增加“测试标签→搜索选择”的箭头。重新拟合允许用240行，因为它们属于开发资源；测试行用于评价未来未知样本，加入训练就改变了对象。三条路线全部选择完后统一评价，是为了避免先看某一条测试结果再改变另一条流程。

G2：3×2子网格只有三种深度；六个不放回随机点可能涉及更多深度，因此在深度最重要时可能更有效。但若关键设置恰在网格或特征比例才最重要，这个优势不保证存在。相同允许域、不同采样政策就是本次比较的一部分，不能称“候选完全相同”。

G3：第二轮已只保留一个，所以第三轮没有竞争，只评价幸存者在60棵时的表现。它仍实际做三折×60=180棵训练，因此不能漏记。可预先省略末轮，但那成为900棵搜索预算的不同设计；若要保持1080，必须事先规定剩余180棵怎样分配，不能事后挑结果。

## 11 L2与L3 数据及单次损失

L2：每份600行，开发240、测试360；开发三折中160训练、80验证。x0、x1、x2含信号，x3至x9为噪声。森林只得到X与y，不得到生成式。ε标准差1，因而真实函数的总体最优MSE为1；有限测试上的噪声平方平均不必恰好1。

测试标签干预是在复制y后把索引240以后改成很大数，仍只给choose前240行。被选择配置与CV分数相同，说明这个具体路径未读取测试标签。它不是所有未来改动永远无泄漏的证明，所以代码修改后仍应重新审计。

L3：每一折以valid_ids索引匹配标签与prediction，逐项平方误差除80。三个MSE再除3。每折验证互不重叠，但训练样本大量共享；因此三折估计相关。下面的可运行片段取真实第0份网格候选0，并打印全部算术结果：

```python
import json, numpy as np
from pathlib import Path
r = json.loads(Path('experiment-result.json').read_text())
y = np.load('data/draws.npz')['y0']
s = next(x for x in r['runs']
         if x['rep'] == 0 and x['method'] == 'grid')
vals = []
for z in s['fits']:
    if z['candidate'] != 0:
        continue
    errors = y[z['valid_ids']] - np.array(z['prediction'])
    vals.append(float(np.mean(errors ** 2)))
print(vals, sum(vals) / 3)
```

这段答案计算的是实际记录而非固定文本里的近似小数；Notebook也会显示相同结果。预测顺序和行号不一致会导致错误，即使两个数组长度碰巧相同。

## 12 L4至L6 复核调度与账本

L4：读取halving第0份stages[0]的前4个candidate，必须等于下一轮fits的候选集合；再读stages[1]第一名，必须是末轮唯一编号。答案脚本与Notebook会直接输出这两个集合，避免把候选ID误当DOMAIN全局下标。候选ID只是本次抽出的configurations里的局部序号。

L5：按相同rep配对，均值与标准差见正文表格；所有18个最终测试MSE都在runs中。样本标准差分母n−1=5，不能叫置信区间。六个数据种子已预先固定，不能因随机未胜出而重新抽一批再只报告后者。

L6：故意失败只请求15棵，完成0棵，异常可读、没有重试。它独立于主要三方法公平比较。非法输入应显式抛ValueError，不应自动截断、广播成另一任务或用零分替代。账本应保留失败尝试的真实成本与协议处理，而不是把未完成工作伪报成功。

## 13 L7与L8 最终提交示例

L7：新执行结果应每个代码格都有实际递增计数，无error输出；七张图由新结果重新生成并嵌入。计时图计时可变，其他图的数值关系应一致。仅打开旧Notebook或改execution_count不叫重新执行。命令行执行器测试IPython进程内内核；浏览器Jupyter和远程内核不在本次范围。

L8参考段落：我们在六份独立生成的600行回归数据上比较固定子网格、随机采样与逐次淘汰，每路线每份预算1080棵搜索树及60棵重拟合树。固定三折选择后，在360行独立测试上，平均MSE分别为3.209982、3.290078、3.219101。随机4/6份比网格差，淘汰3/6份更差。本结果不支持新搜索法普遍更强，只刻画该生成机制与预算口径。等树数不等时间，六份同机制数据不足以代表所有研究任务；Bayesian优化未在本实验中运行。
