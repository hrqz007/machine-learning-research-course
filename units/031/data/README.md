# 一维梯度下降的合成数据

regression.csv沿用第28讲原创五点x=(0,1,2,3,4)、y=(1,2,2,4,6)，用于独立推导一维剖面。每个b都配最佳截距a=3−2b；f(b)=SSE/(2n)=4/25+(b−6/5)²。q=2、w*=6/5、c=4/25，不能把a固定或使用SSE却保留原学习率。

learning_rates.csv使用明确整数分子/分母给η=0、1/10、1/4、1/2、3/4、1、5/4。Fraction理论轨迹读取这些有理数；浮点轨迹使用明确转换后的学习率，并实际逐步更新。近似分数输入不应被伪装为已存储float的精确原意。

主初值b0=0，固定绘图20步，另有最多250步的停止实验。η1/4与3/4误差绝对值每步减半，参数误差10^-6最少21步，梯度10^-10最少35步。η1/2理论一步到位；η1两点循环；η5/4误差倍率−3/2发散，不能用循环结束或增长保护冒充收敛。

model_spec还定义目标乘数10、参数坐标放大100、非二次反例w^4从1用η1更新，1→−3、目标1→81。所有数据均为合成教学机制，无RNG、网络服务、付费API或现实性能含义。
