# 教学数据与重复流程

全部输入是人为指定的合成教学设定，无真实人员或业务数据。

model_spec.json记录主模拟：PCG64基础种子22022，R=4000，n为4、16、64、256，Bernoulli概率1/4。分布编号0到3依次为Bernoulli、Exponential(scale1)、Pareto I(alpha1.5，生成器输出加1)、标准Cauchy。每组种子=基础seed+1000×分布编号+n。不同n独立重新采样；不是同一数据前缀。群组反例种子=基础seed+8000，8组×8份复制。

finite_population.csv是四个固定、带身份的总体单位。unit_id唯一；value为整数。A、B的值都为0，C、D的值都为1，但不能去重。脚本实际读取全部四行，枚举所有无序两单位组合，得到六个样本均值及精确方差。

脚本运行生成outputs/report.json及sample_means.csv。CSV每行是一个完整模拟批次的均值，字段family、n、replicate（从0开始）、mean。默认共有4×4×4000=64000行；这些是统计量记录，不是64000个真实设备。报告区分精确分数、理论量及有限模拟量。重尾数据没有删极端值或截断。

Notebook额外运行均值图使用种子220222至220225，每条4096次Bernoulli结果。它单独研究同一序列的前缀均值，与主重复矩阵设计明确分开。
