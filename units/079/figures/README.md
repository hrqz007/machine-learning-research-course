# 五幅原创图

plots.py从解析公式和experiment.run结果生成同名PNG与SVG。

1. 01_geometry：真实倾斜高斯与独立近似的等Mahalanobis半径轮廓（半径1、2，不把它们称为95%区间）。
2. 02_elbo：初始化及前30次坐标更新，下界、族内极限与固定证据。
3. 03_coordinates：前16次坐标更新的均值路径与解析中心。
4. 04_direction：相同独立高斯族，两个KL方向产生不同方差。
5. 05_noise：噪声扫描、后验相关绝对值与原坐标边缘方差比。

图不复制外部素材；所有数值与正文一致。中文字体来自Noto CJK，缺失时应安装字体再构建，不能默许方框字。
